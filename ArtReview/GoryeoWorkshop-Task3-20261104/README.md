# 3번 닥목 한지 공방 검토안 — 승인·본편 연결 완료

기존 한지 작업장/건조대 그림과 종이 일꾼을 유지하고 접수 위치만 추가한다. 사용자 “좋은 것 같아” 승인 후 본편 Crafting.Recipes와 goryeo_life 배치 원본에 연결하고 Dakmok 씬을 다시 만들었다.

## 주문형 레시피

- 상품: 기존 paper(종이) 1묶음. 인벤토리에 없는 닥나무 껍질 등을 새 상품으로 만들지 않고, 재료는 공방이 제공한다.
- 비용: 현재 닥목 장터 종이 매입가+작업삯5냥, 최소18냥. 단순히 같은 물건을 직접 사는 것보다 싸게 공급하지 않는다.
- 대기: 게임시간6시간, 한 번에1묶음, 하루2묶음. 완성품은 짐이 비면 찾아갈 수 있다.
- 접수 위치: Dakmok JSON(37,53), 기존 한지 작업장 앞쪽 통행 가능한 빈칸. 충돌 없음. 종이 일꾼 이름과 겹치던 최초(40,52)에서 옮겼다.

## 초기 재고·중립·보통날 비교

양쪽 모두 같은 목적지 판매 시세를 가정한 단위 비교다. 출신·흥정/운송비·이동 시간 차이와 이후 시세 변화는 포함하지 않는다. 주문에는 추가로6시간이 걸린다. 가격/이익을 게임에서 보장하는 문구로 쓰지 않는다.

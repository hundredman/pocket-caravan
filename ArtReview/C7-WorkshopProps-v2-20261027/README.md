# 수확·청자 물품 크기 수정

2026-10-27 사용자 요청: 건조대 크기는 괜찮지만 수확/청자 개별 물품이 이전 게임보다 커 보이므로 최대한 작게, 이전 정도로 표현한다.

- 한지 건조대 PNG/Aseprite는 앞 시안 그대로 복사했다. 크기 수용 의견을 기록했으며 전체 그림 승인으로 범위를 넓히지 않았다.
- 수확 꾸러미는 큰 볏단 머리·자루를 작은 볏단 여러 개와 낮은 곡물 자루/바구니로 재구성했다. 윤곽은 직전47×27에서41×24로 바뀌었다.
- 청자는 큰 병·항아리3개 구성을 작은 병·항아리·그릇6개로 재구성했다. 윤곽은 직전37×30에서39×24로 바뀌었고 개별 물품을 작게 했다.
- 모든 후보는 기존48×32 캔버스와 하단31을 유지한다. 원래 게임·직전 시안·수정안을 같은6배와 실제1배로 비교한다. 개별 물품의 체감 크기는 사용자 그림 검토 대상이다.

별도 AI 원본에서 온전한 묶음을 전체 균등 최근접/A5 기존 후보색/Aseprite 외곽선으로 정리한다. 새 물품 묶음 높이는24px 이내로 제한한다. 건조대는 재생성·축소·색 정리하지 않는다. 런타임 그림 가공 없음. 기존 본편/승인본/수레/ID·저장·충돌 미변경.

원래 게임 사용처와 별도 큰 건조대 구분은 source-usage.json을 유지했다. 비교판의 원래 게임/직전/수정3열과 실제 Unity 전후를 보고 판단한다. 본편 연결이나 개별 승인 범위를 자동 확대하지 않는다.

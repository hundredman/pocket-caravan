## 연결 전 남은 판단

성문 속 열린 공간의 폭은 현재 개경4칸 통행 폭을 확정하거나 대체하지 않는다. 그림 승인 후 실제 출입구 크기, 담장 접합, 발밑, 캐릭터 가림과 충돌 영역을 별도 검토해야 한다. 현재 도로를 줄이거나 경로를 막는 구현은 하지 않았다. `binding-notes.json`에 근거와 남은 항목을 기록했다.

다음 남은 후보는 종이 건조대·수확/곡물 소품·청자/장독 등이다. 벚나무는 원본/사용처 연결 확인이 필요하다. 이 묶음 승인만으로 C7 전체나 B3~B5 본편 연결이 완료되지 않는다.

**2026-10-29 사용자 수정 요청 반영·그림 승인 대기·본편 미적용.**

- 이삭/볏짚 금색은 승인된 초가집 지붕과 같은 #b77c3e / #e2ac52 / #f7d17b다. 잎은 올리브색 일부만 남기고 전체 인상을 따뜻한 황금색으로 바꿨다.

- rice-ripe.aseprite / rice-ripe.png가 편집 원본과 게임용 시안이다. 이진 알파,7색. 원화ripe-rice-ai.png, [프롬프트](prompt.txt), native정리 prepare.lua.

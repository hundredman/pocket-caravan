# M4 ② 새 맵 JSON (검토용)

M3 그림(지형+마을)을 게임 맵 형식으로 내보낸 결과다. 본편 `Maps/`·씬·등록은 바뀌지 않는다(본편 전환은 ④).

- 원본: `M4_LAYERS=<폴더> python3 Tools/WorldLayout/m1_tiles_preview.py --zones`(층 그림) → `python3 Tools/WorldLayout/m4_export.py <폴더>`
- 결과: `Assets/PocketCaravan/Editor/B2Preview/M4/Maps/<mapId>.json`(.gitignore로 저장소에 올리지 않는 미리보기 폴더), `.../Tiles/m4_*.png`(새 칸 그림 1,294개, 기존 타일과 같은 칸 33종은 기존 이름), 여기 `<mapId>.png`(JSON에서 다시 그린 그림), `<mapId>-blocked.png`(붉은 칸 = 막힘, 어두운 곳 = 이웃 맵), `report.json`
- 맵 하나 = 그 맵 구역을 감싸는 직사각형. 구역 밖 칸은 이웃 맵 그림을 보여 주되 막는다.
- 층: 바닥(풀·물·흙길), 장식(풀포기·꽃·다리), 아래 개체(막힌 칸이거나 밑동이 같은 줄 이상인 개체 그림), 위 개체(걸을 수 있는 칸을 가리는 지붕·나뭇잎). 각 층 안에서는 밑동 줄 순서로 겹친다.
- 막힘: 물(다리 판자가 칸의 절반 이상 덮으면 걸을 수 있음), 숲·산·수원지 숲, 건물·소품 충돌, 나무 줄기 가운데·덤불·바위 밑동.
- 길 등급: 마을 사이 큰길·다리 2, 마을 흙길 1.
- 검사(정적): 13개 맵 모두 JSON만으로 다시 그린 그림이 원래 그림과 픽셀까지 같음(담당 밖 칸 제외). 맵 객체(스폰·출구·시장·NPC)는 ③에서 넣는다.
- Unity 미리보기 씬(2026-10-28, Mac Unity 6000.3.26f1): `MapJsonBuilder.BuildSingleMap`으로 13개 모두 생성 성공. 바닥 타일 빠짐 0, 막힘 칸이 JSON과 모두 일치(Unity 씬 검사). 화면 `unity-preview.png`. 씬·타일은 `.gitignore` 미리보기 폴더라 저장소에 없다. 실제 걸어 보기는 ③(스폰·출구) 뒤에.

## ③ 맵 객체 (2026-10-28)

- 원본: `Tools/WorldLayout/m4_objects.py`(m4_export.py가 부름), 검사 `Tools/WorldLayout/m4_reach.py`
- 출입구: 두 맵이 맞닿은 경계에서 양쪽이 걸을 수 있는 곳을 가로·세로 직선으로 묶어 출구(경계 바로 안쪽)와 도착 자리(상대 맵 경계에서 한 칸 더 안)를 만든다. 걸을 수 있는 경계 전체가 이어진다(배치안 D). 13개 맵에 출구 958개(경계가 계단 모양이라 1칸짜리가 많다).
- 기능 객체: 시작 위치 S0(나루 '시작 위치'), 기존 시장·게시판 7곳, 퀘스트 NPC 6명, 옛 맵의 대화 주민·일꾼·낚시·상인 행렬·지역 주민·마을 발전 소품·주변음·도적을 새 자리로 옮겼다. 석등 그림마다 불빛. 옛 이정표 24개는 방향 글이 옛 배치 기준이라 옮기지 않았다(M5에서 새로 씀).
- 새 마을(남동 포구·중앙 길목 마을·쉼터 마을 2곳)의 시장·게시판·새 NPC는 ID·시장 자료(E2)가 정해지지 않아 넣지 않았다.
- `<mapId>-objects.png`: 주황 출구, 하늘 도착 자리, 흰 S0, 노랑 시장·게시판, 분홍 NPC·주민, 빨강 도적.
- 검사: 정적(m4_reach.py) — S0에서 출구를 따라 걸어서 13개 맵 모두, 모든 시장·게시판·NPC·주민에 닿음. 출구마다 목표 맵의 같은 폭 도착 자리와 돌아오는 출구가 있음. Unity 씬 검사 — 미리보기 씬 13개 생성, 도착 자리 모두 걸을 수 있는 칸, NPC·시장·게시판 수 일치. 실제 맵 넘나들기(플레이)는 ⑦에서.

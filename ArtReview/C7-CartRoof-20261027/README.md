# 수레 구조·기와집 지붕 수정 묶음

2026-10-27 사용자 지시: 수레가 작을 때 조잡하고 바퀴·손잡이 위치가 이상함. 기와집 지붕도 밋밋해 수정 필요.

## 만든 것

- **수레32×32:** 기존 사선 구도를 버리고 정면에 가까운 탑다운 구도로 새 AI 원본 제작. 같은 차축의 좌우 바퀴와 적재함에서 앞으로 이어지는 두 손잡이를 배치했다. 전체 개체를 균등 최근접으로28×27에 맞추고 A5 후보17색·이진알파로 정리했다. Aseprite에서1px 외곽선과 나무색 중심이 보이는3px 폭 손잡이를 작성했다. 전체 캔버스·발밑30 유지. 출처 `ai_processed`.
- **기와집64×48:** 새 AI 그림은 기와 골·용마루·처마 구성 참고로만 사용했다. 승인된 온전한 집 원본에 네이티브 지붕 레이어를 추가했다. 곡면 하이라이트·짧은 기와 겹침선·처마 끝·용마루를 정리했다. 변경은 기존 지붕의 청회색 픽셀(y14~26)에만 한정되며, 실루엣·벽·문·창·기단·발밑47은 그대로다. 기존 승인본과 승인 기록을 덮어쓰지 않았다. 출처 `authored`.

후보17색은 공통 D3 팔레트 결정이 아니다. 두 그림은 후속 사용자 지적으로 changes_requested이며 본편 교체 없음. 수레 복원·용마루 색 후속안은 `../C7-CartRoof-v2-20261027/`에 보존했다. 앞 수레 시안은 `changes_requested`로 보존했다. 다른 기와 건물로 일괄 확장하지 않았다. 우물·석등도 자동 승인하지 않았다.

## 재현

1. Aseprite 배치에서 `Tools/ArtTrials/c7_cart_roof.lua`에 `root`(이 폴더 절대경로), `base`(저장소 절대경로)를 전달한다.

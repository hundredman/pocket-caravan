# C7 큰 건조대·낮은 담장·작은 장독

## 원본과 범위

- **큰 한지 건조대64×48:** `c6_goryeo_paper_7473141b`, 현재 닥목에서24렌더칸 참조. 승인된3×2칸 작은 건조대와 별개인4×3칸 원본이다. 종이3장·기둥·짧은 받침으로 구성한다. 발밑46 유지.
- **낮은 담장64×32:** `c6_goryeo_wall_c7149fb3`, 현재 송악8칸·개경16칸 참조. 양끝이 마감된 완성 개체 한 구간이다. 도시 성벽의 단일 타일 `house:10:8/10:9`나 성문 연결을 교체하는 작업이 아니다. 이 그림을 이어 붙이는 반복 성벽 규칙도 추가하지 않았다. 발밑31 유지.
- **작은 장독16×16:** `c6_single_element_4_0`, 갈색 열린 장독 한 개다. 승인된3×2칸 청자 진열과 다른 역할이며 캐릭터보다 작은 기존 크기다. 발밑15 유지.

본편 원본/목록/맵에서의 사용 근거는 source-usage.json에 기록했다. ID/저장/충돌·마을 배치를 변경하지 않는다.

## 만들기·검토

각 원본은 형태와 크기 참고, 승인된 작은 건조대/청회색 용마루 기와집/가게와 팀 베네치아·아라비아는 스타일 참고다. AI 단일 개체 제작 → 온전한 개체 균등 최근접 → A5 기존 일반23색·장독5색 후보 → Aseprite 원본/외곽선. 첫 건조대·담장 후보는 너무 납작해 원래 개체 비율에 가깝도록 추가 AI 편집했다. 후보색은 D3 공통 팔레트 결정이 아니다. 생성 중 런타임 크기/색 변형을 추가하지 않는다.

[원래/수정·실제1배·팀 비교](style-comparison.png), [최신 Unity Play 전후](game-comparison.png). 성문·기와집·객주·가게·인물·지형·연못은 동일한 검토 시험장 맥락이다. 실제 마을 배치·이동 검사가 아니며 세 그림 각각 사용자 승인 대기다. 승인 소품과 기존 게임 수레는 보존한다. 본편 적용 없음.

## 남은 판단

벚나무는 legacy STAMPS가 nature(14,0)2×2를 가리키지만 현행 동결 목록/색인에서 해당 키·온전한 개체 연결을 찾지 못했다. 다른 woodland를 벚나무로 추측해 바꾸지 않았다. 정확한 원본·사용처 연결 검토가 필요하다. 성문4칸 입구 연결·담장 접합·가림/충돌 판단도 별도다. binding-notes.json 참조.

## 재현

Aseprite 배치에서 `Tools/ArtTrials/c7_courtyard_props.lua`에 root(이 폴더 절대경로) 전달 → Pillow Python `Tools/ArtTrials/c7_courtyard_props.py prep` → 같은 Lua `finish=true` → Python `register` → 이 worktree Unity6000.3.26f1 `C7CourtyardPropsReview.Run`(Burst 비활성·worker2) → Python `board`.

실제 보행·수동 플레이·저장 회귀·전체 통합·게임 빌드는 실행하지 않았다. C7 전체 완료나 본편 연결 완료로 처리하지 않는다.

최종 가시 윤곽은 큰 건조대62×38(원래62×45), 담장62×28(원래62×30), 장독11×12(원래11×13)이다. 모두 원래 캔버스·발밑 유지. 장독의 어두운 입구는 네이티브에서 정리해 열린 형태를 보강했다.

# M2 마을 구역도 (검토용)

M1② 지형(ArtReview/M1-Tiles) 위에 마을 11곳의 기능 자리를 잡았다. 나루는 은샘 승인(2026-10-28) 위치 그대로이고, 나머지 10곳은 은샘의 "승인 없이 모두 진행" 지시(2026-10-28)로 같은 규칙을 적용해 자동으로 잡았다.

- 원본: `Tools/WorldLayout/m2_zones.py`. 결과: `zones.json`(전체), `<마을>.json`, `<마을>.png`(1:1), `<마을>-half.png`, `<마을>-lanes.npy`, `check.json`
- 색: 노랑 장터 광장, 주황 이벤트 마당, 빨강 건물 자리(흰 칸은 문 앞), 하늘 물가 자리, 파랑 배, 흰색 게시판·우물, 분홍 NPC, 연노랑 석등, 초록 성장 자리, 갈색 골목
- 마을마다: 장터 광장(시장), 게시판, 이벤트 마당, 집, 우물, 석등, 성장 자리 + 마을별 건물(개경 궁성·객주·시전, 송악 상점·정자, 닥목 촌장 집·한지 작업장, 장단 곳간, 포구 상점·창고·나루터·배, 길목 마을 객주·상점, 쉼터 마을 주막)
- 장터 광장: 개경 14×8, 보통 마을 12×7(자리가 모자라면 돌리거나 줄임: 송악 7×10, 닥목 10×6), 쉼터 마을 8×5(북쪽 쉼터 6×4). 계획 문서의 24×15는 M1에서 마을 범위가 줄어 들어가지 않는다.
- 기존 ID: M0 대응표 그대로. 새 ID 제안(런타임 등록은 M4): `transit_southport`, `transit_crossroads`(시장·게시판), `rest_north`, `rest_lake`(쉼터 마을 시장·게시판). 새 NPC는 이름만 두고 ID는 M4에서.
- 정적 검사(`check.json`): 마을 11곳이 모두 한 길망에 있음. 길이 맵 경계를 넘는 출입구 17곳. 모든 건물 문에서 길까지 골목이 이어짐.
- 남은 점: 북쪽 쉼터 마을은 땅이 좁아 집 2채 중 1채만 들어감. 길 경계 넘는 횟수(M1 남은 점)는 지형을 그대로 두라는 지시로 고치지 않음.

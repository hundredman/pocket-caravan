## 검증과 제한

관련 정적/픽셀/도구 검사25개 통과: main C6 12개, main R2 5개, 신규8개. 신규 검사에는 A2 승인 차단, Aseprite12개 재출력 RGBA 일치, 전체87칸 재구성/누락 거부, 기존·승인 PNG353개 보존, 볏단 몸통 폭, 화면 차이 영역과 원본 불투명색 오차≤1 확인이 포함된다. PNG 동일성은 크기와 디코딩한 RGBA로 비교한다.

Unity 카메라 촬영은 Play 진입·본편 씬 열기·씬 저장·공용 런타임 부트 없이 수행했다. Smoke의 기존 화면과 최종 before3장이 RGBA 일치하며 페이지마다 후보 네 영역만 바뀐다. 배/연꽃 뒤 사각 물색은 가독성용 배경이며 새 물 지형이 아니다. 실제 이동·통행·충돌·가림·저장·수동 플레이·전체 통합·게임 빌드는 미실행이다.

보호 대상100파일의 세션 전후 검사에서 변경/추가0. shared 데이터의 과거 해시를 영구 CI 조건으로 되돌리지 않았다. 보호 결과는 이번 자체 변경 검사이며 향후 main의 정상 변경을 금지하는 테스트가 아니다.

C7 전체 완료는 아니다. 단일칸/조립 지형·미확인 벚나무 원본·성문 통행/담장 연결·본편 연결 검토는 별도이며 일부 원본은 transit 전용이다. 이번 승인으로 공용 파일 수정 권한이 생기지 않는다.

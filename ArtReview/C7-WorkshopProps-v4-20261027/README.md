# 풍성한 볏단·청자 수직 중심 정렬

사용자는 v3 볏단이 더 홀쭉해 보이고 긴 청자의 주둥이가 기울어 보인다고 지적했다. 줄기만 넓힌 v3를 수정 요청으로 남기고, 이번에는 볏단의 전체 형태와 병 어깨까지 수정했다.

- **볏단:** 원래 게임 수확 그림의 풍성한 이삭·짧은 줄기·벌어진 밑동을 참고해 전체 수확 묶음 AI 수정1회. 온전한 묶음을 균등 최근접/A5 기존9색으로 정리한 뒤, 같은 개체의 기존 곡물 자루·바구니 전경을 원본 자리에 보존하면서 볏단 영역을 편집했다. 바구니와 자루 중심 픽셀은 동일성 검사로 확인했다. 가늘고 긴 줄기3개 모양 대신 짧고 넓은 볏단 형태다. 새 원본은 AI/harvest.png, 정리 중간본은 Prepared/. 최종 전체 개체는 Native/harvest.aseprite이다. 맵에서 조각을 재사용하거나 가공하는 방식이 아니다.
- **청자:** 네이티브 Aseprite 편집으로 주둥이·목·어깨의 알파 윤곽 중심을 모두 x14에 맞췄다. 한쪽에만 있던 입구 하이라이트를 지우고 어두운 내부를 가운데에 놓았다. y7~20 각 행의 좌우 끝 중심이 일치하는지 검사했다. 기존8색 유지. 다른 그릇·항아리·받침은 유지했다.
- **건조대:** 이전 PNG/Aseprite 그대로 복사했다. 추가 수정·재생성·전체 그림 자동 승인 없음.

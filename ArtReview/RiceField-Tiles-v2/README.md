# 벼 포기 겹침으로 만든 논 블록

**황금색·좁힌 포기 수정본·그림 승인 대기·본편 미적용.**

숲을 나무 개체로 합성했던 방식처럼 RipeRice-v2의32×32 벼 한 포기 전체를16px 간격으로 겹쳤다. 행마다4px 엇갈리고 밑동의 뒤→앞 순으로 그린다. 초가 지붕 금색으로 모아 그린 v2 포기를 전체 그대로 사용했다. 합성 시 줄이기/회전/색 변경은 하지 않았다.

- [간격 비교](comparison.png): 왼쪽24px(64포기) / 오른쪽16px(144포기), 같은12×12칸 범위·동일2배.
- [9종 조립판](module-sheet.png): 반복 중앙, 위/아래/좌/우 가장자리, 바깥 모서리4개.
- [Unity480×270](unity-480x270.png): 기존 캐릭터·풀·단독 벼와 논 블록9개를 실제로 연결한 모습. 넓은 논의 일부가 화면에 보이도록 배치했다.

## 조립 단위

논의 논리 블록은 **6×6칸(96×96px)**이다. 중앙을 반복하고 바깥에는 방향에 맞는 가장자리·모서리를 붙인다. 가장자리 이삭이 네모로 잘리지 않도록 좌우16px/위32px/아래16px 바깥 표현을 따로 포함한다. 따라서 외곽 조각의 PNG는 중앙보다 크고, catalogue.json의 logicalOffsetPixels로 배치한다.

처음부터 모듈 용도로 합성한 넓은 논을 렌더 구역별로 분할했다. 조각 속 잘린 식물 부분을 독립 개체로 쓰는 것이 아니라, 인접 모듈과 함께 원래 포기 전체를 복원한다. 바깥 경계의 포기는 화면 밖으로 잘리지 않게 전체가 들어간다.

현재는 가로/세로 각각2블록 이상인 **직사각형 논**용이다. 최소12×12칸이며 임의 곡선·오목 모서리·한 칸 폭 논용 규칙 타일 전체를 완성한 것은 아니다.

## 원본·검사

- Tools/ArtTrials/rice_field_tiles.lua → Source/field-master.aseprite와 Native/*.aseprite/PNG9종.
- Tools/ArtTrials/rice_field_tiles.py → catalogue.json, checks.json, 비교/조립 그림.
- 2×2/3×3/5×2/2×5/4×3 블록 조립과 포기 전체를 직접 배치한 기준 그림이 디코딩RGBA로 완전히 같다. 논 크기를 늘려도 경계에서 이삭이나 밑동이 빠지지 않는다.
- 원본 벼 색/알파/크기는 그대로이며 새 조각도16px 격자·알파0/255다. Unity 타일9개 연결 렌더와 기존 풀 위 직접 합성 기준의 논 구역도 RGBA차이0이다.
- Unity는 별도 메모리 Edit 검토 씬으로 촬영하고 원래 씬으로 복귀했다. 본편 맵·기존 숲·원본 벼·A2·경제·저장은 변경하지 않았다. 실제 플레이·충돌/가림·바람 애니메이션·본편 연결은 미검사다.

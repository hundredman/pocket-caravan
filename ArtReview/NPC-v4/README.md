# 사람 NPC 선·색 정리 v4 · 아낙 정면 스타일 확인

사용자: v3가 좋아졌으나 선과 색 정리가 필요함. 얼굴/소품 배치와 몸 비율은 유지하고 재질별 윤곽선·중간색만 정리했다.

- `comparison.png`: 정리 전 v3 / 정리 후 v4, 동일한 16×24와 확대 배율.
- `game-comparison.png`: 각 480×270 검토용 합성. 건물·나무는 두 화면에서 같은 이미지를 사용했고 본편을 교체한 캡처는 아니다.
- 촌장 37→28색, 아낙 36→27색, 행상 37→26색. 피부는 밝은 면/기본/그늘을 유지하고, 옷/목재의 비슷한 중간색과 윤곽선 변동을 정리했다. 눈 반짝임과 역할별 색은 남겼다.
- 기본 얼굴·몸 배치·발밑·16×24 크기는 유지했다. 후속 요청으로 아낙의 왼쪽 세로선과 그 연결 잔여물 11픽셀을 제거했다. 추가로 화면 오른쪽 눈 위의 머리카락1픽셀을 피부색으로 바꿔 눈과 분리했다. 그 외 아낙 픽셀과 촌장/행상 파일은 각각 수정 직전과 동일하다. `woman-arm-fix-comparison.png`, `woman-eye-fix-comparison.png`에서 각 수정 전/후를 확인할 수 있다.

원본 생성: `Tools/ArtTrials/npc_polish_v4.py`가 v3 네이티브 렌더러를 같은 좌표로 호출하고 색·윤곽선 처리만 바꾼다. 비교 그림은 `review_npc_v4.py`. PNG와 Aseprite 원본은 인물별 `*-front` 파일이다. `trial-colors.txt`는 이 시안에 실제 사용된 색 목록이며 D3 팀 공통 팔레트 승인본이 아니다.

크기·알파0/255·발밑·원본 재열기 픽셀 일치, A2 목록/PNG 기술 검사를 확인했다. 정면만 갱신했다. 사용자 미술 승인·걷기/다른 방향·Unity 임포트/실제 플레이는 대기다. 건물·나무·동물 원본·본편 Assets/·저장/ID는 바꾸지 않았다.

# 참고 후 폐기한 AI 자세 시안

기본 imagegen 도구의 precise-object-edit로 원래32×48 사막여우를 참고해 정면 앉기 자세를 만들었다. 얼굴·귀·상의·팔레트 보존, 무릎을 접고 손은 무릎 위, 투명 배경/32×48 논리 격자, 의자·배경·그림자 없음이 요청 내용이다. 결과는 얼굴/상의 색과 형태를 바꿔 사용할 수 없었다. 이 파일은 **자세 참고 전용/사용 안 함**, 본편/새 Sprite 입력으로 읽지 않는다.

최종 새 자세는 원래 PNG를 Aseprite에서 열고 Tools/ArtGen/goryeo_seat_fennec.lua로 하체만 다시 그렸다. 원래 귀·얼굴·상의·허리띠0~30행은 RGBA 픽셀 동일 검사로 보존을 확인한다. 원본 파일은 고치지 않았다.

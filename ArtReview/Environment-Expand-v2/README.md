## 방법

`Tools/ArtTrials/environment_expand_v2.py`가 현재 게임 렌더러 `goryeo_art.sprite`의 실제 해상도 결과를 기준으로 쓴다. 승인된 v2의 `gentle_cleanup.lua`를 변경하지 않고 gentle 설정 그대로 적용했다. 원래 색의 고립된 내부 픽셀만 이웃의 같은 계열색으로 바꾸며 불투명 픽셀의4%까지만 변경한다. 넓은 단색 면으로 다시 그리거나 팔레트 수를 강제로 줄이지 않았다.

모든 개체가96% 이상 원래 픽셀을 유지했고 크기·알파·실루엣은 동일하다. 새 색은 없다. 초가집은 본편에5×4칸과4×3칸 두 크기가 있어 각각의 기존 원본을 독립 보정했다. 큰 버전을 즉석 축소해 작은 버전으로 쓰지 않았다. 소나무 woodland0는 앞선 v2 표본을 이번에 다시 바꾸지 않았다. 숲 나무는 woodland1/2/3/4/6/7이다.

원본의 출처/크기는 `checks.json`. 기술 검사 원본 재열기/알파/팔레트/변경률·A2 결과는 미술 승인을 대신하지 않는다. D3 공통 팔레트는 새로 정하지 않았다.

## 실제 Unity 보기

**캡처 위치 오류:** 숲 화면의 플레이어 발 셀(개경7,50)은 나무 내부의 진입 불가 칸이다. 검토자의 강제 위치 설정 오류이므로 이 장면을 정상 플레이의 가림 재현 근거로 사용하지 않는다. C3a 후속 점검과 상세는 `Docs/Validation/Environment-Decision-2026-10-25.md`.

개경 Play(비시작 씬, 저장 꺼짐)에서 원래 타일을 메모리로 복제하고 후보의 온전한 개체를 기존16px 셀에 대응시켰다. 위치/크기/충돌은 유지했다. 개경6종334셀=19개체, 나루 작은 초가집24셀=2개체를 임시 표시했다. 실제 Game 캡처를 전후 같은 카메라/PPU16/Point로 촬영했다. 승인 전에 본편 PNG/타일/맵/씬을 저장하지 않았다. Play 종료 시 원래 게임으로 돌아간다. 사용하지 않은3종 숲 나무의 게임 배치/시각 검사는 아직이며 원본 비교/PNG 기술 검사만 했다.

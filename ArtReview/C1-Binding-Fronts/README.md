# C1 연결표의 새 역할 5명 정면

`Docs/C1-Binding.md`의 순서대로 지게꾼 porter, 시전 상인 merchant, 비단 장수 merchant_silk, 선비 scholar, 떡 장수 woman_ricecake를 만들었다. 전부 사용자 승인 대기다.

- `all-fifteen-fronts.png`: 윗두줄 승인10명, 아랫줄 새5명. 모두16×24를 같은6배/원래크기/실루엣으로 비교했다.
- `prop-variants.png`: 시전 상인/비단 장수, 아낙/떡 장수 소품 전후.
- `unity-game-1920x1080.png`: 실제 장단 Unity Game 화면 캡처. 맨왼쪽 플레이어, 이어서 승인10명, 오른쪽5명이 위의 새 역할 순서다. 기존 캡처에 합성한 그림이 아니다.
- 원본: 인물별16×24 PNG와 `.aseprite`. 생성/비교 원본은 `Tools/ArtTrials/npc_binding_fronts.py`.

지게꾼은 머리띠/빈 지게로 행상의 큰 짐과 구분했다. 시전 상인은 상투/조끼/장부, 비단 장수는 동일한 몸과 비단 두루마리, 선비는 넓은 유건/책, 떡 장수는 승인 아낙의 물동이 대신 쟁반을 쓴다. 상인 변형은 소품 범위(11~15,16~21) 밖 픽셀이 동일하다. 떡 장수는 물동이와 쟁반 범위 밖에서 승인 아낙과 픽셀 동일하다. 즉석 맵 변형이 아닌 별도 등록 에셋이다.

크기/알파/발밑·Aseprite 저장/재열기5쌍 확인. A2 기술 미리보기 오류0. `checks.json`, `manifest-report.json` 참고. 팔레트는 시안용이며 D3 전체 확정이 아니다.

현재 실제 Unity의 검토 오브젝트는 메모리에만 있다. PPU16·pivot(8,6)·scale1, autosave=false·sceneDirty=false·일시정지 확인. 본편 참조나 PNG/씬/데이터를 저장하지 않았다. 새5명의 걷기·본편 교체·이동/말걸기는 아직 진행하지 않았다.

다음: 정면 사용자 승인 → 새5명 걷기 → C1-Binding 역할별 경로로 전체 일괄 교체/동물 보관 → 맵 이동·말걸기/게임 화면 확인. 그다음 C2·C3 확대 → A3a → A4 → R2 계산 → B1 순서를 유지한다.

# 작업6 아이콘 수정안 v3 — 볏단·양모 그림 승인 대기

사용자 정정: 기존 스타일 선호, 직전 새 아이콘은 얄쌍함. 볏단 두께를 조금 더 늘림. 향신료는 이전 아이콘 유지. 양모는 기존 스타일에서 윗부분 중앙의 움푹 팬 곳만 보정.

- 곡식(grain): v2와 같은 이삭·색·높이를 유지하고 묶음 아래 몸통을 두껍게 수정했다. 내장 image_gen으로 v2 원화를 편집하고 Aseprite에서16×16 격자로 정리했다. 아래쪽 y10~14 불투명 픽셀22→26. ID/이름/무게/가격은 그대로다.
- 향신료(transit_spice): 사용자 선택에 따라11/03 v1 원본 전체를 그대로 채택했다. 원본과 디코딩 RGBA 차이0. 새 생성/윤곽 보정은 하지 않았다.
- 양모(transit_wool): 기존 Aseprite 원본에서 윗중앙 홈의(7,3),(8,3),(8,4)3픽셀만 수정했다. 기존 팔레트를 쓰고 나머지253픽셀은 원본과 완전히 같다. 기존 폭/높이/하단·끈·명암·전체 덩어리 유지.

Native에 전체16×16 PNG/Aseprite3쌍, Raw/grain.png에 생성 원화, prompts.json에 실제 프롬프트와 원본/픽셀 수정 기록이 있다. 재현은 Tools/ArtTrials/item_icons_v3_native.lua. 맵 생성 중 변형이나 부분 조각 사용은 없다.

native-comparison.png: 위 기존 스타일, 가운데 직전 시안v2, 아래 이번v3. 각10배와1배. inventory-comparison.png: 실제 Unity InventoryUI, 왼쪽v2/오른쪽v3. 검토 전용 ItemData 복사본만 표시했다. 실제 상품 등록/본편 아이콘 교체가 아니다. 본편 DB/곡식 원본/공용 UI·맵·씬과 상품ID/가격/저장은 유지했다.

향신료 v1 재사용 선택은 기록했고, 볏단/양모 v3는 사용자 그림 승인 전이다. 통나무·포구의 별도 승인 상태는 그대로다. 검증 결과 Docs/Validation/ItemIcons-v3-2026-11-04 참조. 사람이 직접 조작한 플레이·온라인·신규 품목 거래 검사는 하지 않았다.

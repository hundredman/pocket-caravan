# 북유럽 N1 지형: 승인 2026-10-28

원본: `Tools/MapGen/northworld/n1_terrain.py`. 방식은 고려 `Tools/WorldLayout/terrain_v3.py`와 같아: 높이 → 강 → 지형 종류 → 마을 범위 → 길 → 마을과 길 기준 맵 경계.
입력은 N0 결과(`ArtReview/North-N0/n0_masks.npz`, `n0_seeds.json`)야.

재현:
```
python3 Tools/MapGen/northworld/n0_layout.py Tools/WorldLayout/world-layout.json ArtReview/North-N0 <한글 폰트>
python3 Tools/MapGen/northworld/n1_terrain.py ArtReview/North-N0 ArtReview/North-N1 <한글 폰트>
```
시드는 고정이야. 검토 그림은 Noto Sans CJK로 만들었어. 승인한 그림의 해시는 `approval.json`에 있어.

**본토**
- 동쪽에 등뼈 산맥(빙하·만년설)이 있어.
- 얼음 동굴은 빙하 골짜기에 있어. 피오르 나루에서 눈 덮인 고개로 가.
- 라우가르에는 온천 호수가 있어. 순록 고원은 높고 평평한 툰드라야.
- 낮은 곳은 침엽수림이고, 해안은 피오르 바위 해안이야.

**중앙 북쪽**
- 침엽수림과 풀밭이고, 길목 마을과 개울 나루 근처에 밭이 있어.
- 북쪽 개울은 북문 동쪽 언덕에서 북동 바다로 흘러. 개울 다리길에서 다리로 건너.
- 눈숲 고갯길은 산을 깎은 고개야.

**다른 지역으로 나가는 자리** (region_links.json 번호)
- ① 베네치아 venice_c_vineyard: 눈숲 마을 서쪽 경계 (-101,-94)
- ⑨ 베네치아 venice_c_pass: 서남 솔숲길 서쪽 경계 (-79,-74)
- ⑩ 베네치아 venice_c_gate: 서남 솔숲길 남쪽 경계 (-49,-46)
- ⑪ 고려 transit_crossroads: 동남 물가길 남쪽 경계 (42,-40)
- ⑤ 한가운데 초원(아라비아 초원): 북쪽 길목 마을 남쪽 끝 (7,-8)
- (새로, 은샘 확인 전) 고려 북동 포구: 개울 다리길, 해안 쪽 경계 끝 (105,-127)

**나머지**
- 2026-10-29 수정(N2 하다가 결정): 북쪽 개울이 개울 나루 마을 옆을 지나가. 동남 물가길에 작은 연못과 개울을 넣었어.
- 2026-10-29 수정(N3 하다가 결정): 폭 2칸 이하인 띠는 옆 맵에 붙여. 라우가르 맵 북동쪽 1칸 띠를 정리했어.
- 맵 면적은 N0 목표의 85~120%야. 마을 둘레 6칸은 그 마을 맵에 들어가.
- 남은 점: 본토 마을끼리 가까워(사이 약 10칸). 북문 마을이 목 양옆 앞바다 띠를 가져가 있어.
- 길, 출입구, 구역 세부는 N2에서 맵별로 다시 다뤄.

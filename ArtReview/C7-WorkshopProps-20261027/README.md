## 대상·출처

모두 기존48×32/발밑31 캔버스를 유지한 별도 그림 후보다.

- **한지 건조대:** 현행 본편 `c6_paper_rack_665314e5`/3×2칸 틀과 종이3장을 새로 제작했다. 닥목에서12렌더칸 참조(완전한6칸 개체2개에 해당). 가시 윤곽43×30→43×23. 닥목의 별도4×3칸 `c6_goryeo_paper_7473141b` 건조대는 다른 원본이며 이번에 교체·제작하지 않았다.
- **수확 꾸러미:** `c6_goryeo_harvest_168ed569`를 기준으로 볏단·곡물 자루·바구니를 제작했다. 장단에서12렌더칸 참조. 가시 윤곽47×30→47×27. 밭·지형 타일로 사용하지 않는다.
- **청자 진열:** `c6_goryeo_celadon_54def069`를 기준으로 꽃병·뚜껑 항아리·그릇과 낮은 받침을 제작했다. 나루·개경에서 각6렌더칸 참조. 가시 윤곽46×30→37×30. 청자 역할을 유지하고 갈색 장독으로 바꾸지 않았다.

본편 원본/목록/맵에서 확인한 근거는 `source-usage.json`. 새 B3 마을의 배치·역할 연결은 이번 그림 검토와 별도다.

## 재현

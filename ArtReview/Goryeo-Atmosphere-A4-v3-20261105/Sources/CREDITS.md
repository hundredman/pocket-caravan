# A4 material-source audio

- Dirt: Kenney, RPG Audio, footstep07.ogg — CC0. https://kenney.nl/assets/rpg-audio
- Grass / stone contact / wood: Kenney, Impact Sounds, footstep_grass_000 / footstep_concrete_000 / footstep_wood_000 — CC0. https://kenney.nl/assets/impact-sounds
- Water splash: rubberduck, 40 CC0 water / splash / slime SFX — CC0. https://opengameart.org/content/40-cc0-water-splash-slime-sfx

Original primary pages were checked for licence. Primary zip downloads were unavailable, so the five public mirrored audio files were fetched at immutable Git commits; each downloaded file was checked against the inspected Git blob SHA-1. URLs/authors/source packs/hashes are in provenance.json. The water file is a processed mirror named wade.wav; its mirror credits map wade/wade1 to splash_12/splash_14 in the same CC0 pack. The exact original of that pair is not independently identified. https://github.com/PerpetualBeta/Citadel/blob/36249966ead30ea5e4e0eba9e9f0e7636d46992b/CREDITS.md

Only these five sound files were copied, not the mirrors' code/other assets. Whole audio retained, mono/22.05k conversion, gentle low-pass/DC removal, short endpoint fades and soft peak limiting. No new pitched hits or generic source substitution. Approval pending; no production audio replacement.

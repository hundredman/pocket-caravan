# 수레 첫 소품 시안 복원·기와집 용마루 청회색 정리

사용자 지시(2026-10-27): “수레는 바꾸지 않은 처음 버전이 더 나았어. 그리고 기와집의 윗 부분이 흰데 다른 기와 지붕들처럼 수정해줘.”

수레의 ‘처음 버전’은 처음 제출한 C7 소품 묶음(`C7-Batch4-20261027`)으로 해석해 해당 Aseprite·PNG를 픽셀 그대로 복원했다. 최초 게임의 동결 수레와는 구분한다. 실제 원본 경로는 selection.json에 남겼다. 새 수레 제작·추가 비례 변경 없음.

기와집은 직전 수정 원본에 청회색 용마루 레이어만 추가했다. 변경은 y10~15의 밝은 청회색 픽셀뿐이고 알파·실루엣·그 아래 기와 무늬·벽·문·기단은 그대로다. 가게·객주에서 쓰는 청회색을 따랐다. 기존 승인 원본이나 다른 건물을 덮어쓰지 않았다.

[비교판](comparison.png)은 왼쪽 직전 제출/가운데 복원·수정본/오른쪽 팀 참고와 실제1배다. 아래는 실제 Unity Play480×270 전후다. 본편 적용은 없으며 두 그림의 최종 확인 대기다. 우물·석등 자동 승인 없음.

재현: Aseprite 배치에서 `Tools/ArtTrials/c7_cart_roof_v2.lua`에 root(이 폴더), base(저장소)의 절대경로를 전달 → Pillow가 있는 Python으로 `c7_cart_roof_v2.py register` → 이 worktree Unity6000.3.26f1 `C7CartRoofV2Review.Run`(Burst 비활성·worker2) → Python `board`.

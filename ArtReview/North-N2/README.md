# 북유럽 N2 구역도 (검토용)

원본은 `Tools/MapGen/northworld/n2_zones.py`야. 자리 잡는 규칙은 고려 `Tools/WorldLayout/m2_zones.py`(은샘)의 Planner를 옮겨 와서 썼어.
- 건물 문에서 길까지 2칸 폭 골목이 24칸 이하로 이어지는 자리만 골라.
- 건물과 마당끼리는 1칸씩 띄워.
- 물가와 바닷가에 붙어야 하는 것은 그 조건을 지켜.

입력은 N1 결과(`ArtReview/North-N1/n1_grid.npz`)야.

재현:
```
python3 Tools/MapGen/northworld/n2_zones.py ArtReview/North-N1 ArtReview/North-N2 <한글 폰트> <지금 맵 객체 목록 json>
```

**색**
- 노랑: 장터 광장
- 주황: 이벤트 마당, 쉼터
- 빨강: 건물 (흰 칸은 문 앞)
- 하늘: 물가 자리
- 파랑: 배
- 흰색: 게시판, 우물, 룬석
- 분홍: NPC
- 연노랑: 횃불
- 초록 점: 성장 자리, 채집·사냥 자리
- 빨간 점: 이벤트
- 검은 점: 도적
- 갈색: 골목

**마을 (11곳)**
- 모든 마을: 장터 광장(시장), 게시판, 이벤트 마당, 집, 우물, 횃불, 성장 자리
- 마을별 건물:
  - 비르카: 얄의 장원, 여관, 상인 길드, 대장간, 훈련장
  - 순록 고원: 순록 우리, 썰매 공방
  - 모피 사냥꾼: 털옷 공방, 가죽 건조대
  - 피오르 나루: 항구 부두, 배 2, 창고, 대구 덕장
  - 라우가르: 목욕 회관(온천가), 꿀술 양조장
  - 얼음 동굴: 동굴 입구(산에 붙음), 광부 캠프. 시장 없음(지금과 같음)
  - 룬돌 언덕: 룬돌 원과 룬석 5. 시장 없음
  - 북문: 국경 표석, 천막 좌판
  - 눈숲: 썰매 창고, 장작더미
  - 개울 나루: 물방앗간, 나루터, 나룻배, 빨래터
  - 북쪽 길목: 여관, 상단 본부, 고려·베네치아·아라비아 좌판
- 집은 마을 범위 둘레 5칸까지 놓을 수 있어. 본토 마을이 좁아서 그렇게 했고, 고려는 범위 안에만 놓아.

**이동 구간 (5곳)**
- 쉼터 마당 7×5와 모닥불, 맵마다 시설이 하나씩 있어:
  - 나무꾼 오두막
  - 길손 역참과 룬돌 둥지
  - 숯가마
  - 물레방아(연못가)
- 채집·사냥 자리는 길에서 2~7칸 떨어진 곳이야. 땔감은 숲, 약초는 풀밭, 사냥은 숲·언덕, 낚시는 물가에 둬.
- 이벤트는 길 위에 14칸 넘게 띄워서 둬. 도적은 쉼터에서 먼 길 위야.

**없어지는 맵의 내용 옮김**
- 국경 고개 → 비르카 맵의 목 길가 '국경 초소'
- 피오르 길 → 피오르 나루 맵의 얼음 동굴 고갯길가 '피오르 고갯길 쉼터'

**ID**
- 지금 북유럽 맵의 시장·게시판 town ID, npc ID, 이름 있는 talker는 모두 같은 ID·이름으로 자리를 받았어.
- 검사 결과는 `check.json`의 `oldContentLost`에 있어 (비어 있음).

**남은 점**
- 피오르 고갯길가 낚시터는 물가가 없어서 못 잡았어. 얼음 낚시꾼은 쉼터 옆에 서.
- 출입구: 고려처럼 걸을 수 있는 맵 경계 칸을 전부 열어 (2026-10-29 결정, N4에서 고려 `m4_objects.seams` 방식으로). 길이 경계를 넘는 자리는 18곳이야.

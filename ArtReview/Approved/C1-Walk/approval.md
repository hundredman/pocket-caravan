# 10명 4방향·걷기 승인

2026-10-24 사용자: **“훨씬 낫다. 이대로 하면 좋을 것 같아.”**

옆머리 보완 후 제출한 좌우 전후 비교와 실제 Unity 걷기 화면을 기준으로 현재10명 전체의 dulr×4 걷기를 승인했다. 각16×24 PNG160개와 Aseprite10개를 이 폴더에 동결한다. sha256.json이 원본 해시다.

미술 승인 범위는 이10명의 현재 프레임이다. 기존 주민 직업과 새 그림의 연결이나 추가 역할을 임의 결정한 승인은 아니며, 본편 교체/이동/상호작용 검증 완료도 아니다. D3 팀 팔레트 전체 확정은 별도다.

2026-11-15 도적 다시 그림 (은샘 승인 “a, b, c 다 좋은데? 종류별로 사용하자.”, 목 부분 보완 요청 반영):
삿갓이 떠 보이고 옆모습이 어색하던 도적을 같은 틀로 다시 그렸다. `frames/bandit_*`는 A안(패랭이 + 복면)으로 바꾸고 sha256.json을 고쳤다.
B안(상투 + 붉은 머리띠 + 복면)·C안(패랭이 + 텁수룩 수염)은 `Assets/PocketCaravan/Resources/Bandit/Looks/`에 있고, 맵마다 `BanditLook`이 고른다.
`bandit.aseprite`는 예전 그림 그대로다 (PNG가 기준).

2026-11-15 패랭이·갓 보완 (은샘 "일단 다 수정해줘"): 행상(trader)·농부(farmer)의 패랭이가 떠 보여 머리에 닿게 낮추고 챙 아래 그늘 줄을 넣음, 옆모습 챙은 머리 가운데에. 닥목 촌장(dakmok_chief) 갓에 챙을 닮. 앞·뒤 챙은 좌우 대칭. 정면 승인본(`*-front-c1-expand-*.png`)도 새 d0로 맞춤. `.aseprite`는 예전 그림 그대로 (PNG가 기준).

2026-11-16 닥목 촌장 탕건 (은샘 3번안 선택, 옆모습 보완 요청 반영): 갓 챙을 빼고 원래 설계인 탕건으로. 위 좁고 아래 넓은 두 단, 말총 점무늬, 옆모습은 뒤가 솟음. 옆모습 이마를 한 칸 올리고 모자 아래 빈 곳을 머리카락으로 채움.

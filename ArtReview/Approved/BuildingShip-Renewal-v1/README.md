# 건물·배 리뉴얼 승인본

2026-10-28 사용자 **“좋다. 모두 승인할게.”**로 제출한 건물9종·배1종 전체를 승인했다.

PNG/Aseprite10쌍과 크기·디코딩RGBA 지문은 approval.json에 동결했다. 건물은 지붕 윗면과 앞면이 보이는 시점, 배는 낮은 각도에서 선체 옆면이 드러나는 시점이다.

본편/A2 연결 시 이 파일을 기준으로 사용한다. 현재는 그림 승인·동결까지 완료했고 본편 교체·전체13맵 가림/충돌·실제 플레이 확인은 아직 하지 않았다. 이전 승인 원본은 보관했다.

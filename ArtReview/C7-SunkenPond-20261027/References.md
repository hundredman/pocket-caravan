# 연못 참고 재검토 (2026-10-27)

사용자가 v12 그늘 위치·테두리·모양을 거절했다. 이전 기술 검사 통과는 그림 승인과 무관하다. 다음 제작 전 형태와 지면 경계부터 재검토한다.

## 직접 확인한 제작자 공개 장면

1. Game Endeavor, Mystic Woods, Water Decorations (16×16, Top-Down).
   https://game-endeavor.itch.io/mystic-woods/devlog/336576/water-decorations
   이미지 https://img.itch.zone/aW1nLzc5MDkxMjAuZ2lm/originalm/4Uknq8.gif
   실제 브라우저에서 확인: 넓고 평평한 수면, 완만한 굴곡과 들어간 부분을 가진 지면 구멍. 화면 위쪽 둑의 흙 단면이 더 두껍고 아래쪽 경계는 얇다. 그림체의 단순함은 두 후보 중 팀 목표에 더 가깝다고 판단한다.
2. PixiVan, Top Down Forest Tileset (16×16).
   https://pixivan.itch.io/top-down-forest-tileset

   제작자 페이지는 브라우저522, 웹 도구에서는 본문 확인. 공개 원본 이미지는 브라우저에서 직접 확인했다. 높은 쪽 풀 아래 흙/그늘, 바로 아래 가는 수면선, 넓은 평면 수면이 분리된다. 잔 질감은 팀 목표보다 많아 경계 구조만 참고한다.

## 제작 판단 (아직 새 그림 승인 아님)

v12는 물을 길쭉한 타원 개체로 만들고 안쪽 색면을 타원처럼 겹쳐 그릇/대야처럼 읽힌다. 밝은 띠를 둘레에 반복하고 큰 어두운 면을 위쪽에 둔 것은 땅 단면과 물속 깊이를 혼동시킨다. 위 참고작처럼 지형에 난 구멍을 먼저 설계하고, 둑 단면과 바로 밑 좁은 그림자를 분리한다. 수면은 대체로 한 평면으로 두고, 빛 방향은 현 게임 주변 에셋과 맞춰야 한다. 참고작의 위쪽 둑 표현은 카메라에서 보이는 단면이며 그 자체를 광원 방향으로 단정하지 않는다.

원본 복제/재배포/게임 도입 없음. 외부 이미지를 저장소에 다운로드하지 않고 출처와 관찰만 기록했다. 스타일 최종 기준은 여전히 팀 베네치아·아라비아이며 참고작은 시점·물가 구조 비교용이다.

# 볏단 두께·긴 청자 입구 정리

사용자 요청: 작은 물품 구성은 유지하면서 홀쭉한 볏단과 번진 긴 청자 윗부분을 수정한다.

새 AI 생성·재샘플링·전체 축소·팔레트 변경 없이 기존48×32 Aseprite 원본을 네이티브 도트로 수정했다. 이전 편집 레이어는 숨김으로 보존하고, 온전한 개체 수정 레이어와 외곽선 레이어를 추가했다.

- **수확:** 작은 볏단의 묶인 몸통과 노출 줄기에 두께·금색 결을 보강했다. 변경84픽셀은 x8~27/y16~28 영역 안이다. 전체 가시 윤곽41×24/발밑31 유지.
- **청자:** 긴 병의 넓은 검은 번짐을 지우고 입구 테두리·어두운 안쪽·좁은 목을 정리했다. 외곽선 연결을 포함한 변경23픽셀은 x11~16/y7~13 안이다. 다른 병·항아리·그릇·받침은 이 영역 밖이므로 픽셀 그대로다. 전체39×24/발밑31 유지.
- **건조대:** PNG/Aseprite를 이전 폴더에서 그대로 복사했다. 재생성·크기·색 변경 없음. 건조대 크기 수용 의견만 기록하고 전체 그림 승인으로 확대하지 않았다.

두 수정 영역 밖의 모든 픽셀 동일성을 검사했다. [원래 게임/직전/수정안 비교와 실제1배](style-comparison.png), [최신 Unity Play 전후](game-comparison.png). 승인 성문/건물/인물/지형/연못은 양쪽 동일하다. 본편·기존 승인본·수레·ID·저장·충돌 미변경·수정안 확인 대기다.

재현: Aseprite 배치에서 `Tools/ArtTrials/c7_workshop_props_v3.lua`에 root(이 폴더 절대경로), base(저장소 절대경로) 전달 → Pillow Python `Tools/ArtTrials/c7_workshop_props_v3.py register` → 이 worktree Unity6000.3.26f1 `C7WorkshopPropsV3Review.Run`(Burst 비활성·worker2) → Python `board`. 건조대 원본은 v2/Native에서 그대로 복사한다.

새6+직전 기록5=11검사 통과. A2검토0오류·미승인본편거부/전체18렌더칸 재조합·누락거부/기존색·이진알파·발밑·외곽선/Aseprite 실제 재출력RGBA/건조대·승인본 보존/수정 영역 밖 동일성 확인. Unity Play480×270 before는 직전trial과 디코딩RGBA 일치, 변화는 수확/청자 영역만이며 불투명 원본/화면RGB오차≤1. Unity 종료0·C# 오류0/SearchDatabase 예외0.

# 원본 보존 보정 v2 · 사용자 검토 대기

사용자 지시: 비교 그림 왼쪽의 기존 게임 아트가 기준. 과도하게 단순화한 v1은 반려. 원본의 형태·색·명암·질감을 유지하고 픽셀 느낌만 살짝 정리한다.

- `environment-comparison.png`: 원본 / 아주 약하게 / 약하게. 기와집은 원본 픽셀 98% / 96%, 소나무는 99.78% / 97.26%를 그대로 유지했다(불투명 픽셀 기준). 캔버스·모든 알파·실루엣은 완전히 같다. 새 색을 만들거나 색 수를 강제로 줄이지 않았다.
- `npc-comparison.png`: 기존 캐릭터 생성기의 몸·옷·색 테두리·음영을 유지하며 사람 얼굴과 역할 소품을 넣은 정면 3명 시험이다. v1의 단색 도형 몸을 재사용하지 않았다. 방향·걷기 전체는 이번에 갱신하지 않았고, 정면 그림체 확인이 먼저다.
- `game-comparison.png`: 각 480×270 기존 게임 캡처에 후보를 합성했다. 교체 후 Unity 캡처나 플레이 검사가 아니다. 환경은 '약하게' 보정을 사용했다.
- 원본: 환경 4개 `*-micro.aseprite`, `*-gentle.aseprite`, NPC 3개 `NPC/*-front.aseprite`. 모두 본편 밖에 있다.

환경 최종본은 `Tools/ArtTrials/gentle_cleanup.lua`로 Aseprite 안에서 원래 64×48 픽셀을 직접 보정했다. 가장자리·알파를 건드리지 않고, 주변과 유사하지만 홀로 고립된 내부 색 픽셀만 원본의 이웃 색으로 바꿨다. 아주 약하게는 최대2%, 약하게는 최대4%까지만 변경한다. 격자 크기를 키우거나 큰 면으로 뭉개지 않는다.

NPC는 `Tools/ArtTrials/native_npc_refine.py`로 기존 `chars.py`/`chars_human.py`의 실제 해상도 렌더러와 색을 사용했다. AI 검토안은 원본의 형태 변화 또는 16×24로 줄였을 때의 정보 손실이 커서 최종본으로 채택하지 않았다. 도구/프롬프트 기록은 `PROCESS.md`에 있다.

**본편 미반영.** 기술 검사는 미술 승인과 다르다. 상태는 모두 pending이며 D3 공통 팔레트를 새로 확정하지 않는다. R6·Q1·A5 코드, 저장, ID, 맵과 씬은 이번 수정에서 바꾸지 않았다.

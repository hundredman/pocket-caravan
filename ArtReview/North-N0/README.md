# 북유럽 N0 땅 모양: 구조 결정 2026-10-28

원본: `Tools/MapGen/northworld/n0_layout.py`. 고려의 `Tools/WorldLayout/world-layout.json`(중앙 대륙 땅, 고려와 중앙 동쪽 구역)을 읽기만 해. 좌표는 Docs/WorldLayout.md를 따라.

- 본토는 피오르 반도 모양이야. 좁은 목(국경 고개)으로 대륙에 붙어. 7개 맵, 20,000칸(앞바다 포함).
- 중앙 북쪽은 12시 방향 ±47°야. 고려 동쪽 구역은 빼. 9개 맵(마을 4, 이동 구간 5), 25,000칸.
- '피오르 길'과 '국경 고개'는 없어지고 비르카와 피오르 나루에 들어가. 예전 세이브 위치는 합쳐진 맵으로 옮겨.
- 고려 '북동 포구' 연결 자리(70,-150)는 개울 다리길과 이어.
- 맵 경계는 아직 면적만 맞춘 직선이야. N1에서 지형, 마을, 길에 맞춰 다시 그어.

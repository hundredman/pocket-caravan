# 풀밭 위 연못 맥락 확인 · 제안 검토 대기

2026-10-27 사용자는 원래 지형을 선택했고, 연못은 개경의 벽돌/포장 바닥 전용처럼 보이므로 풀밭 배치 시 수정이 필요하다고 지적했다.

## 확인 결과

기존 [A4 승인 범위](../../Approved/A4-Pond/approval.md)는 **개경22칸/11조합과 기존 돌마당·연꽃**이다. 다른 배치는 별도 검토 대상으로 명시돼 있다. 물 모듈 자체는 물·얕은 물색·갈색 물가·투명 부분으로 구성돼 있으며 벽돌 그림을 포함하지 않는다. C7 시험 도구가 CSV의 `goryeo_paving_*`를 연못 아래에 그대로 깔아 투명한 바깥 부분에 회색 포장이 보였다.

이전의 “연못 수정 불필요” 의견은 풀밭의 배치 맥락까지 확인한 판단으로 사용하지 않는다. 개경용 승인본은 그대로 보존한다.

## 이번 확인본

[실제 Unity 비교·부분 확대](comparison.png). 양쪽 모두 원래 지형과 승인 건물·인물을 사용한다. 왼쪽은 개경 포장을 포함하고 오른쪽은 포장을 빼서 기존 풀이 보이게 했다. **물색·모양·물가 그림을 수정하지 않은 맥락 확인본**이며 자연형 연못 완성안이나 배치 승인으로 처리하지 않는다.

검토에 쓰던 위치가 길에 걸쳐 있어 양쪽 연못을 같은 위치에서2칸 남쪽으로 옮겼다. 기존22칸 중 첫 번째 완전한 연못11칸만 사용했다. 나머지 동일 연못은 화면 밖이므로 제외했다.11칸 모두 시험장의 길 밖 풀 칸임을 정적으로 확인했다. 실제 B3 배치/보행 검사는 아니다.

- 실제 Unity previewOnly Play480×270 전후 재촬영, 같은 카메라/PPU16/Point, 종료0.
- 물11조각의 불투명 픽셀1928개, 건물2개와 나무는 전후 차이0. [증거](checks.json).
- 관련팀스타일5검사 재실행 통과. [결과](../../../Docs/Validation/C7-TeamStyle-2026-10-27/terrain-choice-tests.txt).
- 기존 Unity SearchDatabase 인덱싱 예외1회. 전체 통합·실제보행·수동플레이·저장회귀·게임빌드는 실행하지 않았다.

물 PNG/Aseprite 원본, 개경 승인 기록, 본편은 변경하지 않았다. 풀밭에 연못을 실제로 넣을 때에는 자연스러운 물가/둑 및 형상도 필요한지 별도 그림 검토를 받는다. 원래 지형 유지 결정은 [기록](../GroundOrigin-v7/decision.md)에 있다.

`PondContext-v8`은 위치가 길에 걸쳤던 내부 확인 이력이다. 최종 비교는 이 `PondContext-v9`만 사용한다. `C7PondContextReview.Run`이 Unity 촬영, `c7_pond_context_review.py`가 비교와 픽셀 검사를 재현한다.

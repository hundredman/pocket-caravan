# Task6 승인 기록 확인 — 별도 그림 승인 대기

작업5의 승인 “그래.”는 네 전용 좌판/두 마을 배치에 대한 것이다. 작업6의 별도 그림은 원본 README/manifest/handoff 및11/04 지시문에서 미승인으로 명시돼 있다. 이후 볏단·향신료·양모 아이콘은 개별 승인·본편 연결을 완료했다. 포구 수정은 후속 사용자 승인으로 본편 적용 완료(ArtReview/PortWater-Task6-20261104), 통나무는 기존 가로+추가 각도 v3(ArtReview/LogAngles-v3-20261104) 네 방향 그림 승인·초원 진입로 숲길 사선1곳 본편 연결 완료다. 승인된 별도 범람 지형은 이미 본편 연결 완료이며 이 목록과 다르다.

- 길막음용 통나무48×48: ArtReview/E3-E2-Art-20261103/Native/fallen_log.png. 기존 숲 장식3×2 통나무와 별도 용도다.
- 아이콘16×16: 볏단 v3·향신료 v1·양모 폭12px v4를 사용자 승인 후 본편에 연결했다. 향신료/양모 신규 상품 등록 및 거래·저장 검사를 완료했고 수익 수치는 Claude 검토 메모로 남겼다. 최신 양모 적용 검사는 Docs/Validation/WoolWidth-Applied-2026-11-04.
- 남동 포구·버들나루 바다 빈 모서리: 막혀 있는 바다 배경만 기존 수면으로 채우는 검토. 해안/출구/통행을 바꾸는 승인이 아니다.
- 버들나루 잔물결: 기존 goryeo_ripples 참조를 써서 불투명 청색 바탕을 없애는 검토. 공용 ripples/기존 프레임의 색·알파는 바꾸지 않는다.

assets-review.png는 수정 요청 전의 기존 PNG3개를 실제크기/정수확대로 배열하고,11/03 Unity log/item-ui 원본 캡처를 변형 없이 묶은 것이다. 상품 UI는 검토용으로 실제 신규 상품 등록 화면이 아니다. 포구 비교도 원본 ArtReview/E3-E2-Art-20261103/review-ports.png(11/03 촬영)를 그대로 보여 준다. 최신 본편/현재 장터 캡처로 표시하지 않는다. 이 문단의 과거 검토 그림 자체를 최신 적용 화면으로 취급하지 않는다.

반려된 별도 범람 PNG2개는 승인 요청·연결 대상에서 제외한다. 사용자 그림 승인 뒤 최신 원본/씬에 연결하고 실제 본편 화면·거래·사건/재진입·저장을 검사한다. 이 문단은 최초 제출 상태다. 최신 포구는 적용 완료, 통나무 v2는 미채택·v3도 미적용이다.

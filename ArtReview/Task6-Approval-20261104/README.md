# Task6 승인 기록 확인 — 별도 그림 승인 대기

작업5의 승인 “그래.”는 네 전용 좌판/두 마을 배치에 대한 것이다. 작업6의 별도 그림은 원본 README/manifest/handoff 및11/04 지시문에서 미승인으로 명시돼 있다. 이번 대화에서 이를 개별 승인한 기록은 확인하지 못했다. 승인된 별도 범람 지형은 이미 본편 연결 완료이며 이 목록과 다르다.

- 길막음용 통나무48×48: ArtReview/E3-E2-Art-20261103/Native/fallen_log.png. 기존 숲 장식3×2 통나무와 별도 용도다.
- 향신료/양모 아이콘16×16: 사용자 수정 요청으로 v1 대신 ArtReview/ItemIcons-v2-20261104의 수정안을 검토한다. 같은 묶음에 기존 곡식 자루→볏단 아이콘도 추가했다. 아직 본편 아이콘을 바꾸거나 상품을 등록하지 않았다. 승인 후 작업 지시6번과 E2-CentralMarkets.md의 기존 수치 초안에 따라 연결/등록/거래 검사를 진행한다.
- 남동 포구·버들나루 바다 빈 모서리: 막혀 있는 바다 배경만 기존 수면으로 채우는 검토. 해안/출구/통행을 바꾸는 승인이 아니다.
- 버들나루 잔물결: 기존 goryeo_ripples 참조를 써서 불투명 청색 바탕을 없애는 검토. 공용 ripples/기존 프레임의 색·알파는 바꾸지 않는다.

assets-review.png는 수정 요청 전의 기존 PNG3개를 실제크기/정수확대로 배열하고,11/03 Unity log/item-ui 원본 캡처를 변형 없이 묶은 것이다. 상품 UI는 검토용으로 실제 신규 상품 등록 화면이 아니다. 포구 비교도 원본 ArtReview/E3-E2-Art-20261103/review-ports.png(11/03 촬영)를 그대로 보여 준다. 최신 본편/현재 장터 캡처로 표시하지 않는다. 기존 시안을 다시 제작하거나 본편에 넣지 않았다.

반려된 별도 범람 PNG2개는 승인 요청·연결 대상에서 제외한다. 사용자 그림 승인 뒤 최신 원본/씬에 연결하고 실제 본편 화면·거래·사건/재진입·저장을 검사한다. 지금은 적용 전이다.

- 최신 프레임·태그가 있는 Aseprite10개·시트·방향표·걷기GIF는 `../C1-Walk/`에 갱신했다. `../C1-Walk/unity-walk.gif`는 수정 후 실제 Unity 화면16장을 새로 촬영한 것이다.

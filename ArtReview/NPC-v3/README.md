# 사람 NPC 얼굴 수정 v3 · 사용자 검토 대기

사용자 피드백: 동물 캐릭터는 괜찮으나 사람으로 바뀌면서 어색함. 건물·나무는 긍정적이므로 이번에는 사람만 수정한다.

- `comparison.png`: 왼쪽 동물 기준 / 가운데 이전 사람 / 오른쪽 수정 사람. 같은 16×24, 같은 확대 배율이다.
- `game-comparison.png`: 각 480×270의 실제 기존 캡처에 검토용 합성. 두 화면의 건물/나무는 같은 v2 이미지를 썼다. 새 Unity 교체 화면이나 플레이 검사가 아니다.
- `chief-front`, `woman-front`, `trader-front` PNG와 Aseprite 원본. 기존 동물 그림·건물·나무·본편 Assets/는 변경하지 않았다.

이전 사람의 네모난 피부 면과 머리카락 테두리, 가로 흰 띠처럼 보이던 수염, 물동이/손의 단절을 원인으로 보고 수정했다. 이는 제작자의 분석이며, 사용자 미술 판정을 대신하지 않는다. 얼굴 중간을 둥글게 하고 귀/턱을 줄였으며, 눈 위치를 맞추고 눈동자·코·입을 분리했다. 수염은 입 둘레와 턱으로 나눴고, 물동이는 들어 올린 손과 연결했다. 몸·옷의 원래 캐릭터 음영 방식은 유지했다.

`Tools/ArtTrials/npc_faces_v3.py`가 기존 네이티브 도트 렌더러로 제작한다. `review_npc_v3.py`가 비교 그림과 게임 크기 합성을 생성한다. 정면 그림체 확인용 3명이며 걷기/다른 방향은 이번에 갱신하지 않았다. 본편 적용·사용자 승인·Unity 임포트/플레이는 대기다.

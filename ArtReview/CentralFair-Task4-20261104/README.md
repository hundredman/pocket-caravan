# Task4 큰 장 좌판 시안 — 승인 대기

기존 곡물 좌판을 참고해 큰 장 날용 남색·청록 좌판2개를 제작했다. 내장 image_gen 사용, 프롬프트/참고는 prompts.json, 생성 원본은 Raw, 실제48×48 PNG/Aseprite는 Native. 오프라인 Aseprite에서 전체 오브젝트를 정리했고 조각을 잘라 붙이지 않았다. 정식 이미지나 본편 씬은 바꾸지 않았다.

솔재 길목과 버들나루의 기존 곡물 좌판4개씩에 두 종류를 번갈아 쓰는 검토다. 장터와 이벤트 마당에 적용하며, 평상시에는 기존 승인 그림을 그대로 쓴다. 잡화 판매대·충돌·출구·기능 객체는 유지한다. 큰 장 공용 날짜/2할 보너스/대상 마을 배열은 변경하지 않는다. 남동 포구·교역 길목 순환 추가는 기우 확인 대기로 그대로 둔다.

비교 그림 왼쪽은 평상시, 오른쪽은 큰 장 날이다. Unity 실제 Play960×540 캡처6장을 변형 없이 묶었다. 큰 장 안내 띠와 일부 NPC/게시판 이름의 겹침은 기존 공용 UI이며 이번 시안 변경 대상이 아니다.

실제 날짜1/2로 번갈아 진입하여 공용 IsFairMap 일정, 각 마을4개 전체 좌판/네이티브 크기/저장 차단 등 자동 Play39확인 통과. 기존 저장9파일 백업/불변. 최초 촬영의 버들나루 캐릭터 위치가 막힌 칸이라 검토 도구를 인접 보행 가능 칸 탐색으로 수정 후 재촬영했다. 사람이 직접 조작한 플레이/온라인 검사는 하지 않았다.

검토 씬: Assets/PocketCaravan/Editor/B2Preview/CentralFair20261104 (무시되는 previewOnly 복사본). 생성/재현 CentralFairTrialReview.Build/Run 및 CentralFairTrialPlayReview. 승인 후 본편 동쪽 전용 표시 연결을 진행한다.

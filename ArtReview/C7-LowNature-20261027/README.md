# C7 낮은 자연물4종

## 대상과 원본

현행 C6 동결 목록의 woodland8~11을 그대로 용도·크기 참고로 사용했다. 원본 ID/목적/참조 맵별 렌더칸 수는 source-usage.json.

- 이끼 낀 바위: woodland8/48×32. 가시 윤곽45×30→45×29. 돌 면이 드러나고 이끼와 작은 잎이 가장자리에 모인 형태.
- 낮은 관목: woodland9/32×32.30×21→30×20. 낮은 잎 덩어리로 나무와 구분.
- 키 큰 풀숲: woodland10/32×32.29×27→27×27. 긴 잎과 작은 씨방 줄기, 수확 볏단으로 바꾸지 않았다.
- 쓰러진 고목: woodland11/48×32.41×30→40×30. 원본의 사선 방향과 배경 개체 용도 유지. 제거 가능한 퀘스트 장애물·다리·길로 사용하지 않는다.

모두 발밑31·PPU16·기존 캔버스를 유지했다. 각 AI1회(원래 형상/용도, 승인 버드나무·팀 자연물 스타일 참고)→온전한 개체 균등 최근접→A5 후보색(자연7/바위10/풀9/목재9)→Aseprite 원본·네이티브 외곽선. 기존 승인 자연색을 기본으로 하며 D3 공통 팔레트 결정은 아니다.4개체 전체20렌더칸 등록·조각 단독 재사용 없음.

[확대·실제1배·팀 비교](style-comparison.png), [실제 Unity Play 전후](game-comparison.png). 승인 성문·기와집·객주·가게·버드나무·인물·지형·연못은 양쪽 동일한 검토 시험장이다. 본편·승인 원본·수레·ID·저장·충돌은 미변경. 네 그림 각각 사용자 승인 대기다.

## 누락 점검

`Tools/ArtTrials/c7_remaining_audit.py`로 현행 C6 **온전한 개체 PNG47개에 한정한** 그림 검토 대조표를 만들었다(`whole-object-review-audit.json`). 승인 후보 파일과 승인 기록의RGBA를 확인하고 크기 일치를 별도로 표시한다. 같은 용도 후보가 있어도 아직 개별 ID/발밑/배치·충돌 연결을 구현한 것이 아니다.

배·볏단 단품2색·빨래대·별도 큰 나무 변형·작은 가게·별도 바위·벤치·연꽃 등12개 원본에 역할/변형 검토가 남아 있다. 이47개 표에는 단일 칸 소품·조립형 지형·캐릭터·연결 미확인 벚나무·신규 성문이 포함되지 않으므로 C7 전체 완료표가 아니다. 벚나무 원본 연결과 성문 통행/담장·가림 판단도 별도다. 비슷한 이름이나 큰 그림을 줄인 것만으로 승인·연결을 추정하지 않았다.

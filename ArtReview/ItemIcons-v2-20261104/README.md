# 작업6 아이콘 수정안 v2 — 사용자 수정 요청·보관

사용자 요청: 양모 디자인 수정, 곡식 그림을 볏단으로 변경, 향신료 아래의 네모 같은 모양을 살짝 수정.

- grain: 기존 곡식 자루 대신 묶은 황금색 벼 이삭/줄기. 상품 ID grain·이름 곡식·기존 무게/가격을 바꾸는 작업이 아니다.
- transit_spice: 주황색 향신료·밝은 주둥이·끈을 유지하고 아래 모서리를 안으로 모아 둥근 천 주머니 윤곽으로 수정.
- transit_wool: 두 단처럼 보이던 덩어리를 둥글고 부드러운 아이보리 양모와 휘어진 끈으로 다시 제작.

내장 image_gen으로 제작했다. 전체 입력 프롬프트/참고 파일은 prompts.json, 생성 원본 Raw, 실제16×16 PNG/Aseprite는 Native. Tools/ArtTrials/item_icons_v2_native.lua에서 전체 개체를 최근접으로 옮기고 기존 아이템 팔레트+볏단 황금색으로 정리했다. 이진 알파, 부분 잘라 쓰기/맵 생성 중 변형 없음. 기존 본편/검토 v1 원본을 덮어쓰지 않았다.

native-comparison.png 위 기존/아래 수정안(10배 및1배). inventory-comparison.png 왼쪽 기존/오른쪽 수정안, 실제 Unity Play의 기존 InventoryUI960×540 캡처. 소금은 크기 기준으로 그대로 넣었다. 검토 전용 씬/일시적 ItemData 복사본의 아이콘만 바꿨고 DB·신규 상품/재고는 등록하지 않았다. 저장 차단·실제 창 열기·아이콘 규격·본편 DB/곡식 원본 유지 등 자동 Play12확인·저장9파일 백업/불변 확인.

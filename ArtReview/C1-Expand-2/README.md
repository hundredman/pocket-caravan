# C1 확대 2단계 — 나머지 NPC 7명 정면

사용자 “좋다. 사이즈도 좋은 것 같아. 이어서 진행하자.”에 따라 촌장·행상 정면과 실제 게임 내 크기를 승인 기록으로 동결하고, ArtBrief의 나머지 7명 정면을 제작했다.

| 순서 | 역할 | 구분 요소 |
|---|---|---|
| 1 | 장단 농부 | 패랭이, 걷은 소매, 베옷·흙빛 바지, 볏단 |
| 2 | 송악 약재상 | 복건, 초록 옷, 약초 보따리 |
| 3 | 닥목 촌장 | 작은 탕건, 회색 머리, 갈색 옷, 종이 두루마리 |
| 4 | 개경 객주 | 갓, 넓은 몸, 푸른 도포, 장부 |
| 5 | 아이 | 작은 키, 댕기, 색동 소매, 팽이 |
| 6 | 뱃사공 | 수건 머리띠, 하늘색 옷, 노 |
| 7 | 도적 | 패랭이, 눈 아래 복면, 어두운 옷, 몽둥이 |

- `comparison-1.png`, `comparison-2.png`: 기존 동물 / 새 사람 / 승인 아낙을 같은 6배 확대와 원래16×24로 비교. 사람 옆 실루엣도 포함했다.
- `unity-game-before-1920x1080.png`, `unity-game-after-1920x1080.png`: 실제 장단 씬 Play의 Game 화면. 왼쪽 플레이어는 그대로, 오른쪽7명은 위 표 순서. 전후 동일 위치·카메라·PPU16·pivot(8,6)·scale1이다. 뱃사공은 뒤 석등과 겹쳐 보이지 않도록 x42.75에 두었다.
- PNG와 Aseprite 원본7쌍. `Tools/ArtTrials/npc_expand_remaining.py`가 생성 및 비교 그림 원본이다. `checks.json`과 `manifest-report.json`은 기술 검사 기록이다.
- 아낙과 승인된 촌장·행상 표본은 변경하지 않았다. 새7명은 전부 사용자 검토 대기. D3 전체 팔레트 확정은 아니다.
- 이번 제출은 **정면 역할 시안**이다. 아이의 비교 동물은 크기/스타일 비교용 여우 주민이며 실제 주민 ID를 아이로 바꾸지 않았다. 기존 주민 이름/직업(비단 장수·짐꾼·선비·뱃사공·떡 장수)과 ArtBrief의 새 역할 표는 완전히 일치하지 않으므로 본편 배정 전에 Claude 검토가 필요하다. 기존 NPC·주민·행동 데이터는 그대로다.

실제 Unity에서는 검토 PNG를 메모리로만 읽어 임시 정지 인물을 표시했다. 프로젝트의 PNG·메타·씬은 저장하지 않았다. autosave=false, sceneDirty=false 확인. Play를 종료하면 원래 씬으로 돌아간다. 이동/상호작용/방향·걷기 검사는 아직 하지 않았다.

재현: `PYTHONDONTWRITEBYTECODE=1 python Tools/ArtTrials/npc_expand_remaining.py` (Pillow·로컬 Aseprite 필요).

다음은 7명 정면 사용자 승인 후 4방향·걷기 제작/검토다. 본편 적용은 그 이후이며 동물 그림은 보관한다.

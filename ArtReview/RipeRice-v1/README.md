# 땅에 심는 익은 벼 포기

**색/포기 폭 수정 요청으로 v2 검토 중·본편 미적용.**

요청: 익은 벼 묶음을 다른 식물처럼 땅에 심는다. 수확해 끈으로 묶은 볏단과 구분해, 한 밑동에서 자라는 줄기·잎과 황금빛으로 고개 숙인 벼 이삭을 그렸다.

- rice-ripe.png / rice-ripe.aseprite:32×32 캔버스·PPU16 기준. 실제 불투명 영역26×25, 기존 풀 포기는27×27. 알파0/255,11색.
- comparison.png: 기존 풀 포기 / 새 익은 벼를 같은8배로 비교한다.
- unity-480x270.png: 기존 캐릭터·기존 풀·벼1포기와 반복 식재24포기를 Unity Edit 모드에서 같은 도트 크기로 배치했다. 실제 논맵 설계나 본편 적용은 아니다.
- 내장 imagegen 원화 ripe-rice-ai.png, [프롬프트](prompt.txt). 참고는 기존 풀 포기(그림체/크기)와 수확 작물(황금색)이며 수확물의 묶인 형태를 복사하지 않았다.
- prepare.lua: 개체 전체를 균일 비율로 native 격자에 NEAREST 샘플링, 기존 C7 계열 황금/올리브 시험 팔레트·이진알파 정리. 원본 식물을 자르거나 변형해 재사용하지 않았다.
- unity-review.cs.txt는 재현용 MCP 메서드 본문. 임시 메모리 씬에서 촬영 후 원래 씬으로 복귀했고 본편/승인 원본 쓰기0.

정적 크기·알파·색수, Aseprite 재출력의 디코딩 RGBA 일치를 검사했다. 게임 배치/A2 본편 등록·충돌·바람 애니메이션·실제 플레이·빌드는 하지 않았다. 이 그림은 작물 개체이며 상품 아이콘이나 연결용 땅 타일이 아니다.

후속 사용자 수정 요청에 따른 현재 그림은 [벼v2](../RipeRice-v2/README.md)와 [논v2](../RiceField-Tiles-v2/README.md)다. 이v1은 이전 비교용으로 보존한다.

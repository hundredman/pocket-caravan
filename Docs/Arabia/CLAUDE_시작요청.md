# Claude에 붙여 넣을 첫 메시지

이 폴더는 Unity 게임 Pocket Caravan의 아라비아 지역 개발용 복사본입니다. 먼저 루트 CLAUDE.md와 Docs/Arabia/STATUS.md, Docs/Arabia/02_지역설계_및_첫구현명세.md를 읽어 주세요.

계획만 다시 만들지 말고 실제 씬과 코드를 구현해 주세요. 현재 아라비아 씬은 아직 없으며, 기존 게임 소스만 복사된 상태입니다. 첫 목표는 알 아흐사↔농원길↔자비드의 별도 씬3개에서 Q1 배달과 Q2 구매 후 납품이 완주되는 것입니다.

기존 고려 씬·데이터와 ID/GUID가 충돌하지 않게 하고, 원본 프로젝트는 보존해 주세요. 추가 GitHub 연결이나 원격 업로드 없이 이 복사본에서 작업해 주세요. 공용 파일은 필요한 부분만 기존 값을 유지하면서 추가하고 변경 내역을 별도로 남겨 주세요. 기존 저장 파일을 건드리지 않는 시험 세션을 사용해 주세요.

Unity6000.3.26f1에서 컴파일·씬 왕복·퀘스트·거래를 확인하고, 실제로 통과한 검사와 미실행 검사를 구분해 주세요. 끝나면 Docs/Arabia/04_첫플레이_구현결과.md와 STATUS.md에 실행법·변경 파일·남은 작업을 기록해 주세요.

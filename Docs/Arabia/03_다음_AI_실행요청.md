# 다음 AI에게 전달할 실행 요청

아래 요청과 함께 이 폴더, 로컬 게임 소스, 필요 시 참고 PDF를 전달한다. 인수인계 문서만으로 원본 프로젝트 파일이 전달되지는 않는다.

---

Pocket Caravan 아라비아 제작의3단계, 첫 플레이 구간을 구현해 줘. `AI_HANDOFF.md`와 `02_지역설계_및_첫구현명세.md`를 먼저 읽고 실제 코드와 대조해 줘. GitHub 등 외부 연결을 추가로 요구하지 말고 제공된 로컬 소스를 기준으로 진행해 줘.

1. 원본을 보존하고 작업공간에 개발용 복사본을 준비해 줘. `.git` 없는 원본에서 상위의 무관한 저장소를 사용하지 마. 복사본·Unity 버전·기존 지침을 확인해 줘.
2. 기존 게임의 시작·등록·맵 생성·DB·저장 경로를 확인하고, 기존 상태가 실패하면 원인과 변경 필요성을 먼저 기록해 줘.
3. 아라비아의 실제 3개 맵(알 아흐사/농원길/자비드), 지역·마을·상품·NPC·Q1·Q2 데이터를 만들어 줘. 임시 공용 아트를 활용해 줘. 전체 5거점은 최종설계이며 이번구간에 가짜출구나 빈맵을 넣지 마.
4. 상대 좌표는 기존 등록과충돌하지않는 시험영역으로 일괄이동해 사용해 줘. TownData와등록좌표를맞추고 시험배치를기록해 줘. 다른지역가격영향을확인해 줘.
5. 기존 공용 DB의참조를보존하고 추가해 줘. 생성원본을한곳으로정하고 자기맵만생성해 줘. ‘시작세트만들기’와 무분별한전체생성은하지마.
6. Q1수령·배달·납품·보상1회, Q2선행·지정시장구매·납품·양수이익을완주가능하게해 줘. 예시수치는 실제상점계산후조정하고 확정값처럼소개하지마.
7. 복사본에서 시작/출신/저장 시험정책을명시하고 사용자기존저장은건드리지마. 정식출신선택을구현하지않았다면 테스트설정을제품기능으로보고하지마.
8. Python지역 등록/통합 검사, Unity컴파일, 실제출구왕복과Q1·Q2플레이를검증해 줘. 실행할수없는검사는미실행으로기록해 줘. 기존고려의회귀도확인해 줘.
9. `04_첫플레이_구현결과.md`에 변경파일·실행법·실험값·검사결과·오류·다음작업을적고 AI_HANDOFF.md를갱신해 줘.

이번구현범위는Q1·Q2까지다. 새적재특화·Q3분기·Q6순손익·온라인·최종 아트는별도후속이므로 한꺼번에 추가하지마. 막히는지점이있으면 가능한 독립작업을완료하고 정확한원인과재현절차를남겨 줘.

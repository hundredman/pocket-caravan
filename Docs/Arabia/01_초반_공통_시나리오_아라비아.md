# 초반 공통 시나리오 — 아라비아 버전

2026-10-20 · 초안 v0.1 · 담당 은인

## 한눈에 보기

**1장: 빈 짐가방에서 첫 손수레까지**

선대의 천 짐가방과 빈 장부를 물려받은 작은 동물 행상이 첫 배달을 시작한다. 가까운 오아시스의 심부름에서 출발해 여러 장터를 다니며 물량·길·판매처를 고르는 법을 배운다. 마지막에는 자기 돈으로 손수레를 사고 더 큰 교역에 나선다.

- 공통 흐름: Q1·Q2 필수 → Q3~Q6과 반복 의뢰·자유 교역 중 선택 → Q7 손수레 구입.
- 아라비아 강점: 상단의 포장·운송 노하우를 바탕으로 한 적재 보너스. 수치·적용 수단은 미확정이다.
- 분위기: 생활감 있는 따뜻한 교역 세계. 실패는 다시 일어설 기회로 이어진다.
- 지역: 이미 발전한 수도1개와 수도 외 마을4개. 마을 이동은 열려 있고 일부 시설·고급 거래는 신용에 따라 열린다.
- 제작 범위: 대사와 퀘스트 설계 초안. 실제 기능이 구현되었다는 의미가 아니다.
- 주인공 외형: 모래고양이 계열 동물 상인1안. 사람 NPC1안은 대표 화면에서 비교한다.

## 배경 스토리

선대는 장부의 첫 장에 다섯 장터의 이름과 한 줄을 남겼다.

> “짐은 목적지까지, 약속은 사람에게까지.”

주인공은 낡은 짐가방을 메고 알 아흐사 장터에 도착한다. 장부는 비었지만 손잡이는 여러 번 수선되어 있다. 여관 주인은 그 가방을 알아보고 작은 배달부터 권한다. 주인공의 첫 목표는 거대한 상단의 주인이 되는 것이 아니라, 내 손으로 번 돈으로 첫 손수레를 사는 것이다.

장부에는 방문한 시장의 시세와 거래 기록이 쌓인다. 아라비아의 능력은 민족의 타고난 힘이 아니라 포장 기술과 운송 경험을 게임 규칙으로 각색한 것이다.

### 장소 배치 초안

실제 지명을 사용하는 회의 방향을 따른다. 아래 도시들은 현실에서 이 순서로 가까이 붙어 있거나 하나의 수도에 딸린 마을들이 아니다. 게임 속 크기·거리·위계·특산품 배정은 압축한 가상 교역망이다. 최종 지명 적용은 다음 지역 설계 단계에서 확정한다.

| 장소 후보 | 게임 내 역할 | 초반 화면과 활동 |
|---|---|---|
| 알 아흐사 | 시작 오아시스 마을 | 우물·야자수·농원·여관·대추야자 시장 |
| 자비드 | 농원 마을 | 공동 식사 준비·곡물 시장·바구니를 든 주민 |
| 타이즈 | 공방 마을 | 천 꾸러미·포장 작업대·신용 의뢰 |
| 제다 | 교역 중계 마을 | 항구 짐마당·창고·수레 공방·떠나는 상인 |
| 사나 | 게임상 수도 거점 | 큰 시장·소비처·고급 거래 시설 |

알 아흐사의 오아시스와 대추야자 재배, 제다의 교역항, 사나의 내륙 교역은 자료에서 가져온 모티브다. 자비드를 곡물 산지로, 타이즈를 직물 생산 거점으로 삼는 것은 이번 게임의 역할 배정이며 검증된 역사적 특산품 주장으로 소개하지 않는다. 현재 유산 건축 전체를8~15세기 모습으로 복제하지 않는다.

## 프롤로그 — 목표 약1분

1. 선대의 문장을 짧게 보여준다. 건너뛰기를 허용한다.
2. 알 아흐사 입구. 밝은 흙길 끝에 우물, 천막, 야자수와 짐을 옮기는 주민이 보인다.
3. 길잡이 하산이 가방의 묶음을 가리킨다. “매듭은 튼튼하네. 이제 어디로 갈지 정하면 되겠어.”
4. 여관 주인 마리암: “옆 장터에 가져다줄 것이 있어. 첫 줄은 그 일로 채워 보렴.”
5. 조작을 넘긴다. 게시판과 첫 의뢰인 위치만 안내한다.

현재 조작 기준: WASD/방향키 이동, Shift 달리기, Space 대화·확인, Q 퀘스트, M 지도, L 장부, Esc 메뉴. 원본의 E/F·Space 연타는 복사하지 않는다.

## 등장인물 — 공통 역할8개

이름은 창작 인물의 작업명이다. 힌드바드만 아래 옛이야기 모티브에서 가져왔다. 의뢰의 상대 주민·상점 주인은 보조 NPC이므로 역할8개가 개체8개라는 뜻은 아니다.

| 공통 역할 | 아라비아 인물 | 성격·하는 일 | 연결 |
|---|---|---|---|
| 길잡이 | 하산, 길 안내소의 기록원 | 길과 짐 무게를 짧게 설명. 정보 독점 능력은 없음 | 전체 |
| 마을 어른 | 마리암, 알 아흐사 여관 주인 | 선대의 가방을 기억하고 첫 거래를 돕는다 | Q1·Q2 |
| 첫 의뢰인 | 힌드바드, 초보 짐꾼 | 혼자 들기 벅찬 짐을 나눠 맡긴다 | Q1 |
| 정직 시험관 | 살마, 타이즈 창고 관리인 | 장부와 실제 수량을 확인한다. 함정을 꾸미는 인물은 아님 | Q3 |
| 먼 마을 의뢰인 | 나디아, 사나 시장의 상인 | 멀리서 오는 납품을 기다리고 큰 주문을 맡긴다 | Q4·Q5 |
| 길 위의 위협 | 붉은 끈 패거리 | 길목에서 통행료를 요구하는 허풍쟁이들 | Q5·길 사건 |
| 라이벌 상인 | 라시드, 이동 상인 | 많이 팔기만 하면 이긴다고 생각한다 | Q6 |
| 운반 수단 판매자 | 유수프, 제다의 수레 장인 | 손수레를 팔고 첫 운송을 지켜본다 | Q7 |

## 1장 공통 퀘스트

| 구간 | 퀘스트 | 배우는 것 |
|---|---|---|
| 필수 | Q1. 힌드바드의 반쪽 짐 | 수락·무게·이동·납품 |
| 필수 | Q2. 여관의 저녁 준비 | 자기 돈으로 구매하고 납품해 이득 얻기 |
| 선택 | Q3. 장부에 없는 꾸러미 | 정직 선택·신용 |
| 선택 이벤트 | Q4. 같은 길, 한 묶음 더 | 적재 강점과 물량 선택 |
| 선택 | Q5. 두 길 사이의 약속 | 거리·노면·위험 비교 |
| 선택 | Q6. 한 장터에 다 팔지 말 것 | 재고·가격 변화·분산 판매 |
| 마무리 | Q7. 내 이름을 단 손수레 | 운반 수단 구매와 성장 확인 |

Q1→Q2가 필수 선행이다. Q2 이후Q3·Q5·Q6을 자유롭게 선택하고 Q4는 조건 충족 시 안내한다. Q7은Q2 이후 자금이 있으면 진행 가능하다. 선택 의뢰를 전부 끝내야만 구매할 수 있게 하지 않는다.

### Q1. 힌드바드의 반쪽 짐

- 시작: 알 아흐사 힌드바드. 목적: 자비드 공동 부엌의 배달 담당.
- 내용: 초보 짐꾼 힌드바드가 많은 바구니 앞에서 쉬고 있다. 주인공에게 대추야자 꾸러미 일부를 맡긴다.
- 흐름: 수락하며 의뢰 짐 수령 → 안전한 길로 자비드 이동 → 담당자에게 납품. 첫 의뢰부터 왕복을 여러 번 강요하지 않는다.
- 완료 조건: 지정 상품N개를 지정NPC에게 전달. N은 초보 등짐의 여유 있는 적재량으로 조정한다.
- 보상: 보수R1과 작은 신용. 길에서 달리기를 안 써도 완료 가능.
- 시작 대사: “짐을 잘 나른다는 건 혼자 다 든다는 뜻은 아니더라. 이 묶음을 함께 맡아 줄래?”
- 진행 대사: “자비드의 공동 부엌으로 가면 돼. 무거우면 천천히 걸어도 괜찮아.”
- 완료 대사: “기다리던 짐이구나. 네 이름도 장부에 적어 둘게.”
- 구현: 기존giveItem/Deliver 재사용. 목표NPC·상품·수량을 지역 데이터로 지정.

### Q2. 여관의 저녁 준비

- 시작: Q1 완료 후 알 아흐사 마리암에게 받는다. 자비드에서 곡물을 사서 돌아온다.
- 내용: 여관의 저녁 준비를 위해 곡물 꾸러미를 구매한다. 처음으로 자기 돈을 쓴다.
- 흐름: 제안에서 예상 구매비·납품 보수를 확인 → 지정 시장에서 구매 → 마리암에게 납품 → 장부에 첫 이득 기록.
- 완료 조건: 지정 시장에서 지정 품목N개 구매 후 전달. 실제 납품 때 짐이 있어야 한다.
- 보상: 납품 보수R2에 구매비 보전분 포함. 소득으로 보이는 금액은 R2−실제구매비다.
- 시작 대사: “곡물은 자비드에서 사 오렴. 물건값을 빼도 네 몫이 남도록 줄게.”
- 진행 대사: “장부에 산 값을 적어 두렴. 받은 돈이 전부 이익은 아니니까.”
- 완료 대사: “이제 한 줄을 네 힘으로 채웠구나. 다음에 무엇을 나를지는 네가 골라 보렴.”
- 구현: Buy→Deliver. 가격 상승으로 적자가 되거나 자금이 모자라 진행 불능이 되지 않도록 재고·초보 구매 조건 검사. 돈 부족 시 선지출 없는 일반 배달을 안내.

### Q3. 장부에 없는 꾸러미

- 시작: 타이즈 살마. 목적: 같은 마을의 포장 작업대.
- 내용: 맡은 천 꾸러미에 장부보다 하나가 더 있다. 물건을 떨어뜨리는 사건은 없다.
- 선택A: “꾸러미가 하나 더 있습니다.” 추가 물건을 돌려주고 신용 보너스.
- 선택B: “장부에 적힌 것만 전하겠습니다.” 납품 후 수량 대조에서 불일치가 확인된다. 추가 물건을 돌려주며 신용 보너스를 받지 못한다. 영구 진행 차단은 없다.
- 두 선택 모두: 기본 배달 보수 지급. 추가 물건을 개인 재화로 확정하지 않으며 무한 획득 경로를 만들지 않는다.
- 시작 대사: “여기 적힌 수량을 작업대에 전해 줘. 포장표도 함께 확인해 주겠니?”
- 진행 대사: “장부에는 세 묶음인데, 매듭은 네 개다.” 이3/4는 이야기 연출 예시이며 실제 수량은 최종 데이터와 맞춘다.
- 완료A: “남는 짐까지 챙겨 주었구나. 다음에는 더 중요한 물건도 맡길 수 있겠어.”
- 완료B: “한 묶음이 더 있었네. 다음에는 출발 전에 함께 세어 보자.”
- 구현 추가: 선택 결과·추가 물건 소유·회수·보상 여부 저장. 현재 직선 목표만으로 ‘선택 가능’하다고 표시하지 않는다. 구현 전에는 글로 읽는 시안 상태로 유지.

### Q4. 같은 길, 한 묶음 더

- 발생: Q2 이후 자유 구간에 진입하고 적재 특화가 적용된 상태에서 한 번 안내. 정확한 지연 시간은 플레이로 조정한다.
- 내용: 나디아가 사나로 가는 공방 납품을 모집한다. 작은 주문과 큰 주문 중 선택할 수 있다.
- 아라비아 체험: 빈 등짐 기준으로 보통 한도C보다 크고 아라비아 한도Ca 이내인 큰 주문 W를 준비한다(C<W≤Ca). 실제 물품 단위로 가능한 값이 없으면 무게·수량을 다시 조정한다. 배율을 임의 확정하지 않는다.
- 큰 주문은 보수가 늘지만 느려지고, 손수레가 있으면 그 수단의 실제 한도로 재조정한다. ‘특화=무조건 최적’으로 만들지 않는다.
- 현재 짐 때문에 못 받으면 이유와 비우는 방법을 안내. 다른 출신으로 방문했을 때는 작은 주문·수레 운송 등의 경로를 허용한다.
- 시작 대사: “같은 길로 가는 짐이 하나 더 있어. 네가 감당할 만큼만 골라 줘.”
- 진행 대사: “더 싣는 것과 더 빨리 도착하는 것은 다른 일이야. 길도 함께 살펴봐.”
- 완료 대사: “한 번의 여행으로 여러 약속을 지켰네. 이번에는 물량을 잘 골랐어.”
- 구현 추가: 공통 적재 계산, 주문 분기, 안내/수락/완료 상태 저장. 한 번의 운송은 한 번의 수락과 납품으로 표현하고 중간 소량 왕복이 큰 주문 체험으로 잘못 인정되는지 검사.

### Q5. 두 길 사이의 약속

- 시작: 제다 물류마당. 목적: 사나 나디아에게 천막용 천 납품.
- 길A: 길지만 노면이 좋고 도적 위험이 낮은 큰길.
- 길B: 짧지만 거친 지면과 붉은 끈 패거리가 있는 지름길.
- 출발 전에 길의 특징을 알려준다. 신용 부족으로 한쪽 길을 잠그지 않는다.
- 대응: 기존 도적 시스템의 달려 피하기·통행료 선택을 활용하고, 실제 우회로를 연결한다. 호위 고용·지형 수리는 추가하지 않는다.
- 시작 대사: “사나까지 부탁해. 큰길은 돌아가고, 샛길은 짧지만 험해.”
- 진행 대사: “지금 짐이 무겁다면 짧은 길이 더 오래 걸릴 수도 있어.”
- 완료 대사: “어느 길로 왔든 약속을 지켰구나. 다음에는 네 경험으로 길을 골라 봐.”
- 구현: Deliver+실제 경로. 첫 버전은 별도 제한시간 없이 진행하고, 강탈 시 대체 구매나 안전한 배달로 회복할 수 있는 절차를 확보.

### Q6. 한 장터에 다 팔지 말 것

- 시작: 타이즈 라시드. 목적: 직물 거래로 품목별 순이익P 달성.
- 내용: 라시드가 사나에 직물을 대량 판매해 가격이 내려간다. 주인공은 장부를 확인하고 제다와 다른 시장으로 나눠 팔거나 회복을 기다린다.
- 라시드는 악당이 아니라 계산을 성급하게 하는 경쟁자다. 사건은 전 세계 모든 상품을 붕괴시키지 않고 지정 시장·상품에 한정한다.
- 완료 조건: 수락 이후 지정 품목의 누적 실현 손익≥P. 해당 품목의 손실 판매도 차감한다. 보상·다른 상품 판매·보유 재고의 미실현 이익은 제외.
- 시작 대사: “나는 한 장터에서 전부 팔 거야. 너도 따라올 테야?”
- 진행 대사: “사나에는 이미 같은 물건이 많네. 다른 장터의 수요도 볼까?”
- 완료 대사: “나눠 파는 편이 나을 때도 있군. 다음 거래는 내가 먼저 살펴보겠어!”
- 구현 추가: 현Profit은 양수만 누적하므로 그대로 사용 불가. 품목별 손익 추적·수락 시점·라시드 거래1회·시장 상태 저장 필요. 공유 시장의 사건 권한은 온라인 담당과 별도 계약.

### Q7. 내 이름을 단 손수레

- 시작: Q2 이후 제다 유수프에게 가격과 목표를 확인 가능. 모든 선택 의뢰 완료를 요구하지 않는다.
- 흐름: 자유 교역·선택/반복 의뢰로 돈을 모음 → 공통handcart 구매 → 원하는 짧은 배달을 해 보며 적재량 변화 확인.
- 완료 조건: 손수레 보유 확인. 이미 구매한 플레이어도 인정한다. 이후 짧은 배달은 체험 권장이고 결말을 다시 잠그지 않는다.
- 시작 대사: “네 이름으로 된 수레 한 대, 어떠니? 번 돈으로 천천히 마련해.”
- 진행 대사: “수레 값은 여기 적혀 있어. 다음 물건을 살 돈도 조금 남겨 두면 좋겠지.”
- 완료 대사: “이제 이 수레는 네 것이야. 바퀴 자국이 어디까지 이어질지 기대되는구나.”
- 마지막 장면: 처음의 빈 가방, 거래 기록이 쌓인 장부, 새 손수레가 나란히 보인다.
- 마무리 문장: “다음 장은 어느 장터에서 시작할까?”
- 구현: BuyVehicle 재사용. 수레 가격·적재3배 등 이전 예시는 고정하지 않는다. 수도의 생성이나 일괄 관문 개방으로 끝내지 않는다.

## 보상 흐름과 시간 검증

- 목표: 필수 구간 약5분, 자유 구간 약10~20분. 측정 전의 목표이며 완주시간으로 보고하지 않는다.
- 기준 변수: 시작 자금S, 수레 가격H, 실제 구매비C2, Q1보수R1, Q2보수R2.
- Q2 진입 가능: S+R1≥C2. Q2 이득 보장: R2>C2.
- Q2 후 자금: S+R1−C2+R2. 이 금액과H의 차이를 선택 의뢰·반복 배달·교역으로 메운다.
- 수레 구매 후 최소 운영비를 남기는 것이 권장되지만, 남은 돈이0이어도 선지출 없는 배달로 재기 가능해야 한다.
- Q3~Q6 중 어떤 하나를 건너뛰어도 Q7 도달 가능 여부를 각각 검사한다. Q4 미수락·Q3 다른 선택으로 결말을 막지 않는다.
- 대량 상품 판매는 가격을 떨어뜨릴 수 있다. 적재 강점 평가는 판매액이 아니라 실제 순이익/왕복 시간/재고 변화로 한다.
- 표시 화폐는 우선 공통 구현에 맞춘다. 지역 환율을 새로 만들지 않는다.

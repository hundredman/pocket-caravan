1. main의 기준 커밋과 Unity 버전.
2. 지역별 브랜치·PR·병합 상태와 실제 씬/등록 파일.
3. 출신 적재/이동/판매 변경, Q3 선택, Q4/Q6 이벤트 저장의 중복 구현 여부.

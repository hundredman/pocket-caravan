## 2. 실행 방법

Unity Hub에서 개발 복사본을 6000.3.26f1로 연다. 메뉴 **Pocket Caravan > 아라비아**:

1. `1. 첫 구간 데이터 갱신 (DB 보존·추가)` — 아라비아 에셋 생성/갱신, GameDatabase에 **뒤에 추가만** (기존 순서·GUID·시작값 확인 후 저장)
2. `2. 아라비아 씬 3개만 생성 (선택 생성)` — 3개 씬만 생성, 빌드 목록은 기존 순서 유지 + 아라비아 3개를 끝에 추가. 공용 파일 변화는 `Docs/Arabia/Reports/scene_build.md`에 기록
3. `3. 시험 플레이 (알 아흐사에서 시작)` — 직접 플레이
4. `4. 정적 검사 (데이터·씬)` → `Reports/static_checks.md`
5. `5. 자동 플레이 시험 (Q1·Q2·왕복·저장)` → `Reports/autoplay.md`
6. `6. 자동 보행·화면 캡처 시험 (Q1 경로)` → `Reports/walk.md`, `Reports/Screens/*.png`

맵을 고칠 때: `arabia.py` 수정 → `python3 Tools/MapGen/arabia_export.py` (통행 검사 포함, `--preview <폴더>`로 미리보기) → 메뉴 2.

직접 플레이 조작: WASD/방향키 이동, Shift 달리기, Space 대화, Q 수첩, L 장부, Esc 메뉴.

### 시험 세션과 저장 (기존 저장 보호)

- 아라비아 씬에서 Play를 시작하면 `RegionTestSession`(`Resources/RegionSessions/arabia.asset`)이 적용된다.
  - 저장 파일: `persistentDataPath/pocket_caravan_arabia_test_save.json` (본편 `pocket_caravan_save.json`과 분리)
  - 시작값: 돈 100 (공용 startMoney 복사), 출신 `Origin_Arabia`, 등짐(walk)
  - 자동 저장·이어 하기·Esc "처음부터 시작"은 이 전용 파일만 쓰고 지운다. "처음부터 시작"은 알 아흐사로 돌아간다.
- 본편 시작(빌드 0번 Naru)과 `World/settings.json`의 startMapId(Naru)는 바꾸지 않았다.
- 주의: 이 복사본과 원본 프로젝트는 같은 `DefaultCompany/PocketCaravan` 저장 폴더를 쓴다. 복사본에서 **Naru로 Play하면 기존 규칙대로 본편 저장을 읽고 쓴다** (이번 작업에서는 Naru Play를 하지 않았다).
- 자동 시험은 전용 저장이 이미 있으면 `.manual-backup`으로 보관했다가 끝나면 되돌린다. 마지막 시험 결과는 `.autotest-last`로 남긴다.

## 5. 남은 문제·한계

- **사람의 실제 키보드 조작은 검증하지 않았다.** 이동은 PlayerMotor 실제 처리로 자동 보행했지만 Input System 키 입력, 조작감, Space로 대화 넘기기는 사람이 메뉴 3으로 확인해야 한다.
- macOS 플레이어 빌드, 기존 Play 검사(`로컬 의뢰·회수·저장 검사`, 장애물·환경 원형 Play 검사)는 이번에 실행하지 않았다.
- 지도(M)와 상업 백과는 고려 전용 자료라 아라비아 위치가 표시되지 않는다. 음악은 기본값(나루 곡)이 재생된다.
- 수락 거절·납품 부족 대사는 공용 코드의 고려식 말투("~구먼", "~하네")가 그대로 나온다.
- 임시 아트: 야자수·낙타·모래고양이 주인공 없음. 대추야자 아이콘은 약재 꾸러미, 맡긴 짐은 상자 아이콘을 빌려 씀.
- 교역 차익이 얇다 (자비드 곡물 5 → 알 아흐사 판매 6, 알 아흐사 대추야자 6 → 자비드 판매 7). 자유 교역 재미를 위해 기준가·재고 조정 필요.
- 농원길 횡단이 적재 상태 약 16초로 짧은 편이다. 속도 비교를 더 체감하려면 길이를 늘릴지 플레이 평가 필요.
- Q2는 수락 전에 산 곡물을 구매 단계로 세지 않는다 (현행 규칙). 제안 대사로 안내만 했다.
- `Origin_Arabia`에는 예전 장거리 판매 보너스(3맵 이상)가 남아 있지만 첫 구간은 최대 거리 2라 발동하지 않는다. 새 적재 특화는 미구현.
- 정적 검사가 씬 3개를 추가로 열 때 "More than one global light" 오류 로그가 2줄 나온다 (에디터에서 여러 씬을 동시에 연 탓이며 Play 중에는 나오지 않음).

## 9. 2026-10-22 3차 다듬기 — 잘린 나무·다리 통행 (사용자 피드백 반영)

피드백: "나무들이 잘라져 있음, 거기 맞춰 다시 · 다리를 건너지 못함 · 다른 것들 다듬기".

### 원인과 수정

| 문제 | 원인 | 수정 |
|---|---|---|
| 나무가 잘려 보임 | 가장자리 숲(`border`)이 나무를 겹쳐 심으며 이미 찬 칸·맵 밖 칸을 잘라냄(clip) → 반쪽 나무, 수관 일부 없는 나무 | `border`를 다시 작성: 나무를 통째로만 나란히 심고, 안 맞으면 다른 나무·다음 자리. 세로 띠는 맵 끝에 붙여 심음. 띠 영역은 막아서 숲 뒤 샛길도 없앰 |
| 물 위 나무 | 배치가 물 칸을 검사하지 않음 | 물·다리 칸에는 물건을 놓지 않음 (바닥 장식 제외) |
| 다리를 못 건넘 | 물을 칠한 뒤 그 위에 포장길을 칠해도 '물' 표시가 남아 공용 빌더가 막음 | 물 이외 바닥을 칠하면 물 표시를 지움. 다리 전용 `bridge()` 추가 (막힘 해제, 길로 계산) |
| 다리 모양 | 물 위에 돌 포장 사각형 | 야자나무 판자 다리 + 양쪽 난간·기둥 (새 그림 조각 `arabia_tbridge*`), 물은 다리 밑으로 이어짐 |

다리: 농원길 지름길 다리(28~31, 17~18)·대상로 다리(28~31, 26~29), 자비드 수로 다리(20~21, 31~34, 남북).

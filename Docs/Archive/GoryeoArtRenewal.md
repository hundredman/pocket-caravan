# 고려 픽셀 아트·담당 면적 개편

2026-10-23. [회의와 후속 확인](../Meetings/2026-10-23.md)을 적용한다. 최종 미술 승인이 아니라 실제 플레이 가능한 수정본이다.

## 제작 원본

- `World/Terrain/continuous.json` + `Tools/MapGen/continuous.py`: 기존 해안·수계·교역 동선의 원본. 여기의80×64는 중간 제작 좌표다.
- `World/Terrain/area_budget.json` + `Tools/MapGen/compact.py`: 최종 가변 크기 구역과 담당 면적. 건물은 전체 묶음으로 재배치하고 실제 길/연결/스폰을 재생성한다. 개경 궁성·정원·시전의 최종 배치는 `capital()`에서 직접 설계한다.
- `Art/Goryeo/Source/Architecture.png`: 생성한 고려 전용 픽셀풍 건축/소나무 원본. 프롬프트와 생성 방식은 같은 폴더 `Provenance.md`.
- `Tools/MapGen/goryeo_art.py`: 원본의 실제 영역, 16px 타일 출력, 건물별28색과 명확한 투명 경계, 고려/장단 팔레트. 고해상도 그림을 그대로 게임 위에 올리지 않는다.
- `Tools/MapGen/world_registry.py`의 `atlas_content()`가 지형→면적→아트를 순서대로 적용한다. JSON·PNG·게임 지도·Unity 씬 모두 이 결과를 사용한다.

위 `World/Art` 경로는 `Assets/PocketCaravan/` 기준이다. 생성 타일은 기존 빌더와 호환되도록 `Art/NinjaAdventure/Tiles/`에 있지만 `goryeo_` 이름으로 구별하며 무료 팩 원본의 재색칠만으로 만든 건축물이 아니다. 바닥·물결·일부 식생과 소품은 기존 에셋을 유지한다.

## 규모와 보존

고려13구역20,000칸, 중앙 동쪽6구역25,000칸, 합계45,000칸. 바다와 막힌 땅도 포함한다. 수도1+고려 마을4, 중앙 마을2, 시장7곳·상품/퀘스트/시설 ID·경제 좌표는 유지한다. 북·서·남 문명과 다른 팀 영역을 생성하지 않는다. 중앙 동쪽의 기존 내륙 경유 지역을 담당 구획으로 사용하며 최종 팀 접경 계약은 연결 시 함께 조정해야 한다.

저장 재산을 초기화하지 않는다. 이전 높이 기록을 보존하고 기존 저장의 위치 보정과 통행 가능한 길 탐색을 이용한다. 지형 재배치 때문에 예전의 세부 위치를 그대로 재현하는 것은 보장하지 않는다. 이동 페이드아웃0.12초/페이드인0.18초는 기존 구현이다.

## 미술 방향과 제한

기와집·시전·초가·전각·정자·소나무 원본을 제작했다. 개경은 큰 전각과 연못, 시전, 주거 골목을 재배치했다. 고려는 차분한 청록/청회색, 장단과 들길은 황금 들판 팔레트로 구분한다. 기존 한지 작업·나루 짐꾼·물결·바람 연출은 유지한다. 작은 픽셀에서 캐릭터·길·상호작용이 구분되는지가 최종 판단 기준이다.

생성 아트는 고증된 건축 복원 자료가 아니다. 사실적인 첫 결과는 적용하지 않았고 픽셀 스타일 수정본을 실제16px 셀에 맞춰 사용했다. 모든 지형·캐릭터를 새로 제작한 것은 아니다. 추가 보강에서 마을별 소품·석등 주야 조명과 나루 낚시를 구현했다. 장날 개최/보상·멀티 동기화는 미완료다.

## 재현

`export.py` → `validate.py` → `validate_world.py` → Integration unittest. Unity에서는 등록된 고려/중앙 동쪽19씬만 `BuildSelected`로 갱신한다. `SceneTerrainChecks`로 실제 셀·스폰·구 저장 보정을 확인하고, 본편 저장과 분리된 중앙 비교 Play에서 `CentralConnectionChecks.Begin()`으로 실제 모터 왕복을 확인한다. 검사 결과는 `Docs/Validation/GoryeoArt-2026-10-23.json`을 기준으로 한다.

## 체크포인트 이후 마을별 보강

`Tools/MapGen/settlement_details.py`가 최종 크기에서 실제 충돌과 동선을 지키며 대표 시설을 배치한다. 나무는 통째로 옮기거나 제거하고, 새로운 건물/작업장 앞을 실제 길로 연결한다.

- 개경: 회색 판석 마당, 낮은 기와 돌담, 석등, 청자 진열대와 연꽃.
- 예성 나루: 물가 상가, 청자 진열대, 목재 선착장과 낚시 안내 주민.
- 닥나무 마을: 강 건너 한지 건조대와 작업장.
- 송악: 소나무 사이 정자, 낮은 담, 석등.
- 장단: 큰 초가와 볏단/곡식 바구니, 황금빛 들판.

`VillageDetails.png`, `CourtyardStone.png`와 프롬프트를 원본 폴더에 보존한다. 새 소품은 16px 셀/28색/이진 알파, 바닥은 64px 반복/12색이다. 기존 직선 외곽의 반복 바위 줄도 줄였다.

`GoryeoLantern`은 기존 시계의 낮·밤에 맞춰 따뜻한 국소광을 변화시킨다. GameManager는 전역광을 명시적으로 찾아 석등을 태양광으로 잘못 선택하지 않는다.

`GoryeoPastime`은 나루의 선택형 3회 타이밍 낚시다. Space로 던지고 낚아채며 Esc로 닫는다. 물고기를 놓아주는 짧은 휴식으로, 돈·신용·화물 보상이나 저장 형식을 변경하지 않는다. 장날 보상 결정과 독립이다. 현재 최고 기록은 해당 방문 동안만 유지한다. 추가 마을 미니게임과 사용자 재미 평가는 남아 있다.

새 검증/실행 화면은 `Validation/GoryeoVillagePolish-2026-10-23.json`, `Images/GoryeoArt/` 참고. 이전 검증 기록은 당시 결과로 보존한다.

실제 닥목/장단 화면에서 기존 불투명 청록 물결 프레임의 네모 배경을 발견해 고려 전용 투명 물결로 수정했다. 원본 네 프레임의 형태/속도는 유지하고 바닥 물색이 비치도록 내보낸다. 다른 지역 물결 원본은 변경하지 않는다.

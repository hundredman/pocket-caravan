# 고려 반도→대륙 내륙·중앙아시아 방면

최신 방향: 2026-10-22. **한반도에서 북서쪽 육로로 대륙에 진입해 중앙아시아 방면으로 이동하는 형태**로 수정한다. 고려는 동쪽의 반도 권역이다. 이전의 장단 남서쪽 연결과 문자 그대로 중앙 십자 도로를 만든 배치는 대체한다.

[세계 지리·실크로드 기준](WorldTradeNetwork.md)에 따라 실제 지리의 인상을 살리되 거리·비율을 조정한다. 프로토타입에서는 고려(동)·북유럽(북)·베네치아(서)·아라비아(남)가 여러 경유 구역을 통해 중앙 권역에서 연결되며, 문명 간 이동은 중앙을 거친다.

십자형은 동·서·남·북 문명과 중앙 권역 사이의 전체 교역망 구조다. 한 맵에 반드시 네 출구/십자 도로를 만드는 규칙이 아니다. 각 방향은 여러 경유 구역으로 연결하며 장기적으로 거미줄 교역망으로 확장한다.

## 실제 지형과 연결

최신 구현/원본/검사/화면은 [연속 지형](ContinuousTerrain.md)을 따른다. 고려13+중간권6=19구역이며, 실제 해안·수계·길·숲과 지도는 같은 타일을 사용한다. 이전의 지도 전용 반도 프로필은 제거했다. 수도1+마을4와 기존 경제/의뢰ID는 유지한다.

고려 나루·개경·송악 산록과 서해안 우회길에서 솔바람 고개로 나와, 솔재→버들 물가→버들나루→초원 진입로→내륙 길목을 지난다. 중앙 한 장에 문자 그대로 십자 도로를 만들지 않는다. 현재 북·서·남 문명은 미연결이다.

Unity `Pocket Caravan → 중앙 연결 → 내륙 교역 길목 열기` 후 Play하면 기존 저장과 분리해 비교한다. 본편 시작은 Naru, 지도는 M이다. 길뿐 아니라 연결된 풀밭 경계도 이동 가능하다. 구역별 씬 전환은 남아 있다.

경제용 worldCoord는 지리적 방위가 아니다. 기존 가격/상품/시장ID를 지리 재배치 때문에 변경하지 않는다. 지형/접속을 바꿀 때는 continuous.json 수정→export→선택 씬 생성→검사를 함께 수행한다. 다른 담당 지역을 자동 재생성하지 않는다.

이전15맵 Peninsula ZIP/검증은 당시 결과로 보존한다. 새19맵 소스/검사는 [현재 기록](Validation/ContinuousTerrain-2026-10-22.json), 실제 빌드 버전은 [빌드 현황](../Reference/BuildStatus.md)을 확인한다.

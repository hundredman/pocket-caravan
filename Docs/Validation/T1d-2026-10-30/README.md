# T1d 전환을 조금 늦춤 / A7e 주요 숲 복원

사용자가 T1c 카메라 무빙을 승인하고 전환 시점을 조금 더 끝으로 늦추도록 지시했다. 주요 숲을 지우고 논을 추가한 곳도 원복하도록 했으며, 사용량 초기화 뒤 재개 지시를 받아 진행했다. 원격 통합은 여전히 보류한다.

## 전환

`CameraFollow.cs`는 바꾸지 않았다. 기존 전환은 발밑 충돌 상자의 앞끝이 경계에 닿는 시점이었다. 이제 발 중심이 출구의 바깥 면에 도달한 뒤 전환한다. 기본 발 크기0.5×0.25칸이므로 가로0.25칸(16px 기준4px), 세로0.125칸(2px) 더 걸어간다. 별도 시간 지연이나 카메라 이동은 없다.

마지막 구간에서 발 상자가 막히지 않도록, 담당 지역의 유효한 출구 칸 안에 발 중심이 있을 때 바깥쪽으로 걸친 발 상자의 검사점만 경계 안쪽으로 투영한다. 옆 방향/건물/일반 벽은 그대로 검사하며 발 중심이 다음 칸으로 빠져나가도록 허용하지 않는다. 다른 문명의 전환·충돌은 기존대로다. 저장 형식·ID·출구/도착 위치는 바꾸지 않았다.

Unity 경계 검사는 기존 앞끝 접촉 시점에서 전환되지 않는지 추가했다. 13맵 전체 담당 출구, 네 방향 걷기/달리기·30/60/144Hz, 실제 지역 간 이동·다른 문명 회귀 및 촬영을 실행해 **8368확인 통과**했다. 결과는 `ArtReview/BoundaryDepth-20261030/checks.json`.

## 논과 숲

직전 추가3곳의 원본 나무 배치를 조사했다. 장단(193,48)은 나무 원본35개/그중 숲 원본23개, 송악(174,-5)은32개/숲21개와 겹쳤다. “빈터”로 고른 곳에 숲을 제거하는 구현이 허용되어 있던 것이 잘못이었다.

- 두 논과 그 개간 영역을 원본 레시피에서 제거해 숲을 복원했다.
- 개경(240,8)은 나무0개/숲 장벽0으로 빈터인 것이 확인되어 유지했다. 추가1개, 총9구획(종전 본편8개+검토용1개).
- 새 후보는 건물·길·물·기능물/출입구 보호 외에 나무 원본 최대3개·숲 원본 최대1개·장벽 비중10% 이하로 제한한다. 무리하게 수량을 맞추지 않는다. 이번에 선택된 곳은 실제 나무 제거0이다.
- 장단·송악 검토 JSON의 ground/deco/obj/high 전체를 타일 이름으로 정규화해 입력 본편의 지문과 비교했다. **모두 동일**하다. 마을 소품은 별도 런타임 루트이며 지형 복원 검사에 섞지 않는다.

본편에 이미 승인된8개는 유지한다. 숲 가장자리 몇 그루와 겹치는 기존 구획은 새 지시가 허용한 소수 나무 대체 범위로 구분했다. 밀집 숲을 대체한 신규2곳은 남기지 않았다.

`ArtReview/ForestRestore-20261030/Before/`는 직전11구획 검토본의 실제 게임 캡처다. 같은 구도의 새 실제 게임 화면과 합친 `forest-restoration-comparison.png`에서 숲 복원/빈터 유지 여부를 확인할 수 있다. 11마을+3개 부지의14시점 전후28PNG(1280×720)와 게시판 UI를 다시 촬영했다. 소품 충돌·이벤트 전환/복원·옛 위치 복구·캐릭터 프레임·게시판 열기/닫기 등 **1511확인 통과**. 이는 새 검토본의 결과이며 과거11구획 캡처는 Git 이력과 Before 폴더에 보존한다.

## 기타 검증과 상태

- Python **343실행,16skip,실패0**. 새2개 검사는 신규 논의 숲 보호 기준과 장단/송악 지형 원복을 확인한다.
- 본편 세계 연결1408출구 오류0. 검토 생성87원본/3293합성칸 인증 오류0·13맵 pixelDiff0.
- 기존 기능/출구/도착 객체 보존. 직전 검토의 숲 개간으로 생겼던 경계7칸도 사라져 이번 추가 경계0.
- E1 분석은 PlayerMotor 소스 지문만 갱신했다. 계산 결과/보정값/거리/경제 수치는 모두 동일한 것을 비교 후 확인했다.
- 본편 맵/씬/지도·공용DB/색인/빌드목록·다른 팀 데이터 변경 없음. previewOnly와 작업 브랜치 코드만 변경했다. QA 자동저장 비활성화 확인. 실제 저장 파일의 전후 해시는 새로 수집하지 않았다.
- 사람이 직접 하는 WASD 체감, 모든 화면비/실기기FPS/장시간 플레이/플레이어 빌드는 미실행. 배치 승인·추가 통합 지시·팀 공지 전 push/PR/원격 병합 금지.

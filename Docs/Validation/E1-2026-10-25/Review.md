# E1 거리 환산 검토 — 구현 중단·Claude 판단 요청

기준: 2026-10-25, 최신 로컬 main `54b9974a`에서 만든 `codex/e1`. Decisions 4~7절을 읽고 E1부터 확인했다. **거리 기준·중앙 ID·D5·외부 연결 결정은 수신했다. 새 중단 이유는 4절의 단일 환산 비율과 경제 차이 ±10%를 동시에 만족할 수 없다는 점이다.**

## 계산 근거

- B1 동결 원본의 9마을·12개 도식 길을 무방향 연결망으로 읽고, 선분 길이 합 ÷ 본편 `PlayerMotor.walkSpeed=3.8`로 예상 보행 초를 구했다. 전체 연결망에서 최단 시간을 구한다. 외부 비활성 자리는 길로 넣지 않았다.
- 고려 5개 TownData의 실제 `worldCoord`와 본편 맨해튼 공식을 읽었다. 10쌍 모두 같은 가중치로 원점을 지나는 최소제곱을 적용했다. `k = Σ(t×d) / Σ(t²) = 0.105348794942645` 거리/초다.
- 본편 의뢰의 `dist=max(1,Distance)`와 `hours=dist*9+8`을 그대로 비교했다. 시간이 아니라 거리만 반올림한 대안도 함께 계산했다. 소수 거리 채택이나 반올림 정책을 결정한 것은 아니다.
- 걷기 속도를 일괄 변경하거나 초를 게임 시간으로 바꿔도 최소제곱 비율이 반대로 변하므로 `k×t`와 이 충돌은 같다. 가속·페이드·길 위 사건 등 고정 지연은 이번 도식 길 계산에 넣지 않았다. 실제 길 통행·B2 지형 검사는 아니다.

## 고려 10쌍의 기한 비교

기한 단위는 본편 게임 내 시간. 마지막 열은 거리만 가까운 정수로 반올림했을 때이며, 반올림 선택에 따라 해결되는지 보는 보조 계산이다.

## 최소제곱 이외의 단일 비율도 불가능

나루–장단의 기존 기한은 44시간이다. ±10%를 지키려면 `k`가 **0.349182~0.446422**여야 한다. 나루–송악의 기존 기한은 17시간이고 허용 상한은 **0.044090**다. 두 구간부터 서로 겹치지 않는다.

거리 정수 반올림도 나루–장단은 **0.348077~0.447527**, 나루–송악은 최대 **0.055628**다. 반정수 경계값을 모두 허용하는 넓은 구간으로 잡아도 겹침이 없어, ties-to-even/half-up 차이로 해결되지 않는다.

전체 10쌍의 허용 비율 교집합은 `calibration.json`에 있다. 소수/정수 모두 하한이 상한보다 커서 비어 있다.

## Claude에게 필요한 판단

1. 4절의 **단일 시간 환산·기존 공식 유지**와 **10쌍 모두 경제 차이 ±10%** 중 충돌 시 어떤 기준을 수정할지 정해 달라. 예를 들면 허용 변화폭 수정 또는 구간별 보정 허용은 서로 다른 설계 변경이며 Codex가 채택하지 않았다.
2. 정해진 기준으로 거리 자료형·반올림과 상품 가격/보수/기한의 회귀 허용 조건을 명시해 달라. 본편 세 함수는 현재 정수 거리이며, 보수에는 기존 BFS와 맨해튼의 서로 다른 경로가 있으므로 통일 후 모두 비교해야 한다.
3. B2에서 실제 통행 길 길이로 재계산하는 조건은 유지한다. 이번 문제를 통과시키려고 승인된 마을 좌표/길 모양을 임의 변경하지 않는다.

## 완료 범위와 실행 결과

- 추가: `Tools/Routing/check_distance_calibration.py`, 회귀 검사 8개, 원본 SHA-256/전체 36개 내부 최단 경로/고려 10쌍/허용 비율 교집합을 담은 `calibration.json`. 본편 코드·지도·그림·ID·저장 형식은 변경하지 않았다.
- 정적 검사: 전체 Python **132개 통과**(기존 124+신규 8). 가중 최단 경로는 독립 Floyd–Warshall 계산으로 36쌍 대조, 속도 배율 상쇄·최소제곱 최적성·실현 불가능 구간·소스 변경 감지·보고서 재현을 검사했다.
- 기존 세계 검사: **오류 0, 등록 출구 92개**. 별도 수학 검사 명령은 **종료 코드 2**로 불충족을 정확히 반환한다. 테스트 통과는 E1 완료나 경제 조건 통과를 뜻하지 않는다.
- 미실행/미완료: Unity 검사·실제 이동·저장 회귀·수동 플레이·게임 빌드. 세 거리 함수의 본편 통일, 지도 연결, 상품 가격/보수 전체 비교표와 ±10% 회귀도 아직 미완료다. 기한 조건부터 불가능하므로 임의 정책으로 구현하지 않았다. 진행 중 의뢰의 수락 당시 조건 보존은 다음 실제 구현 때 다시 검증해야 한다.
- **E1 미완료·Claude 검토 대기. 사용자 지정 선행 순서에 따라 B2 → R2 → C3a → C6도 시작하지 않았다.** 화면 변화가 없어 새 아트 승인 요청은 없다.

# T1f 짧은 트랜지션 복원·이웃 맵 표시 최소화

사용자 지시: 무연출 이동은 렉이 심하게 느껴져 페이드를 복원한다. 실제 경계 너머로 이웃 맵을 넓게 보여 캐릭터가 화면 중앙에서 갑자기 전환되는 것처럼 보이는 원인을 바로잡는다. 승인 카메라/실제 지형·이동 판정은 유지한다.

## 구현

- 같은 지역 이동은0.10초 커버/0.14초 리빌 복원. 고려↔중앙은 기존 지역명 연출/시간 유지. 같은 지역 자동 도착 팝업은 계속 생략.
- 완전히 덮인 한 프레임을 먼저 표시한 뒤 씬 로드를 시작해 로딩 정지가 게임 화면에 그대로 노출되지 않게 한다. 실제 로딩 시간/FPS 개선을 보장한다는 뜻은 아니다.
- `m4_export.py --isolated-views`가 현재 맵의 실제 소유 칸을 `viewOwnership`으로 내보낸다. 넓은 CameraBackdrop은 생성하지 않는다. 전체 지형 원본·그림·논/숲·움직임 데이터/ID는 바꾸지 않는다.
- Scene importer는 현재 맵과 바깥 한 칸의 렌더링 타일만 불러온다. 더 먼 이웃 그림은 Tilemap에 놓지 않으며 그 타일만 쓰는 에셋도 불러오지 않는다.
- MapViewBoundary는 경계 밖 한 칸에서 어두워지는 **표시 전용 mesh1개**를 만든다. 안쪽은 투명하며 외곽은 기존 어두운 배경색으로 가린다. PNG 자르기/색 변경이나 지형 재제작이 아니다. 셰이더를 씬에 참조로 보존한다. 프레임마다 만들지 않고 씬 로드 때 한 번 생성·해제한다.
- CameraFollow/MapExit/PlayerMotor, 기존 충돌·저장 형식·시장/NPC/퀘스트/출구/도착 ID 변경 없음. 13맵 검토본에만 새 표시 데이터를 연결했다. 본편 Maps/Scenes/DB/색인/빌드목록·원격 미반영.

## 실행 결과

- Python **345실행,16skip,실패0**. 추가2개 검사는 소유 마스크/넓은 배경 제거/비소유 통행 금지 보존/먼 이웃 렌더링 감소를 확인한다.
- Unity 컴파일 오류0, URP2D Sprite-Unlit 셰이더 존재/지원 확인.
- 나루·송악·장단·중앙 동문 마을4곳의 실제 길 출구에서 기존 본편과 검토본을 동일한 발 위치/카메라로 촬영. **9426확인 통과**: 카메라 위치 동일, 먼 이웃 타일 로드0, 추가배경 없음, 표시mesh 존재. 실제 PNG는 `ArtReview/MapIsolation-20261030/Edges/`.
- 169경로 정책/실제6회 이동·페이드·지역명·도착 알림·저장 차단·검토 맵 연결 **543확인 통과**. 같은 지역/지역 간 모두 로드를 덮는 프레임 확인. 같은 지역 팝업 없음. 결과는 `Travel/checks.json`.
- 검토 메뉴로 임시 빌드 경로를 후보13맵으로 연결한 뒤 실제 TravelTo6회를 실행하고, 매 도착이 previewOnly+새 표시 경계인 것을 검사했다. 종료 시 빌드 설정 원본 복원 확인. 본편 세계1408출구 오류0.
- 13맵 합산 기본층 배치 슬롯88,218→62,633(먼 이웃25,585 제외). CameraBackdrop27,764슬롯도 제외. 이는 정적 렌더링 데이터 수이며 실측FPS/로드 시간 수치가 아니다. 표시용mesh는 맵당1개 추가된다.
- 합성 인증54원본/1670합성칸 오류0. 기존 넓은 배경 포함87원본/3293칸보다 적다. 지형 원본 자체는 바꾸지 않았다.

## 검토 방법

Unity 메뉴 **Pocket Caravan → Review → 맵 경계 검토 (이웃 최소 표시)** 를 사용한다. 단일 검토 씬에서 일반 Play만 시작하면 다음 이동이 원래 본편 씬으로 갈 수 있으므로 이 메뉴가 후보13맵 경로를 임시 연결한다. Play 종료 후 원래 빌드 설정이 복원된다. 이 임시 변경은 커밋/본편 등록이 아니다.

경계 그림 모음은 `ArtReview/MapIsolation-20261030/boundary-comparison.png`다. 새 표시를 승인한 뒤에만 본편 연결을 진행한다. 적용 후보 생성 명령은 기존A7e export 명령에 `--isolated-views`를 추가하고 `VillageFillReview.Build()`로 씬을 생성한다. 생성물은 직접 고치지 않는다.

사람의 실제 WASD/장시간 체감, 실기기FPS·콜드 로딩 시간 벤치마크, 모든 화면비/플레이어 빌드, 실제 저장 파일 전후 해시는 미검사다. 이동 검사는 자동 코드가 실제 TravelTo를 호출한다. 코루틴의 로드·스폰·시간·저장 처리 순서는 유지했다. 원격 통합 시 공용 GameManager 변경과 임포터/새 표시 필드를 설명하고 팀 사전/완료 공지가 필요하다.

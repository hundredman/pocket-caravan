# 네 문명 매매 튜토리얼 안내 문구

2026-11-08 Codex. 사용자 최종 지시: 퀘스트 위에 표시되는 설명만 수정한다. 고려뿐 아니라 다른 문명도 확인하여 같은 문구로 맞춘다.

- 구매: `상인에게 물건 하나 구매하기`
- 판매: `산 물건을 다른 마을 상인에게 판매하기`

고려·북유럽·베네치아·아라비아의 Intro.Tasks 5/6만 바꿨다. 원래 네 지역 모두 특정 마을 장터에서 사기/장터에 다시 팔기였다. 완료 판정/실제 매입·판매 규칙/퀘스트 이름·ID/대사/보상/저장은 바꾸지 않았다. 특히 다른 마을 판매를 완료 조건으로 새로 강제한 것은 아니다. 사용자가 문구만 수정하라고 정정한 범위다.

Unity 컴파일/최종Console오류0, SaveOFF·별도슬롯·NetLogin비활성·Offline에서 네 시작 씬 각단계7/8 실제8캡처 확인(`results.json`). [네 문명 안내 비교](../../../ArtReview/Goryeo-Trade-Wording-20261108/comparison.png). 표시문구 외 코드가 달라지지 않은 것을 HEAD대조로 확인(`source-scope.json`). 첫 임시 이미지 조립은 시스템 Python의 Pillow 누락으로 실패했으며 기존 Pillow환경으로 재실행했다. 중간 문구 캡처3개는/tmp로 옮기고 최종8개만 저장했다.

문자열2개×4파일의 작은 수정이므로 전체Python회귀/세계검사/실제매매/저장복원/빌드는 재실행하지 않았다. 최신main포함·로컬커밋만, 원격미반영. 다른문명 전용파일 변경은 사용자 이번 지시에 따른 위 문구2개로 한정했다.

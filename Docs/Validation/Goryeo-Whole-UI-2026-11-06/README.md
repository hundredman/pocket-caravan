# 게임 UI 1차 점검 근거

[판정·다음 순서·미확인 범위](../../Goryeo/UI-Audit-2026-11-06.md)를 참고한다.

- `ArtReview/Goryeo-Whole-UI-Audit-20261106/play.json`: 최종 검토58확인/실제 게임 화면26장. UI 열기/닫기·캡처·슬롯 격리 검사이고 게임 전체 기능 검증58개라는 뜻이 아니다.
- `ui-surface-inventory.json`: OnGUI 소스61개 목록(타 문명 전용27). 창 형태의 문자열 검색 결과이며 전체 소스 정밀 감사/실행 결과가 아니다.
- `fixture-history/duplicate-slot-guard.json`: 중복 인스턴스가 서로 다른 임시 슬롯을 고른 시도. 실패로 기록하고 깨끗한 Play에서 단일 인스턴스로 재실행했다.
- 콘솔 error0, 기존 사용자 저장9파일 해시 불변·임시 저장0. 온라인 연결/실제 구매/수면/기증·사용자 저장 쓰기는 하지 않았다.

그림의 잘림 문제는 실제 캡처와 표시 코드로 대조했다. 480×270/960×540 문명 선택·4개 선택지 대화가 우선 수정 대상이며, 아직 해당 게임 코드를 수정하지 않았다.

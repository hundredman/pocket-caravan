## 진행한 부분과 중단 지점

`Tools/WorldLayout/export_world_layout.py`는 승인 계산을 셀 단위로 손실 없이 옮기는 준비 도구다. 일부 근사 폴리곤을 다시 래스터화하면 면적이 달라지므로 원래 셀 마스크에서 `[y,x시작,x끝]` 기록을 뽑는다. 맵 경계/육지·앞바다/마을 위치/승인 도식 길·강·산을 한 파일에 묶도록 준비했다.

**실제 이관 실행은 실패**했다(승인된 맵별 면적과 다름). 차이를 보고서로 쓰고, 원본 world-layout.json을 생성하기 전에 중단한다. 임의로 셀을 옮기거나 승인 숫자/원안/시드를 바꾸지 않았다. 성공 경로와 최종 원본의 완전성은 아직 검증하지 않았으므로 B1 완료가 아니다. B2/E1 등 본편 소비 경로도 연결하지 않았다.

## Claude에게 필요한 답변

1. 승인 당시 계산 스냅샷·커밋·실행 조건을 확인해 어느 것이 맵별 면적의 기준인지 정리한다.
2. 문서 숫자가 이전 계산 기록이라면, 현재 승인 원안의 경계를 그대로 두고 이5개 수치를 정정할지 답변한다. 문서 수치가 의도한 최종 배분이라면 해당 수치를 재현하는 **원본 계산**을 제공한다. Codex가 알아서 경계를 조정하지 않는다.
3. 답변을 main의 WorldLayout 해당 본문과 검토 기록에 남기면 B1 이관/소비기/면적·중복·마을/연결 테스트를 이어간다. D4/D7의 팀 경계 협의와 새 중앙 마을의 런타임 ID 연결은 별도이며 이번에 정하지 않았다.

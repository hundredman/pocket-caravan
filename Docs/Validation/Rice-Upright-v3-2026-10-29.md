# 벼 v3 줄기 수정

사용자: 윗부분만 숙이고 아래부분은 꼿꼿하게.

- 내장 imagegen으로 아래 줄기를 곧게 재구성하고 native32×32/폭22px/7색/기존 황금 명암을 유지했다. 형태 적합성은 사용자 그림 승인 대기다.
- 크기/이진알파·황금3색 유지·Aseprite 재출력 디코딩RGBA 일치 확인.
- 같은16px 식재 간격으로 논9모듈을 재생성했다.5크기 조립과 포기 전체 직접 배치RGBA 일치·Unity Edit9모듈 연결 렌더 논 영역차이0. 원래 씬으로 복귀·본편쓰기0.
- 본편/A2/승인 원본 미변경. 실제플레이/가림충돌/애니메이션/빌드 미실행.

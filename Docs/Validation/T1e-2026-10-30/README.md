# T1e 같은 지역 이동 연출 제거

사용자 2026-10-30 지시: 고려↔중앙 대륙에만 트랜지션을 남긴다. 같은 지역의 마을·길 이동은 캐릭터가 중앙에 있을 때 불필요한 트랜지션이 나타나지 않게 한다.

고려/담당 중앙13맵 사이에서 같은 지역이면 커버·리빌·홀드·로드 뒤 대기0, 전환 Draw도 즉시 반환한다. GameManager는0초 효과의 반복문을 건너뛰고 fade를0으로 유지한다. 지역 안 자동 도착 팝업도 제거하며 현재 위치HUD는 유지한다. 고려↔중앙 대륙은 기존0.22초 커버/0.28초 리빌/0.65초 최소 홀드/0.25초 로드 후 대기·도착 지역명을 유지한다.

카메라/발 중심 경계 판정/출구·스폰/씬 로드·도착 처리/게임 시간 전진·저장 호출 순서는 바꾸지 않았다. 다른 문명은 기존 정책/기본 페이드와 자동 도착 알림을 유지한다. 연출만 제거한 것이므로 씬을 로드하는 구조 자체를 스트리밍 맵으로 바꾼 것은 아니다.

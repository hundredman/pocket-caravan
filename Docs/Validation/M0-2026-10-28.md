# M0 대응표·옛 참조

2026-10-28 Codex(`codex/m0-m1`)가 만든 M0 결과에서 M0 부분만 옮겼다. 같은 브랜치의 M1② 새 타일 작업은 폐기되어 가져오지 않는다. 참조 원본은 `ArtReview/M0/`.

### 옛 참조 조사

기계 판독 원본: `ArtReview/M0/M0-references.json`, `ArtReview/M0/old-objects.json`.

- `Assets/PocketCaravan`의 실행 코드/JSON/직렬화 자산·씬·프리팹을 조사했다. 아트와 에디터 검토 폴더는 제외했다. 조사 파일 327개, 관련 줄 748개. 경로·줄/객체 포인터·기존 맵·스폰·ID·좌표를 남겼다.
- 본편 11맵의 **모든 객체**를 수록했다. 스폰 103개, 출구 92개, 퀘스트 NPC 6개, 시장/게시판 각각 7개, 도적 1개. 대화 주민·일꾼·보행 주민 등도 객체 원본에 포함한다.
- 현행/retired 퀘스트 자산 모두 조사: giverNpc와 목표 type별 NPC/방문 맵/의뢰 마을 **34참조**를 실제 맵 배치/마을 ID로 연결했다. 출구의 목적 맵/스폰과 저장 씬의 92개 출구도 대조했다. 이 명시 참조의 미해결 **0건**.
- `WorldIndex.MapOf`와 `GoryeoLayout.Resolve` 같은 동적 조회도 관련 코드 줄에 포함한다. 의뢰/교역 거리는 `TownDistance`와 `WorldIndex`의 시장→맵 조회를 쓰므로 마을 ID·대응 맵 ID를 유지한다. 이번 작업에서 거리 함수/데이터는 바꾸지 않는다.
- 도적/길 사건은 `MapRoot.Current.mapId`, `RoadHazards`의 `e3_` 배치 식별을 사용한다. 기존 도적과 객체 정보를 보존하고 E3 새 사건은 M5에서 배치한다. 셸터 시장/NPC나 사건 위치를 새로 결정하지 않았다.
- **미해결 0은 위 명시 참조의 정적 조사 범위**다. 임의의 옛 사용자 저장/모든 동적 실행을 검증했다는 뜻이 아니다. 옛 저장 위치/스폰 좌표는 새 지형에 자동 복사하지 않고 M4 이주·플레이에서 검증한다.

### codex/b3에서 재사용할 승인

`codex/b3`의 승인 JSON을 읽어 확인했다. 브랜치 전체를 합치거나 옛 배치를 새 지형에 복사하지 않는다.

| 항목 | 근거 | 새 맵에서의 적용 시점 |
|---|---|---|
| 나루 밀도/긴 판자 길 개선 | `ArtReview/B3-Goryeo/Naru-approval.json`: “이 밀도로 승인” | M3 밀도 기준으로 재사용. 육지 흙길·물 위 짧은 잔교, 기존 건물 좌표는 복사하지 않음 |
| 송악 다리 비례 | `goryeo_songak-layout-approval.json`: “이 비례로 진행하고 스타일은 추후 확정으로.” 폭 25%/길이 약20% 감소 | M2 설계 기준. 다리의 길 방향/연결을 다시 확인. 해당 비례 승인을 그림체/본편 승인으로 확대하지 않음 |
| 장단 농경지 | 사용자 “일단 넘어가자” | 완성 그림 승인으로 간주하지 않음. M3 이후 재검토 |
| 닥목/개경 옛 시안 | 별도 완성 승인 없음; 개경 담장/돌포장 거절 | 승인 추정/배치 이식 없음 |
| C7 | 기존 승인 그림/A2 연결만 유지 | 본 작업은 지형만. 옛 맵 배치 조정 중단, C7 소품/건물 미배치 |

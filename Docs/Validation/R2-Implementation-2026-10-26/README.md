# R2 구현 완료 (Decisions 3·9절)

본편 거리 설정 current를 유지하며 평판 가격·점수·구매 조건과 거래 기록을 연결했다. 사용자 “R2 화면 승인”과 그림 해시는 approval.json에 있다. 거래 방향의 범위는 사용자가 추천 판단을 맡겨 9절을 유지했다: 최근 현지 매입분의 반환은 제한하고, 외부에서 가져온 재고를 먼저 처분하는 거래는 허용한다.

## 구현

- 매입 보정 +15/+7/0/−3/−6/−10%, 판매 가산0. 흥정 최대폭0/0/3/5/8/10%를 R3에서 쓸 수 있게 한곳에 뒀다. 현재 UI에 흥정 성공률/재시도 시스템을 새로 구현한 것은 아니다.
- 같은 시점 매입가≥판매가+1 유지. 그 뒤 같은 마을·물건의 최근 매입 기록이 남은 수량은 판매가≤평균 매입가−1을 최종 적용한다. 기록은 수량/평균가/마지막 매입 시각이며 **마지막 매입부터12게임시간** 유효하다. 추가 매입은 잔여 수량과 가중 평균을 갱신하고 시간을 다시 센다. 일부 반환은 평균을 그대로 두고 수량만 줄여 평균 기저를 높이는 악용을 막는다.
- 기록/마을별 일일 판매 누적·지급 여부를 PlayerState에 두고 저장한다. 맵을 나가도 유지하며 옛 저장은 빈 기록으로 시작한다. 선택적 schema1 블록으로 SaveData v3과 기존 시장/화물/퀘스트/시설 ID를 유지했다. malformed 기록/미등록 대상은 불러오기 전 검증한다.
- 기여 점수10/25/75/250, 단계−6000~42000와 우호 시작3000 적용. 일상 구매0, 제한되지 않은 판매만 마을별 하루50냥 도달시1회25점; 다른 평판 단위의 특산품이 포함되면75점이다. 같은 시작 문명 안은 한 평판, 중앙 마을은 별도 평판이다. 이미 완료한 보상을 재지급하지 않는다.
- 나전칠기 구매만 신뢰 조건. 다른 일반7상품과 판매는 막지 않는다. 기존13시설과 보관소 신용3 조건을 유지한다. HUD/장터/지도에 신용과 별도로 평판 대상·단계·진행을 표시한다.
- NPC 상인은 개인 평판/매입 기록을 적용하지 않는 원래 시세를 쓴다. 수량 견적은 시장/매입 기록을 복제해 계산하며 실제 거래 전에 단가를 재확인한다.

## 검증과 범위

- 본편 C# 연결 .NET 스트레스 **1,290,240조합**, 가격 oracle1680. 최근 매입→되팔기 대상645120조합 중 재고가 허용한372384상황에서 **이익0건**, 동시 호가 위반0. 수량1/5/20/100·성장 켬/끔·전 단계·출신4·장날/일반일·최대 흥정 조건을 포함한다. 현금/적재/흥정 확률을 생략한 스트레스 계산이며 잠긴 품목도 보수적으로 견적을 계산했다.
- 최근 현지 매입 기록 없이 **먼저 판매→재매입**은20577개 유한 이익 사례가 남는다. 이는 9절의 매입분 반환 제한 밖으로 구분해 보고한다. 그20577상황을 기록/시장 상태를 유지해 한 번 더 반복했을 때 **반복 이익0건**이었다. 전체1290240조합 모두 초기 현금 증가0이라고 쓰지 않는다. 사용자 추천 위임에 따라 다른 마을 화물 처분을 막는 새 판매 제한을 추가하지 않았다.
- 고려의 정상 교역 견적640행에서, 출발지의 매입 기록이 다른 도착지의 판매가에 미치는 영향0을 확인했다. 이전 원시 시세/이익과 새 평판 적용 시세/이익을 calculations.json의 normalTrades에 함께 남겼다. 가격 보정 자체의 의도된 변화와 반환 제한의 영향을 구분했다.
- Unity Edit mode49개:144매입→143반환, 부분 수량 평균,12시간/다른 마을, Unity JSON 왕복/옛 기록, 실제 장터의 나전칠기 잠금/해제/적대 판매,13시설 불변, 일일 기여/재로드,0냥 반환 견적, 복제 견적 무변경을 확인했다.
- Q1 25/R6 87/저장27 통과. R6의 옛 점수0 검사는 승인된 점수표 검증으로 바꿨으며 신용/기수락 보존 검사는 유지했다. 실제 출신 시작 평판으로 Q1 100냥 시나리오를 검사: 곡식 교역 이익2냥·완료 후240냥. .NET QuestSaveProbe/ReputationProbe도 통과했다.
- Python155개·기존 출구92개 오류0. 경로 설정은 중첩 소수를6자리로 고정해9-4 환경 차이를 해결했다. B2 원본 모양이나 승인 그림은 바꾸지 않았다.
- HUD/장터/지도는 별도 previewOnly 씬에서 실제 Play 캡처 후 종료했다. 영구 플레이 저장을 쓰지 않았다. 사람이 처음부터 끝까지 한 수동 플레이나 게임 빌드는 미실행이다.

## 재현


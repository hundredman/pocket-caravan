# 연못 깊이 시안 검사

관련 검사16개 통과: pond-tests.txt 11개, team-tests.txt 5개. PNG는 크기와 디코딩 RGBA로 비교한다. 첫 검사에서는 선언 팔레트9색을 전부 사용한다고 잘못 가정해 실패했고, 실제 사용색이 후보 팔레트 안에 있으며 수면3색을 포함하는지 확인하도록 정정 후 재실행했다.

실제 Unity Play480×270 이전/수정/장식3장 생성. 전후 연못 영역 밖 픽셀 변화0, 장식 변화는 두 완전 개체 영역 안. 기존 UnityEditor.Search.SearchDatabase ArgumentOutOfRangeException1회. 캡처 완료 파일 존재, C# 컴파일 오류 기록 없음.

본편은 `nature_live.json`을 기본 생성 원본으로 읽는다. 검토 템플릿 `nature_a7d.json`은 review 상태로 유지해 승인 전 production 거부 검사를 보존한다. Headwaters catalogue의 승인 지문은 재저작 중에도 보존하고 원본이 바뀌면 재검토하도록 한다. 본편 생성 뒤 지도 지형과 물 마스크도 같은 원본에서 갱신했다.

기존 건물 교체 검사의 “모든 게임플레이 필드 불변”은 이제 자연 지형/출입구 승인 변경 때문에 그대로 적용할 수 없다. 통합 전550820eb1에서 기능물·길·크기·이름·ID를 고정한 자료를 저장하고, 승인된 출입구6건 이동만 예외로 하는 검사로 확장했다. 역사적 A7 검토의 충돌 불변 검사는 당시 바닥 해시를 사용한다. 새 본편 논8구획/외부 연결 보존 검사는 CI에서도 실행된다.

실기기 FPS/장시간 사람 플레이/모든 버튼의 실제 마우스 입력/플레이어 빌드는 미실행이다. 자동화는 실제 Unity 런타임과 이동 코루틴을 사용하며 창 열기/닫기는 검토 코드가 호출한다. 원래 사용자 저장을 직접 이어 하지 않고 격리한 임시 저장으로 복구를 확인했다.

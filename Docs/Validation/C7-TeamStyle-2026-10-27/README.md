# C7 팀 그림체 수정 검증

2026-10-27, `codex/c7`. 사용자 정정에 따라 베네치아·아라비아의 **표현 방식**을 원본에서 다시 확인했다. 그림 승인 대기, 본편 미적용이다.

## 확인한 원본과 판단

Figma의 `아트 시안` 페이지를 읽기 전용으로 조회했다. 제목 `77:5`/`92:2` 아래에서 실제 베네치아 `77:9`·`78:11`, 아라비아 `92:31`·`92:32`·`92:102`·`92:107` 이미지6개를 캡처했다. [원본 기록](../../../ArtReview/C7-TeamStyle-20261027/Reference/index.json). 팀 파일을 수정하지 않았다.

관찰상 베네치아는 넓은 지붕/벽 색면과 몇 개의 굵은 장식, 아라비아는 큰 밝은 벽과 한쪽 면 그림자·단순한 문/창을 쓴다. 땅에는 짧은 풀잎/흙 모양이 있다. 이를 기준으로 직전 시안의 빽빽한 지붕 선·작은 명암·벽 격자를 줄이는 방향으로 새 AI 원본3개→A5→Aseprite를 수행했다. 이 해석은 제작자 판단이며 기술 검사나 원본 조회만으로 사용자 그림 승인을 대신하지 않는다.

## 그림 검토 제한

팀 자료의 표시 배율은 캡처 기준이다. Figma 업로드 원본 도트 배율은 확정하지 않았다. 새 집은 같은64×48 캔버스지만 불투명 외곽 높이는39/37px로 직전보다 낮다. 비례도 사용자 검토 대상이다. 플레이어·사람NPC·작은연못은 제작자 의견으로 수정 불필요이며 승인본과 본편을 유지했다.

최종 제출은 `Submission-v5/`다. 사용자 그림 승인을 받은 뒤 나머지 C7으로 진행한다. B3 닥목/개경 후속은 기존 `codex/b3`에 별도로 남아 있다.

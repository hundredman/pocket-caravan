## 확인한 것

- 개체46종은 지형/성장 타일654키 중496키를 포함한다. 나머지158키의 조립용 지형 등록, 캐릭터·애니메이션 참조217PNG의 통합 목록 연결은 아직 하지 않았다. “모든 그림 A2 등록” 완료가 아니다.
- A2 **기존 검사기를 그대로 실행**한 결과: 개체46종의 시험 목록에서 `image_alpha` **7건 실패**. 다른 검사 오류0. 이는 온전한 개체2PNG + 그 구성 타일5PNG의 같은 반투명 픽셀을 각각 검출한 것이다. 승인 검사 제외 `--preview`이며 본편 인증이 아니다. 결과 `a2-report.json`.
- 시험용 whole PNG의 각 칸은 기존 PNG의 RGBA와 정확히 일치한다. 입력11맵·654지형PNG·217참조PNG의 해시를 저장하고 재확인했다. 일부 그림을 임의로 불투명하게 바꾸지 않았다.

## 규칙 충돌 — Claude가 확인할 항목

1. [Decisions-2026-10-25.md 2절](../../Decisions-2026-10-25.md)은 “지금 모습 그대로 '굽기'”, “본편 화면 변화 0”을 요구한다.
2. [A2 검사기](../../../Tools/MapGen/asset_manifest.py)의 `validate_catalogue/check_file`은 모든 PNG에 알파0/255만 허용하며 profile `binaryAlpha=false`도 거부한다. 이는 [ArtGuide.md 4절](../../ArtGuide.md)의 픽셀 정리 기준을 구현한 현재 규칙이다. 문서 4절 해당 단계는 AI 정리 항목 아래에 있지만, 구현은 출처/용도와 무관하게 적용한다.
3. 이미 본편에서 쓰는 아래 픽셀은 이 규칙과 양립하지 않는다. 유지 결정에 따라 마음대로 지우거나 규칙 예외를 만들지 않고 판단을 요청한다.

**권장 판단:** 이번 C6에서는 현재 승인된 그림의 반투명 픽셀도 그대로 유지한다. A2에 범용 반투명 허용이 아니라, 동결 대상 전체 PNG·타일 RGBA 해시와 근거를 명시한 기존 에셋 전용 검사 경로를 허용한다. 새 AI/일반 에셋은 기존 binaryAlpha 규칙을 유지한다. 예외 대상은 위 현재 표현에 한정하고, 이미지 변경/임의 alpha 변경/해시 누락은 검사 실패시킨다. 이는 제안이며 아직 구현/확정하지 않았다.

Claude 답변에는 허용 대상, A2의 명시적 예외 형식/범위, 위 원본 픽셀 보존 여부를 적어 달라. 다른 방향이라면 반투명 제거는 화면 변경이므로 사용자 전후 그림 승인이 새로 필요하다.

# 건물·배 전체 묶음 검토

사용자 요청: 건물은 지붕 윗면+앞면, 배는 낮은 각도에서 옆면이 보이게. 전체 작업 후 일괄 컨펌.

- 건물9+배1, 기존 캔버스 크기와 바닥 기준 유지. 내장 imagegen10원화 → NEAREST 실제 격자/기존 C7 계열 시험 팔레트 → Aseprite 원본·PNG. 전체 시안 pending, 본편 교체0.
- 정적:10개 크기·알파0/255·30색 이하·불투명 그림 존재 확인. Aseprite 원본 재출력10개는 크기와 디코딩 RGBA가 PNG와 일치한다. PNG 파일 바이트는 비교하지 않았다.
- Unity Edit 갤러리: 원래 본편 씬을 로드한 상태에서 별도 메모리 씬/레이어를 만들고 실제 기존 ground/water/player/NPC와 함께 카메라480×270으로 기존/수정6장을 촬영했다. 기존 씬 dirty 상태 불변·본편 에셋 쓰기0, 촬영 뒤 원래 씬으로 복귀. 실행 코드 컴파일 성공·콘솔 오류0.
- 시점/형태 적합성은 사용자 승인 대상이다. 실제 플레이·가림/충돌 회귀·A2 본편 교체·전체 통합·빌드 미실행.

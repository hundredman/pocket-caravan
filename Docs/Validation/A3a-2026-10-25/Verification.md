1. README 우선 항목과 inventory의 실제 사용 좌표를 대조한다. `crop`은 렌더링용 16px 분할도 포함하므로 자동으로 위반 판정하지 않는다. `placements.source`는 후처리 전 원래 스탬프이며 `finalTileFamilies`가 현재 그림이다.
2. 고해상도 원본 추출/축소, 즉석 색 변환, FIELD 언덕 조각의 밭 용도, 연못의 연꽃 개체와 물 조립 타일을 구분해 화면을 검토한다. 유지/교체/삭제는 A3b 판정표에 남긴다.
3. 사용자 결정은 기존 환경 아트 유지다. C6의 옛 출처 0개 목표와 충돌하는 유지 항목은 별도 결정이 필요하며 이번 도구는 정하지 않는다.
4. C3a는 정상 보행칸의 가림 재현을 따로 확인해야 한다. 이전 숲 화면의 진입불가칸 강제 배치는 정상 이동 오류의 증거가 아니다. 이 감사에서 가림 수정을 하지 않았다.

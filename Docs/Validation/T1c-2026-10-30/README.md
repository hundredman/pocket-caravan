# T1c 주인공 중앙 추적·맵 가장자리 고정

사용자 2026-10-30 재정정: “주인공을 최대한 가운데에 두고 코너나 가장자리로 가면 카메라를 유지”. T1b는 목표 변화만 연속적으로 만들었고 출구에 따라 중심을 이동하는 설계를 유지해 이 요구를 충족하지 못했다. 이전 검사에 중앙 추적/고정된 가장자리 기준이 없던 점을 정정한다.

## 변경

- `CameraFollow`의 출구 목록, 출구별 제한 계산, Facing/플레이어 발 위치 의존, FrameExit 강제 재배치를 전부 제거했다.
- 목표는 주인공 Transform 위치다. `MapRoot.WorldBounds`에 화면 반폭·반높이를 적용한 **고정 범위**에만 제한한다. 가장자리 한 축, 코너 두 축, 화면보다 작은 맵의 해당 축은 고정된다.
- 기존0.12초 보간은 유지하며, 보간 결과도 같은 맵 범위에 제한한다. 맵 전환 시의 새 씬 Snap은 기존대로다.
- `MapExit`는 바깥 입력/발밑 실제 경계 접촉 판정과 접촉 위치 보정만 유지한다. 출구 면을 화면 끝으로 당기지 않는다. 불규칙한 논리 구역선은 화면 끝과 다를 수 있다. 이번 사용자 재정정에 따라 중앙 추적이 우선이다.
- 지형·소품·맵 JSON/씬·DB·색인·빌드목록·기존ID/저장 형식 변경 없음. A7e 배치 검토본도 그대로다. 로컬만, 원격 미반영.

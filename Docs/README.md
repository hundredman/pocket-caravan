## 범위를 혼동하지 않기

- **지역과 맵:** main 본편은 고려9맵(수도1+마을4+길4)+중간권4맵이다. 전체 네 문명이 완성됐다는 뜻은 아니다. 북유럽4맵은 [Draft PR #2](https://github.com/hundredman/pocket-caravan/pull/2)에서 검토 중이다.
- **제작 라이브러리:** 원형40개·환경 스킨13종·날씨 표현8종·장애물48종은 별도 제작/비교 도구다. 본편에 모두 배치되거나 실제 날씨·전투·멀티까지 구현된 것이 아니다.
- **운반:** 신규 주행 낙하·누적 게이지·안정화 정차는 제거했다. 감속을 보여 주는 시각 흔들림과 구 저장 복원은 유지한다. 기존 도적 약탈은 별도 규칙이다.
- **멀티:** 초기 MVP는 기본 시스템 후2~4명 실제 검증, 최종 목표는 MMORPG다. 현재 온라인은 미구현이다.
- **아트:** 플레이어 동물 설정과 임시 NPC 그림, 사람 NPC1안 시안은 구분한다. 3D/3인칭 실험은 보존하되 현재 main 제작 기준은2D 탑다운이다.
- **날짜:** 사용자 확인 마감은11월 초다. 발표 제출은10월19일07:00, 발표+질의응답은 팀당10분이다. 두 마감은 별개다.

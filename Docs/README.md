| 문서 | 용도 |
|---|---|

| [전체 요구·구현·누락 대조](RequirementsAudit.md) | 원본·후속 요구 58개 추적, 재현 결함과 수정, 남은 저장/경제/멀티 위험, 회귀 검사 실행법 |

| [개발 기준안](GameDesign.md) | 게임의 목표, 2D 품질·여정·이동·교역·UI 기준 |

| [개발·검증 계획](DeliveryPlan.md) | 기본 시스템 → 2~4명 멀티, 4주 배치, 검증 표, 팀 결정 목록 |
| [개발 검토 기록](DevelopmentReview.md) | 현행 코드와 기획의 차이, 우선 위험과 근거 |

사용자 확인: 기본 시스템이 선행 단계이며, 4주 최종 목표는 2~4명 실제 멀티플레이와 가능 시 추가 인원 검증이다.
현 제작 계획은 2D 우선이다. 2~4명 목표와 장기 MMORPG 용량을 구분한다.

문서의 ‘제안/결정 대기’는 팀 승인이나 구현을 뜻하지 않는다. 현재 코드는 로컬 프로토타입이며, 온라인 전환 완료를 선언하지 않는다.
새 결정은 `DeliveryPlan.md` 결정 목록에 날짜·결정자·이유를 기록하고 관련 문서를 함께 갱신한다.

# Pocket Caravan 개발 문서

> **현재 구현 추적:** [개발 진행표](DevelopmentStatus.md)를 먼저 확인한다. 아래 검토 당시의 ‘4맵·마을2·시설/낙하 제거 미구현’은 이전 기준선이다. 이번 구현은 6맵·수도1+마을4·로컬 시설3종이며, 사용자 후속 확인에 따라 감속을 나타내는 시각적 흔들림은 유지한다. 기획/검증/미완료는 진행표에서 구분한다.

> **10월17일 전체 재대조 교정:** 스타팅 지역은 수도1+수도 외 최소 마을4, 이미 발전한 지역·자유 이동·마을 등급/개인 신용별 시설 이용이 제작 범위다. 재검토 당시 고려는 수도1+마을2+길1로 미달이었으며 후속 개발로 구조를 채웠다. 최신 상태는 개발 진행표를 따른다. [전체 누락 교정](FullRequirementsReview_2026-10-17.md)와 [고려 제작 명세](GoryeoRegionSpec.md)를 우선하며 이전 최소 거점/미정/검토 중단 표현을 현재 범위로 재사용하지 않는다.

기준일: 2026-10-17. 개발 정리는 **해야 할 일 → 파트별 일정 → 검증/결정** 순서로 읽는다.

사용자 확인: 초기 4주 MVP는 기본 시스템 선행 후 2~4명 실제 멀티플레이 검증이다. 최종 목표는 MMORPG 규모의 다중 접속 교역 세계이며, 2~4명은 최종 정원이 아니다. 장기 인원·혼잡도·인프라 예산은 단계적으로 구체화한다.
현 제작 계획은 2D 우선이다. 전체 구조 변경은 종합 검토를 먼저 하며, 후속 요청으로 팀 검토용 고려 지역 프로토타입 개선을 재개했다. 최신 적용 범위와 확인 방법은 위 프로토타입 문서에 기록한다.

2026-10-16 사용자 확인 마감은 **11월 초**다. 회의 자료의 지역 담당은 고려 은샘·베네치아 윤채·아라비아 은인·북유럽 기우다. 정확한 마감일·공통 기능 분담/가용시간은 미확정이다. 기존 일정의 기능별 A~D 배정안과 회의의 지역 A~D 코드는 구분한다. 11월1일 MVP 후보 전달은 역산을 위한 제안이며 새로 4주가 남았다고 계산하지 않는다.

문서의 ‘제안/결정 대기’는 팀 승인이나 구현을 뜻하지 않는다. 현재 코드는 로컬 프로토타입이며, 온라인 전환 완료를 선언하지 않는다.
새 결정은 `DeliveryPlan.md` 결정 목록에 날짜·결정자·이유를 기록하고 관련 문서를 함께 갱신한다.

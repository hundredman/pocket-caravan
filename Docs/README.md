사용자 확인: 초기 4주 MVP는 기본 시스템 선행 후 2~4명 실제 멀티플레이 검증이다. 최종 목표는 MMORPG 규모의 다중 접속 교역 세계이며, 2~4명은 최종 정원이 아니다. 장기 인원·혼잡도·인프라 예산은 단계적으로 구체화한다.
현 제작 계획은 2D 우선이다. 전체 구조 변경은 종합 검토를 먼저 하며, 후속 요청으로 팀 검토용 고려 지역 프로토타입 개선을 재개했다. 최신 적용 범위와 확인 방법은 위 프로토타입 문서에 기록한다.

2026-10-16 사용자 확인 마감은 **11월 초**다. 정확한 날짜·실제 팀원 분담/가용시간은 미확정이다. 11월1일 MVP 후보 전달은 역산을 위한 제안이며 새로 4주가 남았다고 계산하지 않는다.

문서의 ‘제안/결정 대기’는 팀 승인이나 구현을 뜻하지 않는다. 현재 코드는 로컬 프로토타입이며, 온라인 전환 완료를 선언하지 않는다.
새 결정은 `DeliveryPlan.md` 결정 목록에 날짜·결정자·이유를 기록하고 관련 문서를 함께 갱신한다.

# 10월17일 기획 변경과 적용 상태

> **현재 구현 추적:** [개발 진행표](DevelopmentStatus.md)를 먼저 확인한다. 아래 검토 당시의 ‘4맵·마을2·시설/낙하 제거 미구현’은 이전 기준선이다. 이번 구현은 6맵·수도1+마을4·로컬 시설3종이며, 사용자 후속 확인에 따라 감속을 나타내는 시각적 흔들림은 유지한다. 기획/검증/미완료는 진행표에서 구분한다.

> **10월17일 전체 재대조 교정:** 스타팅 지역은 수도1+수도 외 최소 마을4, 이미 발전한 지역·자유 이동·마을 등급/개인 신용별 시설 이용이 제작 범위다. 재검토 당시 고려는 수도1+마을2+길1로 미달이었으며 후속 개발로 구조를 채웠다. 최신 상태는 개발 진행표를 따른다. [전체 누락 교정](FullRequirementsReview_2026-10-17.md)와 [고려 제작 명세](GoryeoRegionSpec.md)를 우선하며 이전 최소 거점/미정/검토 중단 표현을 현재 범위로 재사용하지 않는다.

이 문서는 사용자가 확인한 최신 결정과 아직 구현되지 않은 부분을 구분한다. 이전 PDF·회의 초안·실행 검사·검토용 수치는 과거 근거로 보존하며 최신 사양으로 자동 재사용하지 않는다.

## 1. 확인한 결정

| 항목 | 최신 방향 | 경계 |
|---|---|---|
| 운반 페널티 | 주행 중 물품 낙하·반복 회수를 제외하고 노면·적재량·수단에 따른 감속 중심 | 흔들림 누적→정차 안정화 요구를 이름만 바꿔 유지하지 않음 |
| 고려 | 정보·판단·기회 포착 | 소식 범위·갱신·공유·배율 미확정 |
| 아라비아 | 적재 보너스·대량 수송 | 적재량/적용 수단·배율 미확정. 이전 큰길 적재 감속 완화안을 최종으로 간주하지 않음 |
| 베네치아 | 판매·중개·거래 조건 | 실제 재고 보존. 판매 보정 방식·배율 미확정 |
| 바이킹·북유럽 | 이동 보너스·기동·회전율 | 험로에만 한정하지 않음. 상시/적재 조건·수단·배율 미확정 |
| 맵 | 일반 플레이어에게도 의미 있는 길·물량·중간 거래 선택 | 바이킹만을 위해 오솔길을 강제하거나 지형을 채우지 않음 |
| 역사 표현 | 교역망·장비·기술·경험을 능력으로 각색 | 민족의 선천적 능력, 고려 정보 우위·바이킹 육상 속도를 입증된 사실로 소개하지 않음 |

길 개척은 10월16일 회의 방향에서 제외하고 정해진 교역로를 개발한다. MMORPG 목표와 초기 2~4명 검증, 자유로운 마을 이동과 신용 해금은 유지한다. 도적 강탈·의뢰 기한/배상 등 모든 손실을 제거한 결정은 아니므로 별도 범위로 확인한다.

## 2. 적용 상태

| 대상 | 상태 |
|---|---|
| 기획·작업 목록·서버 설계·팀 안내 | 이번 문서 동기화에 최신 결정 반영 |
| 발표 자료·대본 | 최신 기획으로 갱신. 기존 스크린샷은 이전 로컬 규칙의 화면으로 표시 |
| 현재 PlayerController/HUD/시험장 | 신규 주행 낙하·누적 게이지 제거. 시각적 흔들림 유지. 구 저장 이주 검사, 자세한 상태는 DevelopmentStatus.md |
| 현재 OriginData/Origin 에셋 | **이전 장부·판매·장거리·험로/속도 값이 남아 있음. 새 적재/이동 밸런스 미적용** |
| 기존 실행 파일·저장 | 이전 버전. 새 기획이 적용된 빌드/저장이 아님 |
| 다른 팀원 지역·능력 | 동시 개발 중. 공용 변경 전에 실제 브랜치/필드 사용처를 대조 |

과거 `ledgerStaleMultiplier=0.5`, 판매 재고증가0.8, 장거리판매+5%, 전체속도+5%/풀밭×1.3 및 검토 중 제시한 12%/15%/87%는 최신 확정 수치가 아니다. 아직 정하지 않은 새 배율을 문서 정리 과정에서 임의로 확정하지 않는다.

## 3. 후속 구현 작업

- **MV-01:** 주행 낙하 호출·흔들림 HUD·정차 안정화·회수 안내 제거, 노면/수단/적재 감속 비교.
- **MV-02:** 이전 낙하물의 수량·원가·활성 의뢰를 일회성 이주. 백업·버전·중복 복구·초과 적재·알 수 없는 ID 검사. 단순 목록 삭제 금지.
- **ORG-01:** 정보·적재·판매·범용 이동을 공통 데이터/계산에 반영. 선택·originId 저장·출신별 적재 한도·지역 전환·서버 행위자 검증. 기존 배율 중첩 방지.
- **UX/시나리오:** 낙하/회수·파손을 요구하던 목표·대사·표지·백과·시험장 UI를 새 경험에 맞게 수정. 기본 가격/물량 정보는 모든 출신에게 제공.
- **밸런스:** 단가 보너스 대신 실제 매매차익·왕복 시간·수레 구입 시점·선택 물량/길·피로를 기록. 초보/숙련·혼자/파티를 구분하고 재고 변화·정보 공유를 포함.

낙하를 제거해도 현재 시장에서 대량 거래가 손해일 수 있다. 적재 보너스를 ‘실제로 더 많이 벌 기회’로 만들려면 품목/판매처 분산·소비 거점·의뢰 운송과 함께 검증한다. 이동 보너스도 메뉴·거래·빈 귀환을 포함한 실제 효율로 평가한다.

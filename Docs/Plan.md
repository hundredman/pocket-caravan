# 작업 계획

정리: 2026-10-24. 범위는 은샘 담당(고려 + 중앙 대륙 동쪽)의 배경·맵·아트 재정비와 중앙 대륙 시스템이다.
어느 에이전트(Codex, Claude)든 이 표에서 작업 하나를 골라 이어서 할 수 있게 적는다.

**사용 규칙**
- 작업을 시작하면 상태를 `진행 중`으로, 끝나면 `완료`로 바꾸고 [작업 기록](WorkLog.md)에 한 줄 남긴다.
- `결정 대기`에 걸린 작업은 시작하지 않는다. 결정이 나면 결정 표를 먼저 고친다.
- 완료 기준을 실제로 확인하지 못했으면 `완료`로 바꾸지 않는다. 확인하지 못한 항목을 작업 기록에 적는다.
- 새 작업이 생기면 같은 형식으로 표에 추가한다. 작업 ID는 다시 쓰지 않는다.

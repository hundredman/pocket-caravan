# 세계 배치

정리: 2026-10-24. 원칙은 [방향 기준](Direction.md) 3절이다.
**고려 배치는 검토안 단계다. 사용자가 승인하기 전에는 맵·씬·생성기에 반영하지 않는다.**

## 1. 면적과 담당

| 구역 | 면적(칸) | 담당 |
|---|---:|---|
| 중앙 대륙 전체 | 100,000 | 4명이 1/4씩 |
| └ 중앙 대륙 동쪽 | 25,000 | 은샘 |
| 고려 (동) | 20,000 | 은샘 |
| 북유럽 (북) | 20,000 | 기우 |
| 베네치아 (서) | 20,000 | 윤채 |
| 아라비아 (남) | 20,000 | 은인 |

1칸 = Unity Grid 1칸. 바다·산·건물을 포함한다. 은샘 담당 합계는 45,000칸이다.

## 2. 좌표 약속 (검토안 기준)

- 중앙 대륙 중심을 (0, 0)으로 둔다. x는 동쪽, y는 남쪽이 +다.
- 검토안은 중앙 대륙을 넓이 100,000칸의 원(반지름 약 178칸)으로 단순화했다. 실제 해안선 모양은 팀이 정한다.
- 방향은 시계로 부른다. 12시가 북, 3시가 동이다.
- 중앙 대륙 동쪽 담당은 **1시 30분~4시 30분**(90°)으로 잡았다. 원이면 정확히 25,000칸이다. 사용자 지시는 "대략 1~2시부터 4~5시"이므로, 경계 각도는 이웃 담당자와 합의해 정한다(결정 대기 D4).
- 이 좌표는 땅의 위치(지리)다. 시세 계산에 쓰는 경제 좌표(`TownData.worldCoord`)와 따로 관리한다.

## 3. 고려 배치 검토안 A

그림: [Figma `고려 배치 검토안` 페이지](https://www.figma.com/design/JeXCjYTYRGtV8FCnXWWiqe/?node-id=131-2)
계산 원본: `Tools/WorldLayout/layout_proposal.py`. 실행하면 칸 수와 윤곽 좌표가 나온다.

| 구역 | 위치 | 면적(칸) | 성격 |
|---|---|---:|---|
| 개경 | 중심 | 5,000 | 수도. 궁성·시전·객주. 처음 볼 때 웅장해야 한다 |
| 닥목 | 북 | 3,750 | 숲 계곡, 한지 작업장. 강이 시작하는 곳 |
| 나루 | 동 | 3,750 | 동해안 포구. 튜토리얼 시작 마을 |
| 장단 | 남 | 3,750 | 황금 들판, 남해안 |
| 송악 | 서 | 3,750 | 소나무 산록. 중앙 대륙으로 나가는 관문 |
| 합계 | | 20,000 | |

- 고려 서쪽 면이 중앙 대륙 동쪽 해안선과 **약 123칸 폭으로 맞붙는다.** 고려 남북 길이의 약 3/4이다. 해협이나 좁은 길이 없고 숲·산록·들판이 그대로 이어진다.
- 바다는 고려의 북·동·남 바깥 해안에만 있다.
- 강은 닥목 계곡에서 시작해 개경을 지나 나루 하구로 흐른다.
- 길은 개경에서 네 마을로 뻗는다. 서쪽 송악에서 여러 갈래로 중앙 대륙에 들어간다.
- 진행 흐름: 나루(시작) → 개경(수도) → 송악 → 중앙 대륙 동쪽.

### 사용자에게 검토받을 것

1. 네 마을 방위: 북 닥목 / 동 나루 / 남 장단 / 서 송악
2. 시작 마을 나루를 대륙 반대편 동해안에 두기
3. 면적 배분: 개경 5,000칸, 마을 각 3,750칸
4. 대륙과 맞닿는 폭 약 123칸
5. 중앙 대륙 동쪽 범위 1시 30분~4시 30분

검토 결과는 이 절과 [방향 기준](Direction.md)에 반영하고, [작업 계획](Plan.md)의 D1 상태를 바꾼다.

## 4. 승인 후 구현할 때의 원칙

- **원본 하나:** 세계 배치 원본 파일(좌표·면적·구역 경계)을 하나 두고, 지형 생성기·지도(M)·씬 등록이 모두 그 파일을 읽는다. 지도에만 지형을 덧그리지 않는다.
- **씬 나누기:** 한 구역을 한 씬으로 만들지, 일정 크기 조각으로 나눌지는 기술 결정이다(D5). 어느 쪽이든 경계에서는 길 하나가 아니라 **걸을 수 있는 경계 전체**가 이어져야 한다. 마을 이동은 페이드로 연출한다(10/23 회의).
- **기존 시스템 보존:** 시장·상품·퀘스트·NPC·시설 아이디와 저장 데이터는 유지한다. 위치가 바뀐 저장은 이주표(`Resources/GoryeoLayout.json` 방식)로 옮긴다.
- **면적 검사:** 생성 결과의 칸 수가 1절 표와 맞는지 자동 검사한다.

## 5. 현재 구현과의 차이 (2026-10-24)

현재 맵(고려 5씬 + 중앙 6씬)은 새 방향과 다르다. 다시 만든다.

- 고려 다섯 권역이 개경을 중심으로 모여 있지 않고 길을 따라 이어져 있다.
- 고려가 중앙 대륙과 좁은 땅으로만 연결되어 따로 떨어진 직사각형 섬처럼 보인다.
- 중앙 동쪽 6맵은 직사각형을 이어 붙인 형태이고, 대륙 전체에서의 위치(1~2시~4~5시)를 기준으로 만들지 않았다.

# UI1 공용 창 테마 연결

2026-11-07 정리. 문명 선택/대화 배치는 사용자 “이대로 승인”으로 확정됐다. 이어 소지품·게임 메뉴·상업 백과·여관에 기존 CuteUI 공용 종이 창·제목·버튼·글자를 연결했다. 새 네 창의 그림은 승인 대기다.

소지품은 물품 수와 창 너비에 따라 열수/스크롤을 조절하고 선택한 물품을 드러낸다. 설명·배달 목록은 각각 스크롤한다. 속죄 의뢰의 예치금 반환을 표시한다(보상 규칙 변경 없음). 백과 제목은 줄바꿈하고 본문/목록을 따로 스크롤한다. 게임 메뉴의 긴 불러오기 안내도 버튼을 밀어내지 않는다. 여관은 작은 부가 설명을 본문 크기로 표시한다. 기존 비용/휴식/저장/메뉴 처리 콜백은 유지했다.

## 실행한 검사

- Unity 컴파일 Console error0. 저장OFF 자동 Play221확인, 실제 GameView 캡처13장. 480×270,360×270,960×540 사용.
- 실제 I/방향키/Esc 입력으로 소지품 선택/닫기와 메뉴의 다른 창 입력 차단을 확인했다. 빈 소지품·실제 상품18종·검토용 배달3건으로 마지막 선택/스크롤과 창 내부 범위를 확인했다. 의뢰3건은 합성 표시 자료이며 자연스러운 의뢰 수락 검사가 아니다.
- 고려/베네치아의 기존 백과 데이터와 긴 목록/본문, 좁은 창을 확인했다. 목록 선택/스크롤 위치는 검토 도구가 설정했으며 네이티브 마우스 클릭은 하지 않았다.
- 여관 실제 Offer/CloseAsk/Rest 콜백으로 취소 시 돈 불변, 돈 부족,15냥·4시간·체력 회복 및8시간 버프를 확인했다. 가상 키보드로 IMGUI 클릭/Esc까지 실행한 검사는 아니다.
- Python403개(23skip), 실패0. 월드 검사 결과는 validation 로그 참조. 기존 Editor8종/별도 Python환경/FPS는 이번에 다시 검사하지 않았다.
- 이번 QA 시작 시 존재한 저장8파일 SHA256 불변, 검토용 임시 저장0. 본 저장 pocket_caravan_save.json은 검사 전부터 없었다. 앞선 /tmp/goryeo-ui1-save-backup-20261106 백업은 남아 있으며 원인 추정이나 임의 복원은 하지 않았다.

# 첫 대화 안내 가림과 작은 추적 안내 (2026-11-07)

사용자는 첫 ‘Space로 말을 걸어 보세요’ 안내가 보이지 않는다고 제보했다. 기존 고려 튜토리얼의 y=30, 높이20 배너가 HUD 초상화/상태창(y=5~45)과 겹쳐 앞부분이 가려지는 것을 기존 실제 캡처에서 확인했다.

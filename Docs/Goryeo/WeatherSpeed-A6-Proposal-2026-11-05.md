# A6 날씨별 이동 속도 제안

상태: 사용자 조건 반영 후 재설계 대기. 속도 코드는 아직 바꾸지 않았다.

사용자 조건: 평상시에도 흙길은 풀밭보다 조금 더 빨라야 하며 비가 와도 이 관계를 유지한다. 날씨 감속률만이 아니라 같은 출신·짐·운송수단·달리기 조건의 실제 최종 속도로 비교한다. 아래 최초 제안은 승인되지 않았으며 그대로 구현하지 않는다.

| 현재 날씨 | 흙길 속도 | 같은 거리 이동 시간 | 풀밭·나무다리·돌바닥 |
|---|---:|---:|---:|
| 맑음·안개 | 100% | 기존과 같음 | 100% |
| 봄비 | 97% | 약 3.1% 증가 | 100% |
| 장맛비 | 94% | 약 6.4% 증가 | 100% |

최초 제안의 문제: Vehicle_Walk 실제 길 등급0/1/2/3 계수는1/1.05/1.1/1.1이고 고려 출신 풀밭 계수는1이다. 평상시 등급1 흙길은 풀밭보다5% 빠르지만 최초 봄비안은1.05×0.97=1.0185(1.85% 빠름), 장맛비안은1.05×0.94=0.987(풀밭보다1.3% 느림)로 역전된다. Viking 출신은 풀밭 계수1.3도 있어, 단순히 풀밭 감속률을 조금 더 크게 잡는 것으로 모든 출신에서 조건을 만족하지 못한다.

수정안의 필수 조건은 맑음/비 모두 실제 흙길 속도 > 실제 풀밭 속도다. 추천 비교 기준은 풀밭을 흙길 실제 속도의95% 이하로 두는 것이다. 다만 기존 출신의 풀밭 특성·운송수단 밸런스에 영향을 주므로 최종 수치/적용 방식을 임의 확정하지 않는다. 기존 특성을 보존할 방법을 Claude 검토로 넘긴 뒤 사용자 수치 승인을 다시 받는다. 본편 이동/출신 데이터는 바꾸지 않았다.

빗속 느낌의 차이는 작게 둔다. 빗속 느낌은 이미 승인된 발소리·물 튀김이 맡고, 이동 불편은 최소화한다. 비로 조작이 미끄러지거나 입력 반응·카메라·달리기 체력이 변하지 않게 한다.

고려5/중앙 동쪽8맵의 승인된 A1 실제 날씨와 A4 표면 자료를 함께 쓴다. 길 등급만으로 흙을 추정하지 않고 실제 흙길에서만 적용한다. 이동 속도 최종값에 날씨 계수 하나만 곱하며 짐·출신·운송수단·달리기·기존 길 사건 효과와 중복 누적하지 않는다. 배를 탔거나 다른 문명·표면 자료 누락·날씨 모듈 비활성인 경우에는 계수1로 복귀한다.

승인 뒤 공용 PlayerController의 최종 속도 계산에 명시적인 고려용 계수 호출이 필요한지 검토한다. 몰래 위치를 보정하거나 PlayerMotor.walkSpeed 설정값을 바꿔 우회하지 않는다. 이 공용 연결이 필요하면 변경 파일과 다른 문명 회귀 결과를 함께 기록한다.

저장 필드·가격·거래/평판 수치·게임 시계 배율은 바꾸지 않는다. 다만 느리게 걸으면 도착할 때까지 게임 시간이 조금 더 흐르는 간접 영향은 있다. 이를 숨기거나 시계를 보상 조정하지 않는다.

승인 후 확인할 것: 13맵·날씨/표면 조합, 맑음 복원/외부 지역 계수1, 실제 동일 거리 이동과 달리기/짐/운송수단/사건 조합, 상호작용·충돌·저장 호환. 수치 승인 전 구현하지 않는다.

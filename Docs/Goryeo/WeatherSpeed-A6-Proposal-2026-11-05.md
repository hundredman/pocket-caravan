# A6 지면·날씨 이동 속도

상태: 사용자 “안했다면 수정 진행해줘.” 지시에 따라 구현·검사 완료. 사용자는 “흙길이 풀밭보다는 무조건 빨라야”, “평상시에도 흙길이 풀밭보다 조금 더 빨라야”라고 정정했다. 이전 흙길만 감속하는 안은 폐기했다.

같은 출신·짐·운송수단·달리기·사건 효과에서 흙길을 풀밭보다 최소5% 빠르게 한다. 풀밭 출신 특성을 깎지 않고 해당 인물의 풀밭 속도×1.05를 흙길의 최소값으로 사용한다. 기존 길 등급의 속도가 그보다 빠르면 유지한다. 비 감속은 흙길·풀밭 둘 다 동일하게 적용하므로 역전되지 않는다.

| 날씨 | 흙길·풀밭 공통 날씨 계수 | 일반 고려 도보 풀밭 | 등급1 흙길 |
|---|---:|---:|---:|
| 맑음·안개 | 100% | 100 | 105 |
| 봄비 | 97% | 97 | 101.85 |
| 장맛비 | 94% | 94 | 98.7 |

오른쪽 두 열은 맑은 날 일반 고려 도보 풀밭을100으로 둔 상대 속도다. 높은 등급의 길이나 손수레는 원래 길 이점이 더 크면 그 이점을 그대로 유지한다. Viking 출신의 풀밭1.3배 특성도 그대로다. 이 경우 흙길의 최소 속도가 같이 높아지므로 **기존보다 일부 출신의 고려 흙길 이동이 빨라진다**. 다른 문명 맵의 출신·이동 계산은 그대로 유지한다.

최초 안의 문제: Vehicle_Walk 실제 등급0/1/2/3 계수는1/1.05/1.1/1.1이다. 흙길에만 장맛비94%를 곱하면 등급1은0.987로 마른 풀밭1보다 느려졌다. 현재는 양쪽에 같은 날씨 계수를 곱해 해결한다. 사용자 후속 수정 진행 지시가 이전 재설계 대기를 대체한다.

## 구현 범위

GoryeoGroundSpeed가 승인된 A4 실제 표면·A1 날씨 설정을 확인한다. 고려5/중앙 동쪽8 본편맵의 흙길·풀밭만 적용한다. 실제 풀밭의 길 등급은0인지도 확인하며 현재13맵 전체가 일치한다. 다른 지역/검토전용 맵·표면 누락/크기 불일치·날씨나 표면 모듈 비활성/미승인에서는 원래 계산으로 복귀한다. 나무다리·돌·기타 표면은 원래 속도다.

PlayerController.CurrentSpeed의 출신/운송수단 계산 뒤 한 번 호출하고 기존 짐·달리기·디버그·길 사건 효과를 이어 적용한다. 재산/저장/시간·입력/카메라·충돌/가감속·체력 코드는 바꾸지 않는다. 위치 강제보정/설정값 덮어쓰기는 없다. 배는 육지 흙길/풀밭 판정에 해당하지 않는다. 길 사건이 별도 감속을 주는 구간과 아무 사건 없는 풀밭의 비교까지 뒤집어 사건 효과를 무력화하지 않는다.

느리게 이동하면 도착까지 게임 시간이 조금 더 흐르는 간접 영향은 있다. 시계를 보상 조정하지 않는다. 빌드/온라인·사람 직접 체감은 별도 확인 대상이다. 최종 실행한 검사와 결과는 Docs/Validation/Goryeo-A6-2026-11-05에 기록한다.

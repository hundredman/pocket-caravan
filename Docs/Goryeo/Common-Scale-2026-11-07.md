# 고려 UI 공용 배율 통일·중복 안내 정리

2026-11-07 사용자 재수정 지시: 고려의 UI가 타 지역보다 크게 보이고, 오른쪽 아래 카드와 하단 안내의 내용/영역이 겹친다. 팀원 지역 기준으로 맞춘다.

## 원인과 수정

- 이전 UI3 검토는 글꼴 캐시·근접 표시만 보완하고 고려 전용 배율을 유지했다. 이것으로는 사용자가 지적한 크기 차이를 해결하지 못했다.
- 변경 전 고려는270기준 정수 배율·본문12/작은10·별도 GoryeoGalmuri, 타 지역은360기준 연속 배율·본문11/작은9·공용 Galmuri였다. 960×540에서 고려 본문 명목24px, 타 지역16.5px로 약45% 차이. 1280×720에서는24px/22px여서 차이는 해상도마다 다르다.
- 모든 문명에 기존 팀 기준 `VirtualHeight=360`, `Scale=Screen.height/360`, 본문11/작은9, 공용 `Fonts/Galmuri11/9`를 적용한다. 고려 전용 폰트 강제 Point/정수 배율 분기를 제거한다. 다른 문명 전용 파일은 수정하지 않는다. `CrispRegion=false`는 과거 검토 도구의 API 호환만 남기며 런타임 분기는 제거한다.
- 장터 헤더도 원래 공용의 한 줄 배치를 사용한다. 지역 도착 알림 구분은 UI 배율이 아닌 맵 소속으로 판단해 이전 동작을 유지한다.
- GoryeoIntro.Done은 단계가 바뀔 때 하단에도 ‘잘했어요! 다음: [현재 목표]’를 추가했다. 이 중복 토스트와 프롤로그 마지막의 같은 첫 대화 알림은 제거하고 오른쪽 아래 카드가 목표를 맡는다. 단계/조건/저장 메모는 그대로다.
- 보따리·지도 지급, 노잣돈/거래 결과 같은 별도 정보는 유지한다. 공용 Notify가 카드의 예약 영역과 겹치면 옆 공간, 부족하면 카드 위에 놓는다. Tab을 펼쳤을 때 카드도 공용 HUD의 하단 조작 안내 높이를 확보한다.
- 튜토리얼 카드가 떠 있는 동안 고려의 하단 ‘목표·거리’ 글씨는 중복으로 쌓지 않는다. 기존 길 찾기/화살표와 실제 퀘스트 진행은 유지하며, 튜토리얼 이후에는 기존 목표 글씨를 표시한다.

## 실제 비교와 검증

검토 전후 모두 별도 SaveOFF 슬롯. 등록된 고려 나루·베네치아 리알토·북유럽 비르카·아라비아 사나 씬을 실제 로드한다. HUD·공용 창·8단계 전환·보상 알림 겹침을 검사한다. 단계 전환 검사는 실제 Done 메서드 호출이며 사람이 튜토리얼을 완주한 결과와 구분한다. Q/M은 HUD 가상 입력, 장터/소지품은 실제 열기 메서드를 사용한다.

- 960×540 네 문명 HUD와 480×270·960×540·1280×720·1920×1080의 고려 안내 비교.
- 공용 배율/글자 크기 동일, 다음목표 토스트가8번 전환에서 추가되지 않음, 보상 토스트는 유지되고 카드와 겹치지 않음.
- 소지품·장터·여정 수첩·지도 실제 캡처 및 닫기/입력 잠금 복원 확인. Tab 확장 상태의 하단 조작 안내와 카드 간격도 캡처.
- 최종 실제 수치는 `ArtReview/Goryeo-Common-Scale-20261107/after.json`, `Docs/Validation/Goryeo-Common-Scale-2026-11-07/summary.json`. `before.json`은 기존 크기 차이/중복 토스트를 재현하는 검사이며 기존 코드 정상 판정이 아니다.
- PNG 동일성은 디코딩한 RGBA로 비교한다. 실제4문명 HUD의 돈/상태 부분은 같은 플레이어 상태로 비교해 공용 표시 크기를 확인한다.

온라인·모든 전용 미니게임·모든 탭·사람의 연속 키보드/마우스·장시간 성능·빌드는 이번 결과로 완료 처리하지 않는다. 게임 카메라/지형 크기, 시장/상품/NPC ID, 거래 규칙/가격, 보상과 저장 형식은 바꾸지 않는다. 최소 지원 해상도를 팀 규격으로 새로 확정한 것도 아니다.

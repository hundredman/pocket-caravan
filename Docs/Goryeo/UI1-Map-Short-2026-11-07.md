# UI1 짧은 지도 이름·지형 가림 보완

사용자 피드백: “지도에서 이름은 짧은게 나아.”, “그리고 이름에 지도가 조금 가려.” 앞선 긴 이름 지도는 승인 처리하지 않고 수정 요청으로 기록했다. 이번 검토판은 승인 대기다.

지도 이름표에만 짧은 이름을 쓴다. 등록 이름/하단 현재 위치/ID/저장 데이터는 유지한다. 임의로 옛 별칭(닥목·북동 포구 등)으로 돌아가지 않고 현재 이름의 핵심을 남긴다.

| 등록/기존 표시 | 지도 이름표 |
|---|---|
| 예성 나루 마을 | 예성 나루 |
| 장단 들마을 | 장단 |
| 송악 산록 마을 | 송악 |
| 닥나무 마을 | 닥나무 |
| 솔재 길목 마을 | 솔재 |
| 버들나루 마을 | 버들나루 |
| 내륙 교역 길목 | 교역 길목 |
| 버들 물가 길 | 버들 물가 |
| 북쪽 쉼터 마을 | 북쪽 쉼터 |
| 남쪽 호숫가 마을 | 남쪽 호숫가 |

개경·남동 포구·솔바람 고개·초원 진입로·남쪽 내륙길은 유지한다. 알려지지 않은 이름은 원래 이름으로 표시한다.

고려 전체/상세 이름표는 지형 바깥 양옆 두 열에 배치한다. 양쪽 총 높이 안에서 각 점에 가까운 쪽을 선택하고 행을 위아래로 정리한다. 가는 연결선으로 위치를 알린다. 좁은 창에는 양옆 공간을 확보하기 위해 지도 그림이 조금 작아진다. 지형/지도 원본 이미지 자체는 변경하지 않았다. 목적지는 기존 노란 점/바탕을 쓰고 반복되는 “· 의뢰”는 이름 뒤에 붙이지 않는다. 하단 범례는 유지한다.

공용 CuteMap에 선택 인자를 추가했으며 이 양옆 배치는 WorldMapUI에만 켠다. 다른 문명은 앞선 배치 방식/이름/배율을 유지한다. 기존 빈 곳 탐색·캐시·범례 줄 나눔도 유지한다.

## 확인

- 최종 Unity 저장OFF 자동 Play295확인·실제 GameView15캡처. 고려 전체/상세480×270·360×270, 전체960×540, 모든 현재 장터 목적지 표시480/360, 다른 핀 위치3곳, 타 문명3곳의 지도480/360을 확인했다.
- 모든 고려 캡처에서 이름표와 지형 그림 겹침0, 모든 캡처에서 이름표끼리/지도 점·현재 핀/범례 겹침0과 텍스트 수용을 확인했다. 전체13+정착지2/상세5항목을 보존했다. 모든 칸/모든 언어/모든 의뢰 조합의 보장은 아니다.
- 첫 시도는360×270 모든 목적지에서 이름표끼리 겹쳐 실패했다. 실패120확인 결과와 캡처는 first-attempt에 남겼다. 양옆 열 높이 배분과 목적지 반복 문구 제거 후 최종295확인이 통과했다. 실패를 성공으로 합산하지 않는다.
- Python403개(23skip) 통과. 이 실행은 최종 열 배분 보완 전이며 최종 C# 배치 동작은 이후 Unity295확인으로 검증했다. Python 검사가 C# 지도 동작을 검증한다고 주장하지 않는다. 최종 월드 정적 검사0오류·1437출구, 컴파일 Console error0.
- 기존 사용자 저장8파일 SHA256 불변·검토 임시파일0. 본 저장은 기존 부재 상태이며 백업을 보존하고 복원하지 않았다.

가상 Keyboard로 M/Esc를 열고 닫았다. 상세 전환/모든 목적지 상태는 검토 도구가 설정했으며 자연 수락/네이티브 버튼 클릭이 아니다. 사람 직접 플레이·실제 마우스/휠·온라인·게임 빌드/FPS·이전Editor8종은 미검사다.

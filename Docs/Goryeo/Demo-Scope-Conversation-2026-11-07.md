# 데모 시나리오 담당 범위 — 사용자 전달 대화

공유일2026-11-07. 실제 대화/회의 날짜 미확인. 사용자가 전달한 팀 대화 기준이다.

- 은샘 역할: 데모 버전 시나리오 구상, 앞으로 시연할 전체 흐름 구성.
- “퀘스트 라인을 각 지역별로 만드는 작업인가요?”에 대해 “각 맵별로가 아니라 전체적인 시연 흐름”이라고 확인했다.
- 영상 소스인지 직접 플레이하는 유저 경험인지 물었고, 답은 **“유저 경험에 초점”**이었다.
- 시간은 약5분 제안. 이어 **5분을 기준으로 하고 이후 내용도 진행 가능하게** 이해했다.
- 경매 언급은 의견을 모으며 브레인스토밍할 수 있는 수준이었다. 확정 기능/규칙/담당으로 처리하지 않는다.

이에 따라6분 발표자 대본 중심 초안은 참고용으로 보관하고, [데모 유저 경험 시나리오](Demo-Scenario-2026-11-07.md)를5분의 첫 교역 경험과 이후 연속 진행 기준으로 다시 작성했다. 시나리오 설계와 게임 코드 반영/실제 플레이테스트 완료는 구분한다.

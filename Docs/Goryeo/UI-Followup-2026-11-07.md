# UI2 후속 수정과 시연 준비 — 2026-11-07

브랜치 `codex/hud-cart-label-fixes`. 중단 저장 `3e3e95a8c`에서 재개했다. 사용자가 마지막에 한꺼번에 확인한다고 지시했으므로 중간 승인 없이 구현·검사·비교판·문서를 마쳤다. **최종 그림 승인 대기, 로컬만 반영.**

## 최종 수정

- 이름표: 종이 상자를 폐기했다. 원래 작은 갈무리 글씨 크기를 유지하고 진한 글자에 흰색1px 외곽선을 두른다. 여백은 외곽선에 필요한 수준으로 줄였다.
- 실제 대상 근처의 빈 자리를 먼저 찾고, 조작 중인 대상/게시판을 우선한다. 이름끼리, 게시판 그림, 활성 인물·좌판 등 SpriteRenderer, Objects/Above 타일의 보호 영역을 피한다. 빈 자리가 없는 부차적 이름은 숨기며 큰 배경으로 에셋을 덮지 않는다. 물·풀 같은 바탕 지형까지 글씨를 배제하는 기능은 아니다.
- 카메라와 독립된 배치/공통 픽셀 이동을 유지한다. 화면 밖 생활 수레의 렌더러 culling이 이름표 보호 영역을 없애 배치를 바꾸던 경로를 수정했다. 타일 보호 목록/스프라이트 탐색은 캐시하며 프레임마다 에셋을 만들지 않는다. 에디터 Scene 뷰의 다른 Screen 크기로 게임 카메라 좌표를 덮어 계산하지 않는다.
- Space 안내: 배경·키캡·‘게시판 보기/말 걸기/사고팔기’ 등 부가 설명을 없애고 `Space` 글자만 표시한다. 실제 대상 위치 주변 빈 공간을 사용하며 기존 Space 상호작용은 유지한다. 기존 장식 표지판에 끌려가던 게시판 전용 앵커는 제거했다.
- 사막여우: 사용자가 선호한 이전 얼굴 표시 구도를 복원하면서 정면 고정을 유지한다. 다른 세 출신과 수레/사람 그리기 순서 보완은 유지한다.
- 큰 공용 창: 소지품·장터·의뢰·지도·장부·게임 메뉴 등의 소유자 기반 잠금을 마무리했다. 대화는 다른 큰 창 뒤에서 대기하며 닫힌 다음 열린다. 새 세션 Reset으로 이전 대기 대화가 재등장하지 않고 비활성화된 대화/메뉴는 잠금을 해제한다. 구형 지역 UI의 bool 접근은 보존한다. 모든 온라인 창/지역 미니게임 조합을 검증했다는 뜻은 아니다.
- 채팅 첫 안내: 짧은 문구로 바꾸고 입력하지 않아도 실제6초 뒤 사라진다(마지막2초 페이드). 시간이 지난 일회성 안내는 Enter로 과거 기록을 열어도 되살리지 않는다. 일반 대화의12초 표시/과거 기록, Enter·Esc는 유지한다. 원본에도12초 페이드가 있어 ‘첫 전송 전 무한 유지’의 정확한 원인을 재현했다고 주장하지 않는다. 안내의 수명과 이력 복원을 명시적으로 분리했다.

이 범위는 고려·중앙 동쪽13맵의 전용 이름표와 공용 UI/채팅이다. 다른 문명 전용 파일·기존ID·저장 형식·DB·맵·씬·출구·카메라 이동 코드는 바꾸지 않았다. 공용 UIState/GameManager/GameEvents와 공용 UI 파일은 앞선 WIP 변경을 포함하므로 향후 PR 설명/팀 공지에 적어야 한다.

### 실패와 도구 보완

실패를 삭제하거나 합산하지 않았다. 모달 첫 가상 Escape 누락은 에디터 포커스가 가상 키보드를 무효화하는 조건과 구분해, 검토 중에만 복제한 입력 설정을 사용하고 원래 설정을 복원한다.12초 경계 부동소수점 비교는12.01초로 확인했다. 임시 입력 설정을 Play 종료 복원 전에 파괴해 발생한 InputManager assertion은 로그를 보존하고 종료 뒤 정리하도록 바꿨다. 최종 콘솔 판정은 별도 `final-console.json`에 기록한다.

이름표 비교는 원형 테두리 중복/화면 가장자리에서 정상적으로 들어오고 나가는 이름/문자열만으로 위치를 매칭하는 전제를 정정했다. 가림 탐색은 좁은 길목, 게시판 우선순위, 실제 상호작용 앵커까지 보완했다. culling과 카메라 이동 중 보호 영역 변화도 실제 좌표 기록으로 조사했다. 중간 실패 JSON과 최종 `play.json`을 구분한다.

사용자가 실제 저장ON Play를 켠 상태를 확인한 시점에는 SaveNow 성공 후 종료하고 새로운 기준9파일을 백업했다. 편집/재로딩 중 GoryeoStride 예외와 URP Light2D 정리 assertion 기록도 남겼다. 이를 최종 정상 콜드 세션 결과와 혼동하지 않는다. 원래 이동 막힘은 재시작 후 정상이며 원인 미확인 상태다.

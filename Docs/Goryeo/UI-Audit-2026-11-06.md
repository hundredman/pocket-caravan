# 게임 UI 전반 1차 점검 — 2026-11-06

## 범위와 현재 상태

사용자 요청대로 기존 팀 공용 UI B안을 유지하는 방향으로 검토했다. **화면 전반의 1차 점검이며, 모든 콘텐츠/온라인/언어/입력 조합의 검증 완료는 아니다.** 공통 주요 화면·네 문명 HUD/지도 등 실제 게임 캡처26장, 검토 도구의 열기/닫기·캡처·저장 격리58확인을 완료했다. OnGUI 소스61개를 목록화했으며 이 중27개는 다른 문명 전용이다. 목록화만 한 코드를 실행 검증했다고 쓰지 않는다.

가독성 보완안·문명 선택/대화 배치·소지품/게임 메뉴/백과/여관의 공용 테마 연결은 사용자 승인됐다. 공용 글자 출력 대비를 보완해 전후46/48확인·30캡처를 완료했고 그림 승인 대기다([결과](UI1-Text-2026-11-07.md)). 다른 문명 전용 코드·맵·그림은 고치지 않았다. GitHub integration에는 반영하지 않았다.

## 실제로 촬영한 범위

- 고려 HUD/Tab 상태, 소지품, M 지도, Q 의뢰, L 장부, Esc, 상업 백과.
- 일반 대화/선택지, 여관 권유, 떠돌이 상인/선택지, 전시실 첫 페이지, 오프라인 온라인 창, 시작 메뉴/문명 선택.
- 960×540의 지도·소지품·문명 선택(축소 연락판은 원본과 구분).
- 베네치아·아라비아·북유럽 실제 등록 씬의 HUD/지도. 같은 검토용 플레이어이며 출신별 전체 능력 검사가 아니다.

## 아직 실행 확인하지 않은 범위

실제 로그인/서버 연결·채팅 송수신·네트워크 오류/재접속, 관리자 기능, 사회/리액션 세부 창, 지역별 미니게임·경매 등 전용 화면 전체, M 고려 상세 탭 전체, 모든 긴 문구/최대 잔고 조합, 마우스·한글 IME 실제 입력·앱 재시작·게임 빌드/FPS는 이번 검토에 포함하지 않았다. 로그인 화면은 기억된 이름/키를 검토용 이름/빈 키로 바꾼 메모리 상태만 촬영했고 접속·기억 저장은 하지 않았다. 온라인 창을 캡처했다고 실제 온라인 검사가 된 것은 아니다.

## 검토 도구와 보존

창 열기/닫기는 가상 Keyboard→기존 InputReader를 사용했다. 대화·여관·전시실 등은 기존 Show/Offer 함수를 호출했고, 대화 마지막 페이지는 검토 도구가 골랐다. 구매·기증·수면·새 게임·로그인을 실행하지 않았다. Q 활성 의뢰는 현재 q1_naru의 검토용 SaveData를 Import해 표시했으며 자연 수락/완주 시험이 아니다. 소지품도 검토용 표본이다.

저장은 계속OFF이고 일회용 슬롯에는 파일이 만들어지지 않았다. 기존 사용자 저장9파일은 SHA256이 같다. 초기 중복 검토 인스턴스로 슬롯 격리가 실패한 시도는 `fixture-history`에 보존하고 Play를 완전히 종료한 뒤 단일 인스턴스로 재실행했다. 최종58확인/26캡처만 성공으로 기록한다.

# ATM-B4 일상 활동 — 우물 물 긷기

## 현재 상태

**우물 물 긷기 본편 연결 완료.** 초기 무보상 검토 뒤 사용자가 작은 보상을 요청했고, 사례비3냥 제안에 “좋아. 다음은”으로 승인했다(2026-11-06). 소 여물 등 추가 일상 활동은 후속이다.

- 예성 나루 기존 우물(원본 구역도 x245,y61/1×2칸, 맵 Naru x43,y35 밑칸). 그림·크기·충돌·아낙 배치 유지.
- 가까이 Space→물 긷기→실제3초→사례비3냥 완료 안내. 하루1회/다음날 다시 가능. Esc/그만두기, 컨트롤러/활동 비활성·맵 이탈·슬롯/날짜 변경 시 미소모.
- 신용/평판·아이템/체력 보너스·시간 비용은 없다. 두레박/손동작 애니메이션·신규 소리는 포함하지 않았다. 기존 UIState로 작업 중 이동·시계가 멈춘다.

## 본편 연결과 저장

승인 원문과 approved-source.json SHA를 ArtReview/Goryeo-Daily-20261106/approval.json에 남겼다. Tools/WorldLayout/goryeo_daily.py가 검증해 Resources/Goryeo/Daily/Config.json으로 복사한다. GoryeoDailyDirector가 본편 Naru에만 하나를 설치한다. 틀린 규격/ID/요금·위치/기간을 거절하며, 다른지역/preview에는 자동 설치하지 않는다. 기존 우물 충돌과 남쪽 접근 칸/출구 비중첩도 확인한다.

GoryeoDailyActivity는 기존 공개 GetMemo/SetMemo와 cooldownKeys/cooldownUntil을 사용한다. 키 goryeo:daily:water_day가 없으면 이용 가능하다. 마을일/R4 기록이나 다른 문명 키를 재사용하지 않는다. 저장 필드·버전은 늘리지 않는다.

1. 시작 전에 공개 SaveNow로 저장 가능한지 확인한다. 실패하면 일을 시작하지 않는다.
2. 완료 시 현재 잔고와 이전 날짜를 기억하고, 사례비+3/완료 날짜를 함께 설정해 SaveNow를 호출한다.
3. 실패/예외면 두 값을 모두 복원하고 재시도 안내를 표시한다. 완료 기록과 지급이 따로 저장되지 않는다. 금액 오버플로도 거절한다.
4. 성공한 저장을 읽으면 같은날 추가 수령이 막힌다. 기록보다 과거 날짜에서도 재수령하지 못한다. 다음날은 다시 가능하다.

공용 Core/Economy/Quests/UI·DB/WorldIndex/Connections/BuildSettings, 맵/씬·다른 문명 코드/그림·기존 ID는 미변경이다. 초기 검토용 InstallReview는 Editor/previewOnly/저장OFF에서만 명시적으로 사용한다.

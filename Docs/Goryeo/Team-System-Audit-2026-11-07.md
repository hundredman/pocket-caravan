## 검사와 남은 범위

실제 등록된 Naru→venice_rialto→north_birka→arabia_sanaa→Naru를 SaveOFF 별도 슬롯으로 로드한다. 친구 수첩은 실제 창을 열어 캡처하고 글꼴 참조/크기를 확인한다. 수정 후에는 공용 HUD의 가상 M입력(InputReader.Press)으로 실제 지역별 지도를 열고 닫은 뒤 소지품과의 상호 차단/이동 잠금 복원을 확인한다. 네이티브 키보드로 사람이 연속 플레이한 검사가 아니다. 우물 UI는 실제 승인 씬을 메모리에서 previewOnly로 전환한 검토 모드로만 실행한다.

최종 수치는 `ArtReview/Goryeo-Team-Audit-20261107/after.json`과 `Docs/Validation/Goryeo-Team-System-Audit-2026-11-07/summary.json`을 따른다. 팀원 전용 런타임/맵/씬/DB/저장 형식을 수정하지 않는다. 실제 온라인·장시간 이동/성능·모든 UI탭/모든 미니게임은 미확인이다. 재시작으로 풀린 이동 막힘의 원인도 이번 검사로 해결했다고 보고하지 않는다.

## 이후 작업 기준

새 UI·시스템 작업은 현재 공용/지역 원본의 위치와 재사용할 함수를 먼저 적고 시작한다. ‘계획에 있다’는 이유만으로 별도 기능을 새로 만들지 않는다. 공용 API를 바꾸면 고려 단독 테스트에 더해 타 지역의 기존 bool UI와 왕복 이동을 함께 확인한다. 검사 개수만으로 전체 게임 정상이라고 결론 내리지 않는다.

이번 수정은 로컬 검토본이다. 최종 화면 확인과 별도 integration 반영 지시 전에는 원격 브랜치에 올리지 않는다.

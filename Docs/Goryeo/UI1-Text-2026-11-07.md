# UI1 공용 글자 대비와 지도 이름 점검

소지품·게임 메뉴·상업 백과·여관은 사용자 “이대로 승인”(2026-11-07)으로 확정했다. 이어 공용 글자 출력의 색 공간 차이를 수정했다. 이번 새 글자 비교 그림은 승인 대기다.

## 변경

CuteUI.Label/Wrap/WrapCenter와 NetLogin.Text/입력 칸 글자에 기존 UIStyle.Lin을 적용했다. 이미 종이 GUILayout 스타일에 쓰는 방법이며, 기존 색/폰트/크기/글자 위치/아이콘/창 텍스처를 바꾸지 않는다. Linear 프로젝트에서 글자가 의도보다 옅어지는 경로를 맞춘다. Gamma에서는 기존 Lin 함수가 색을 그대로 반환한다. 로그인 인증/서버 접속/기억 저장/한글 조합 코드는 변경하지 않았다.

## 실행한 확인

- Unity 자동 Play: 원본46확인·최종48확인, 각15장 원본 캡처. 두 세션 모두 complete=true/error 없음. 중간 CuteUI만 변경한46확인은 별도 검증 기록으로 보존하며 최종 결과와 중복 합산하지 않는다.
- 실제 고려 HUD/Tab 상태창·전체/상세지도·오프라인 접속창·장부,960×540/360×270 지도, 세 타 문명 실제 등록 씬 HUD/지도를 표시했다. 타 문명 전용 코드/맵/데이터는 수정하지 않았다.
- 일반/여러 줄/가운데 글자 색·알파 처리 확인. 열 색상의 검토용 팔레트를 촬영하고, 흰 글자 행은 전후 디코딩 RGBA 픽셀 동일을 확인했다. 이것은 월드 전체나 다른 글자의 동일성 검사가 아니다.
- 오프라인 접속창에서 이름 글자 색 경로와 표본 문자열 보존을 확인했다. 접속 버튼/서버 요청/실제 온라인/한글 IME/네이티브 마우스는 실행하지 않았다.
- 이번 시작 시 사용자 저장8파일 해시 불변, 일회용 슬롯 파일0. 본 저장은 이전 검사 때부터 부재하고 앞선 백업을 그대로 두었다. 복원/삭제하지 않았다.

컴파일/정적 검사 최종 결과는 [검증 기록](../Validation/Goryeo-UI1-Text-2026-11-07/README.md). 이전 Editor8종/사람 직접 플레이/게임 빌드/FPS를 이번에 다시 검사했다고 쓰지 않는다. 스크린샷의 배경 생활 연출은 세션마다 달라 전체 화면의 픽셀 동일을 주장하지 않는다.

## 다음 지도 수정의 근거

현재 전체 축약도13구역·정착지2곳과 고려 상세5구역에 빈 이름은 없다. 그러나 WorldIndex의 현재 등록 이름과 전체 축약도 이름13개 중10개가 다르다. 단순 축약(나루/예성 나루 마을) 외에도 닥목/닥나무 마을, 동문 마을/솔재 길목 마을, 북동 포구/버들나루 마을, 북동 길/버들 물가 길 등이 있다. 전체 목록은 map-name-audit.json이다.

WorldMapUI는 area.name을 우선해 현재 WorldIndex 이름이 반영되지 않는다. 이름표는 CuteMap의16개 후보에서 최소 벌점을 고르므로 모두 겹치는 경우에도 중첩을 허용한다. 실제 전체 지도에도 북쪽/내륙 이름표가 겹친다. 다음은 등록 이름 동기화·이름표 겹침/긴 이름·현재 위치 핀·좁은 창 범례를 함께 고치고 실제 그림을 제출한다. 이번 커밋은 지도 데이터/이름/배치/배율을 수정하지 않았다.

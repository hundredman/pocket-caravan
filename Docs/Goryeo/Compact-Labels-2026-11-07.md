# 짧은 이름·호감도 안내·낚시 창 (2026-11-07)

사용자 요청: 긴 NPC/물건 이름과 서로 겹치는 글씨, 호감도 안내의 이름 가림, 나루 낚시 창 잘림을 수정. 추가로 낚시 UI를 승인된 공용 테마와 통일한다. 로컬 구현 후 마지막 그림 확인을 받으며 원격 반영은 하지 않는다.

## 적용

- 고려·중앙 동쪽 승인13맵의 월드 표시명만 단축. `나루 우물가 아낙`→`아낙`, `나루 마을 촌장`→`촌장`, 지역 접두어 제거, 시장은 `장터`, `나루 낚시`→`낚시`. 정식 DisplayName/NPC ID·퀘스트·호감도 친구 이름/저장 키는 그대로다. 타 지역 명칭은 바꾸지 않는다.
- 이름은 대상 위, Space는 대상 아래, 작은 네모 퀘스트 표시는 이름 오른쪽을 유지. 서로 겹치는 실제 대상 이름은 사람 우선·대상의 고정 위치 순서로 중복 표시를 생략한다. 자리 재배치나 플레이어에 따른 우선순위 변경은 없다. 생략해도 원래 상호작용 대상·Space·대화 기능은 유지된다.
- 고려의 머리 위 하트/선물 패널을 없애고 현재 말 걸 대상의 하트·G 선물만 화면 하단에 작은 한 줄로 표시한다. 사람과 물건 이름 위에 별도 창을 쌓지 않는다. 공용 Social의 타 지역 표시는 유지.
- 낚시 창의 고정 y=94를 화면 중앙 기준으로 바꾸고 닫기 버튼을 88px로 확보한다. 공용 CuteUI의 종이색·주황 프레임·청록 버튼/찌 성공 구간을 재사용하며, 3회 시도·방생·보상 없음·판정 규칙은 유지한다.

## 검토 그림과 검사

실제 Unity GameView의 전후 캡처는 `ArtReview/Goryeo-Compact-Labels-20261107/`. 자동 검사는 별도 SaveOFF 슬롯에서 실씬 로드·위치 설정·실제 Interact/Cast/Strike/Close 호출로 진행하며 사람이 연속 플레이한 결과와 구분한다. 최종 수치는 같은 폴더의 `after.json`과 `Docs/Validation/Goryeo-Compact-Labels-2026-11-07/summary.json`을 따른다. 중간 UI 테마 연결 때 잘못 참조한 색 이름은 컴파일 오류로 확인해 수정했으며 최종 콘솔을 따로 기록한다.

Python 전체 회귀는 테마 후속 변경 전403개/23skip, 최종 소스 확인2개 및 최종 테마의 Unity 검사를 별도로 실행한다. 세계1437출구/0오류. PNG를 비교할 때에는 디코딩 RGBA 픽셀을 기준으로 한다. 실제 키보드/온라인/장시간 성능·사람이 하는5분 데모 리허설은 이번 검사 범위가 아니다.

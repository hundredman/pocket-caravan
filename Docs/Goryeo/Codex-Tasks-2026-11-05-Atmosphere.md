# Codex 작업 지시: 고려 "보이고 들리는 것" (2026-11-04 작성)

은샘 지시(11/04): 다른 지역과 비교해 고려에 빠진 **보이고 들리는 항목은 모두 구현**한다. **할 거리는 그다음 단계**로 하나씩(아래 B단계).
Codex가 작업하고 Claude는 최종 확인·검토만 한다. 기준: integration `a5fa5d196`(PR #26 합친 뒤), 비교표는 `Docs/Integration/FeatureParity-2026-11-03.md` 2절.

## 공통 규칙

- **브랜치:** 지금 Mac 저장소 HEAD(= GitHub `region/goryeo`)에서 `codex/goryeo-atmosphere`를 새로 만들어 작업한다. push·PR은 하지 않는다(Claude가 검토 후 합침). `Packages/packages-lock.json`의 Unity 자동 변경은 커밋하지 않는다.
- **대상 맵:** 고려 5맵 + 중앙 동쪽(transit_) 8맵. 지역 판별은 `GoryeoTravelTransition.RegionOf(mapId)`(고려/중앙 대륙)를 쓴다. 다른 지역 맵에서는 아무것도 하지 않는다.
- **다른 지역 코드는 고치지 않는다.** 북유럽·베네치아·아라비아 구현(`NorthSound`, `VeniceSound`, `VeniceStride`, `VeniceLabels`, `NorthLife`, `VeniceLife`, `ArabiaAmbience`)은 **참고만** 하고, 고려용은 `Scripts/Goryeo/`(새 폴더) 또는 `Scripts/World/Goryeo*`에 따로 만든다. 공용 부품(`MapModules/WeatherOverlay`·`WeatherSkin`, `Audio/MapAmbience`, `AudioManager`)은 **가져다 쓰되** 고치면 커밋 메시지에 적고 다른 지역 동작이 그대로인지 확인한다.
- **판정·이동·저장·경제는 바꾸지 않는다**(날씨가 속도에 주는 영향만 예외, 아래 A6). 새 저장 필드가 필요하면 옛 저장 호환을 함께 만든다.
- **그림·소리는 Codex가 만들고 은샘 승인 후 본편에 넣는다.** 그림은 실제 게임 화면 캡처(480×270 기준), 소리는 짧은 들어 보기 파일(mp3/ogg)로 보여 준다. 승인 전에는 검토 폴더(`ArtReview/…`)에만 둔다.
- **성능:** 입자·생활 연출은 화면 안에서만, 개수 상한을 둔다(북유럽 `WeatherOverlay`는 160개 상한). 시연 PC에서 끊기지 않게.
- **검사(커밋 전):** `validate_world.py`, `unittest`(numpy 있는 환경 + Pillow만 있는 환경 둘 다), Unity 8개(ValidateWorld, SceneTerrain, GoryeoRegion, TransitRegion, Q1, GoryeoExperience, TradeBalance, SaveCompat). Play 시험 전 저장 백업, 시험 뒤 저장 불변 확인. 하지 않은 검사를 했다고 쓰지 않는다.

## A단계: 보이고 들리는 것 (이번에 전부)

| 번호 | 항목 | 다른 지역 참고 | 고려에서 할 것 | 끝난 기준 |
|---|---|---|---|---|
| A1 | 날씨 | 북 눈·오로라·바람(`NorthAtmosphere`), 베 안개·비, 아라비아 모래바람·회오리 | 고려다운 날씨 2~3가지: 비(봄비·장맛비), 안개(강가·나루 아침), 바람에 날리는 꽃잎/낙엽 중 고르기. 공용 `WeatherOverlay`·`WeatherSkin` 재사용. 하루 단위로 정해지고(게임 날짜 기준, 같은 날 같은 날씨), 맵마다 어울리는 것만(강가 맵에 안개 등) | 맑음·비·안개 화면 캡처 승인. 입자 상한 지킴 |
| A2 | 지역 음악(시간대 4곡) | 북·베 아침/낮/저녁/밤 | 지금 맵 기준 곡(`AudioManager.MapMusic`: naru·capital·dakmok·road)을 시간대 기준으로. 새 곡이 필요하면 만들어 들어 보기 → 승인. 맵 기준 곡과 어떻게 섞을지(예: 마을은 시간대, 길은 road) 제안 | 4개 시간대 들어 보기 승인. 바뀔 때 끊기지 않게 페이드 |
| A3 | 생활 소리 | 북·베 장터 웅성·동물, 베 NPC 말소리 | 장터 웅성임(장터 광장 근처), 동물(닭·소·개·새, 마을마다 어울리게), 물가 물소리는 이미 있음(`MapAmbience`). 거리에 따라 커지고 작아짐 | 들어 보기 승인. 음소거·음량 설정 따름 |
| A4 | 걷기 느낌 | 베 `VeniceStride`, 북 썰매·눈 자국, 아라비아 모래 발자국·먼지 | 땅에 따라 다른 발소리(흙길·풀·돌·나무다리), 흙길 먼지, 비 올 때 물 튀김(A1과 연결) | 화면 캡처 + 들어 보기 승인 |
| A5 | 장소 이름표 근접 표시 | 베 `VeniceLabels`(4칸 안에서만 이름) | 고려 장소(장터·객주·공방·우물·나루·게시판 등)에 다가가면 이름 표시. 지금 늘 떠 있는 이름표와 겹치지 않게 정리 | 화면 캡처 승인 |
| A6 | 날씨가 속도에 영향 | 북 눈보라, 베 아쿠아 알타 | 비·장맛비 때 흙길에서 조금 느려짐 등 **작게**. 수치 제안 → 승인 | 수치 표 승인, 저장·경제 변화 없음 |
| A7 | 마을 생활 연출 | 북 동물·연기·불빛, 베 비둘기·갈매기·곤돌라·가로등 | 굴뚝 연기(아침·저녁), 마당 닭·개, 논 위 새, 나루 갈매기·배, 밤 등불(이미 `GoryeoLantern` 있음, 늘리기). 중앙 동쪽 길에는 지나다니는 사람(`Walker` 재사용)·짐수레 | 마을 3곳·길 1곳 캡처 승인. 충돌 없음(보이기만) |

순서 제안: A1 → A4 → A3 → A7 → A5 → A2 → A6 (A6은 A1이 끝나야 함).

## B단계: 할 거리 (A단계 뒤, 은샘이 하나씩 정함)

1. 놀거리 ★ 표시(공용으로 할지 기우와 정한 뒤)
2. 나룻배 빠른 이동(예성 나루 ↔ 버들나루 ↔ 남동 포구)
3. 앉기(평상·주막 마루·모닥불)
4. 하루 한 번 일상 거리: 우물 물 긷기1종 본편 연결 완료. 소 여물 주기는 현재 범위 제외, 최종 버그 수정 이후 검토할 선택 확장 후보(2026-11-06 사용자 지시).
5. 날씨 사건 + 비·벼락 뒤 쓰러진 통나무(A1 날씨와 연결, 은샘 11/04 요청)
6. 떠돌이 상인·전시실·숨은 수집물 7개(기우 공용 틀이 생기면 고려 내용만)
7. 정직 시험·퀘스트 연출

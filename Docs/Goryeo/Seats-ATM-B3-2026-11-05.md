# ATM-B3 앉기 검토

상태: **그림·위치 승인 대기, 본편 미적용**. 나룻배 다음 작업을 계속하라는 사용자 지시로 준비했다.

## 제출

- `ArtReview/Goryeo-Seats-20261105/comparison.png`: 실제 Unity 480×270 여섯 장, 서기→앉기. 비교판 아래는 기존/새 자세 4배 최근접 확대다.
- 북쪽 쉼터 마을의 기존 평상 오른쪽 끝, 기존 쉼터 주막 문 옆 마루 후보, 그 마을의 새 모닥불 후보다. 모닥불은 왼쪽 전 화면에서는 숨기고 오른쪽 후 화면에만 표시했다.
- 주막의 기존 그림을 고쳐 마루를 만들지는 않았다. 현재 건물 앞 좁은 바닥이 앉을 자리로 읽히는지는 사용자가 판단한다. 이 후보가 맞지 않으면 전용 마루가 있는 건물/설비 그림이 필요하다.
- 비교 양쪽에서 먼 통나무 사건의 디버그 패널과 일시 알림만 QA에서 숨겼다. 지형·건물·NPC는 실제 본편 씬이다. 본편 UI 코드는 고치지 않았다.

## 구현 범위

원본은 `Tools/ArtGen/goryeo_seat_trial.py`다. 기존 `chars.py`의 글자 그림/팔레트 방식으로 너구리의 접힌 무릎·손을 새로 그렸다. 16×24 원래 격자이며, 기존 서기 PNG를 잘라 붙이거나 눌러 만든 그림이 아니다. 기존 캐릭터 PNG/원본은 고치지 않았다. 모닥불은 NinjaAdventure camp (12,5)의 원래 2×2 조립 정의대로 온전한 네 타일을 사용한다. 다른 지역 생성기를 실행하거나 수정하지 않았다.

`GoryeoSeat.InstallReview`를 Editor에서 명시 호출하고, previewOnly + 저장OFF 조건을 만족해야 설치된다. 자동 설치/승인 Resources/씬·맵 변경은 없다. 고려 출신 너구리의 정면 자세만 준비했다. 다른 출신은 거절해 원래 그림을 보존한다. **그림 승인 뒤 다른 세 출신의 자세와 대상별 배치를 준비·검토하고 본편 연결해야 B3 완료다.**

PlayerController에 앉아 있는 동안 이동/상호작용을 처리하는 작은 훅을 넣었다. Space로 앉고, 이동 입력 또는 Space로 일어난다. UI/이동 잠금·출신 변경·비활성/씬 이탈 때 복원한다. 캐릭터 전체 비율을 바꾸지 않고 전용 Sprite와 몸의 높이만 사용한다. 물리 위치는 통행 가능한 비출구 칸에 둔다. 일어날 때 원래 안전 위치로 돌아간다. 전역 UI 잠금/PlayerController 비활성화는 사용하지 않는다.

체력 보너스·시간 비용·회복/온기 버프·새 저장 필드는 없다. 평소 멈춰 있을 때의 기존 체력 회복은 계속된다. 모닥불 후보는 이번 시각 검토용이며, 승인 후 본편 충돌/불꽃 연출까지 별도로 정리해야 한다. 공용 Core/Economy/Quests/UI·DB/WorldIndex·Connections/BuildSettings, 본편 맵·씬, 카메라·속도 계산은 고치지 않았다.

## 검사

`Docs/Validation/Goryeo-Seats-2026-11-05/` 참조.

- 최종 Unity Play **54확인**, 실제480×270 **6캡처**. preview 설치 제한/중복 정리·세 자리 안전한 발 위치·원본 비율 유지/전용 그림·이동/Space/잠금/비활성 해제·원위치·일반 정지와 같은 체력 회복·재산/짐/수레 보존·원격/미지원 출신 거절·실제 씬 이탈 정리·저장OFF를 검사했다.
- 입력은 실제 키보드 조작이 아니라 같은 입력 처리 함수에 이동/Space 값을 주입했다. 실제 인게임 씬에서 실행했지만 사람이 플레이한 검사는 아니다.
- 최초 QA가 LateUpdate 전에 Sprite를 읽어 실패했다. 프레임 렌더 종료 후 비교하도록 고친 뒤 통과했다. 실패 보고서는 `Unity/initial-before-lateupdate-failure.json`에 남겼다. 이후 캡처에서 평상 물건과 겹치는 자리를 오른쪽 끝으로 옮기고, 주막 발 위치/그림 높이도 수정했다.
- Python 전체 **391개**, numpy/scipy 환경23skip·Pillow만 환경32skip. 마지막 자리 보정 뒤 전용2검사를 두 환경에서 재실행해 통과했다. 새 PNG 검사는 RGBA 픽셀/알파를 사용한다.
- 월드0오류/1437출구, Unity8종(ValidateWorld/SceneTerrain54씬/GoryeoRegion/TransitRegion/Q1/GoryeoExperience/TradeBalance/SaveCompat), 최종 콘솔error0.

# ATM-B3 앉기 검토

상태: **모닥불 움직임 승인, 출신별 자세·위치 최종 승인 대기, 본편 미적용**. 나룻배 다음 작업을 계속하라는 사용자 지시로 준비했다.

## 제출

- `ArtReview/Goryeo-Seats-20261105/comparison.png`: 실제 Unity 480×270 여섯 장, 서기→앉기. 비교판 아래는 기존/새 자세 4배 최근접 확대다.
- 북쪽 쉼터 마을의 기존 평상 오른쪽 끝, 기존 쉼터 주막 문 옆 마루 후보, 그 마을의 새 모닥불 후보다. 모닥불은 왼쪽 전 화면에서는 숨기고 오른쪽 후 화면에만 표시했다.
- 주막의 기존 그림을 고쳐 마루를 만들지는 않았다. 현재 건물 앞 좁은 바닥이 앉을 자리로 읽히는지는 사용자가 판단한다. 이 후보가 맞지 않으면 전용 마루가 있는 건물/설비 그림이 필요하다.
- 비교 양쪽에서 먼 통나무 사건의 디버그 패널과 일시 알림만 QA에서 숨겼다. 지형·건물·NPC는 실제 본편 씬이다. 본편 UI 코드는 고치지 않았다.

## 구현 범위

원본은 `Tools/ArtGen/goryeo_seat_trial.py`다. 기존 `chars.py`의 글자 그림/팔레트 방식으로 너구리의 접힌 무릎·손을 새로 그렸다. 16×24 원래 격자이며, 기존 서기 PNG를 잘라 붙이거나 눌러 만든 그림이 아니다. 기존 캐릭터 PNG/원본은 고치지 않았다. 모닥불은 NinjaAdventure camp (12,5)의 원래 2×2 조립 정의대로 온전한 네 타일을 사용한다. 다른 지역 생성기를 실행하거나 수정하지 않았다.

`GoryeoSeat.InstallReview`를 Editor에서 명시 호출하고, previewOnly + 저장OFF 조건을 만족해야 설치된다. 자동 설치/승인 Resources/씬·맵 변경은 없다. 처음에는 너구리 정면 자세만 준비했으며, 지금은 네 출신별 정면 자세를 검토한다. Sprite 목록에 없는 출신/꾸미기는 거절해 다른 동물 그림이 되지 않게 한다. **새 자세·자리 승인 뒤 본편 연결/충돌 정리·검사를 해야 B3 완료다.**

PlayerController에 앉아 있는 동안 이동/상호작용을 처리하는 작은 훅을 넣었다. Space로 앉고, 이동 입력 또는 Space로 일어난다. UI/이동 잠금·출신 변경·비활성/씬 이탈 때 복원한다. 캐릭터 전체 비율을 바꾸지 않고 전용 Sprite와 몸의 높이만 사용한다. 물리 위치는 통행 가능한 비출구 칸에 둔다. 일어날 때 원래 안전 위치로 돌아간다. 전역 UI 잠금/PlayerController 비활성화는 사용하지 않는다.

체력 보너스·시간 비용·회복/온기 버프·새 저장 필드는 없다. 평소 멈춰 있을 때의 기존 체력 회복은 계속된다. 모닥불 후보는 움직임까지 추가한 시각 검토용이며, 승인 후 본편 충돌/연결을 별도로 정리해야 한다. 공용 Core/Economy/Quests/UI·DB/WorldIndex·Connections/BuildSettings, 본편 맵·씬, 카메라·속도 계산은 고치지 않았다.

## V2 중심 정렬·사막여우 앉기 수정

사용자 “너구리, 고양이, 순록이 앉아 있을때 삐뚤해보이고 사막여우는 앉은 것 같아 보이지 않아.”를 반영했다. 최신 제출은 **ArtReview/Goryeo-Seats-20261105/AlignedV2/comparison.png**, 확대만 보려면 pose-comparison.png다. 캐릭터마다 왼쪽은 이전/오른쪽은 V2다. 이전 실제 게임 캡처는 Expanded/Unity/*-after, 새 캡처는 AlignedV2/Unity/*-after를 사용했다. 옛 시안/원본은 지우거나 덮어쓰지 않았고 Expanded/submission은 revision-requested로 표시했다.

- 너구리·고양이·순록: 머리 중심7.5px에 비해 하체19~23행 중심이7.5/7/6.5/6.5/7px이었다. 띠·옷자락·무릎·신발을 새로 그려 전부7.5px에 맞췄다. 전체 Sprite를 옆으로 밀어 맞춘 것이 아니다. 색의 명암은 보존하고 외곽/양쪽 다리 간격을 정렬했다. 새 소스 Tools/ArtGen/goryeo_seat_aligned.py.
- 사막여우: v1은 상체 높이를 유지한 채 바지만 넓혀 앉기로 읽히지 않았다. 편집 가능한 이전 .aseprite에서 귀·얼굴·상의 위26행을 그대로4px 내려 보존하고, 짧아진 몸통/허리띠/손·넓게 접힌 무릎·신발/옆에 쉰 꼬리를 다시 그렸다. Tools/ArtGen/goryeo_seat_fennec_v2.lua를 Aseprite MCP로 실행했다. 새 .aseprite/PNG는 AlignedV2/arabia-seated-front.*다. 이번에 AI 이미지를 생성하지 않았다.

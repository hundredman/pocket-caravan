# Pocket Caravan 시연 진행안

2026-11-07 · 은샘 담당 시연 시나리오 · Codex 작성. **발표 진행용 초안이며 게임 대사/퀘스트를 새로 넣는 작업은 아니다.** 사용자 검토 전이다. 아래 시간은 편집상 목표이며 실제 리허설 측정값이 아니다.

## 전달할 한 가지

“같은 물건도 필요한 마을로 가져가면 가치가 달라집니다. 서로 다른 문명에서 출발한 상인들이 중앙 대륙에서 만나는 교역 게임입니다.”

기본안은 **약 6분**, 여유가 있으면 약 2분을 추가한다. 본편의 ‘고려 한 바퀴’를 전부 완료하는 것을 시연 조건으로 삼지 않는다. 고려의 풍경과 실제 매매 한 번, 운반과 이동, 다른 문명과 만나는 목적을 한 흐름으로 보여 준다.

## 시작 전 준비

- 시연 당일 팀에서 합의한 integration 커밋/실행 파일을 고정하고 기록한다. 현재 UI 후속 수정은 로컬 검토 중이므로 통합판과 같은 화면이라고 소개하지 않는다.
- 별도 시연용 저장을 쓴다. 개인 저장을 복사·백업한 뒤 게임에서 지원하는 방식으로 준비하고, JSON을 임의로 고쳐 평판/돈을 조작하지 않는다. 시작 장소와 실제 소지금·짐·퀘스트를 아래 빈칸에 기록한다.
- **본 시연 시작 상태:** 고려 캐릭터, 예성 나루, 조작 튜토리얼 완료 또는 마지막 인사까지 완료, 큰 창 모두 닫힘. 기본 물건과 돈만 준비한다. 장단에 가져갈 곡식 1~3개를 살 자금과 적재 여유가 있는지 확인한다.
- 관객 앞에서는 처음 켜고 로그인 실패를 고치는 시간을 쓰지 않는다. 새 게임의 문명 선택/첫 인사는 별도 화면으로 짧게 소개하거나 리허설에서 시간을 측정한 경우에만 현장에서 진행한다.
- Naru → goryeo_jangdan → transit_pass → transit_woodtown 경로를 지도와 실제 출구로 미리 왕복한다. 이 경로는 JSON 연결 조사로 확인했으나, 이번 시연 시간대로 연속 주행한 결과는 아직 없다.
- 장단 장터가 열리는 위치, 솔재 장터의 접근 위치, 다른 문명 참가자가 서 있을 장소를 리허설 때 기록한다. 외부 지역 담당에게 경로 안내를 받아야 하며 다른 문명 맵을 수정하지 않는다.
- 화질: 사용할 실제 해상도/확대율로 이름표·소지품·장터·지도 글씨가 읽히는지 확인한다. 시연 중 창은 하나씩 열고 Esc로 닫는다.
- 네트워크 구간은 팀원 2명 이상이 같은 서버/버전으로 사전 접속해 이동·채팅을 서로 확인한 경우에만 생방송으로 넣는다. 이 문서 작성 자체는 온라인 동작 검증이 아니다.

## 기본 진행 — 약 6분

| 목표 시각 | 화면·행동 | 발표자가 할 말 | 확인할 결과 |
|---|---|---|---|
| 0:00–0:25 | 예성 나루에서 시작. 부두와 장터를 잠시 보여 준다. | “네 문명의 새내기 상인으로 시작합니다. 저는 고려의 예성 나루에서 출발하겠습니다.” | 캐릭터·포구·장터가 함께 보인다. |
| 0:25–0:55 | WASD로 짧게 걷기, Shift 달리기. Tab → I → M을 각각 닫고 차례로 열기. | “짐과 운반 수단에 따라 이동이 달라집니다. 소지품과 지도에서 다음 거래를 준비합니다.” | 돈·짐·위치가 읽힌다. 상태창/지도 설명을 길게 하지 않는다. |
| 0:55–1:40 | 나루 장터에 Space. 곡식 1~3개 선택 → 현재 총액/잔금 확인 → 실제 구매 → Esc. | “먼저 작은 거래부터 합니다. 가격과 짐 무게를 보고, 감당할 수 있는 만큼만 삽니다.” | 실제 돈 감소·짐 증가. 물량은 당시 가격/적재량에 맞춘다. |
| 1:40–2:35 | 지도에서 장단 확인 후 실제 길로 이동. 논·초가·강가가 보이는 자리에서 잠시 멈춤. | “물건을 옮기는 길도 게임의 일부입니다. 고려의 마을마다 생산물과 풍경이 다릅니다.” | 논/생활 연출, 카메라 이동·지역 안 짧은 전환. 장식 모두를 설명하지 않는다. |
| 2:35–3:20 | 장단 장터에서 가져온 곡식 일부 판매. L로 실제 거래 내역 확인 후 닫기. | “지금 판매할 값과 장부의 매입 기록을 비교합니다. 많이 팔면 시세도 달라지기 때문에 어디에 얼마나 팔지 선택합니다.” | 실제 돈 증가·짐 감소·매입/판매 기록. 차익이 있으면 실제 금액만 말한다. 적자라면 “이번 거래는 이 값이라 이익이 나지 않았습니다”라고 설명한다. |
| 3:20–4:35 | 장단 → 솔바람 고개 → 솔재로 이동. 고려→중앙 대륙 도착 표기를 보여 준다. | “고려를 벗어나면 여러 문명으로 길이 이어지는 중앙 대륙입니다. 마을을 거치며 더 먼 판매처를 찾습니다.” | 등록 출구로 이동·중앙 대륙 표시·솔재 장터 도착. 이동이 길면 아래 축약안을 쓴다. |
| 4:35–5:30 | 검증된 온라인 환경이면 솔재에서 다른 문명 캐릭터와 만나 Enter로 한 줄 인사. 상대도 이동/인사. 미검증이면 아래 오프라인 대체. | “출발 문명은 달라도 같은 장소에서 만납니다. 거래 기회를 찾아 이동하며 다른 상인과 함께하는 것이 목표입니다.” | 서로 보이는 이동·수신한 채팅. 플레이어 간 물건 양도는 검증 없이 시연하지 않는다. |
| 5:30–6:00 | 솔재 장터와 지도. 큰 창 닫고 캐릭터가 보이는 화면으로 마침. | “작게 사고, 직접 옮기고, 기록을 보며 다음 거래를 고릅니다. 이 경험을 네 문명과 중앙 대륙으로 넓혔습니다.” | 발표 종료 화면을 한 곳으로 고정. |

## 이동이 길면 — 3분 축약

예성 나루 소개(20초) → 구매/소지품(50초) → 미리 준비한 장단 저장으로 전환했음을 밝히고 판매/장부(50초) → 미리 준비한 솔재 저장으로 전환 또는 촬영 영상(40초) → 마무리(20초). 준비 저장 전환을 실제 연속 이동으로 소개하지 않는다. 시연 중 개발용 C 고속 이동이나 임의 텔레포트를 쓰지 않는다.

## 선택 확장 — 한 가지씩만, 총 약 2분

| 기능 | 넣는 조건 | 보여 줄 것 |
|---|---|---|
| 의뢰 게시판 | 시간 여유와 완수 가능한 목적지/기한을 사전 확인 | Space 보기 → 보상·기한·목적지 읽기. 수락하면 끝낼 경로까지 준비, 단순 미리보기면 닫기. |
| 나룻배 | 예성 나루에서 시작하는 대체 동선이 필요할 때 | 사공과 대화 → 버들나루 또는 남동 포구 → 사공 옆 도착. 실제 설정 8냥/게임1시간. 실제1시간 기다리는 기능이라고 설명하지 않는다. 기본 경로에 추가하면 동선이 늘어나므로 교체용으로 쓴다. |
| 흥정·평판 | 중립 이상 거래 화면을 준비했을 때 | 실제 제안 결과와 안내를 읽는다. 성공을 고정 결과처럼 약속하지 않는다. 마이너스 평판 회복까지 기본안에 끼워 넣지 않는다. |
| 날씨·발소리 | 해당 날씨/지면의 준비된 저장 또는 촬영본이 있을 때 | 흙길과 풀밭의 소리·걷기 연출을 짧게 비교. 비를 기다리거나 개발 메뉴로 사건을 강제하지 않는다. |

## 발표 대사 — 한 장용

1. “Pocket Caravan은 서로 다른 문명에서 출발한 상인이 물건을 사고, 운반하고, 팔며 성장하는 게임입니다.”
2. “고려의 예성 나루에서 작은 거래를 시작하겠습니다. 값뿐 아니라 남는 돈과 짐 무게도 살펴야 합니다.”
3. “장단까지 직접 가져왔습니다. 실제 판매 값과 장부를 보고 다음 거래를 결정합니다.”
4. “이제 중앙 대륙으로 나갑니다. 다른 문명에서 온 상인들도 이 길목에 도착합니다.”
5. “작은 마을의 거래가 문명 사이의 교역으로 이어지는 경험을 만들었습니다.”

새 NPC 대사가 아니라 발표자 대본이다. 확정되지 않은 역사/스토리 설정을 추가하지 않는다.

## 장애가 생겼을 때

- **온라인 연결 실패:** 반복 접속 대신 준비한 오프라인 솔재 화면으로 전환. “지금은 로컬 교역 동선을 보여 드리고, 함께 이동하는 장면은 사전 촬영본으로 보여 드리겠습니다.” 실제 촬영본이 없으면 온라인은 설명만 하고 지원 인원/서버 저장/동시 거래 성공을 주장하지 않는다.
- **다른 참가자 도착 지연:** 미리 합의한 솔재에서 기다리고 추가 지역 순회는 생략. 장소나 접속 상태가 안 맞으면 오프라인 대체.
- **가격이 예상과 다름:** 당시 실제 가격으로 소량 거래. 이익 금액을 미리 대사에 고정하지 않는다. 구매 직후 같은 마을 되팔기로 이익을 보이는 연출은 쓰지 않는다.
- **이동 멈춤/화면 문제:** Esc로 열린 창부터 닫고 현재 위치를 기록. 재현 중 개인 저장을 덮어쓰지 않는다. 안 풀리면 준비 저장/영상으로 전환하고 문제를 숨겨서 해결된 것처럼 말하지 않는다.
- **시간 초과:** 게시판·나룻배·흥정 등 확장부터 생략. 다른 문명 전체 튜토리얼 완주로 범위를 늘리지 않는다.

## 작성 근거와 범위

`Docs/Direction.md`, `Docs/QuestMain1.md`, `Docs/Reference/DeliveryPlan.md`, `Scripts/World/GoryeoIntro.cs`, `Resources/Goryeo/Ferry/Config.json`, `Maps/*.json`의 기존 연결을 확인했다. 기본 실제 연결은 Naru → goryeo_jangdan → transit_pass → transit_woodtown. 솔재에서 초원 진입로/내륙 교역 길목을 거치면 아라비아·북유럽 연결이 등록돼 있지만, 타 지역 왕복/온라인 실연은 이 문서 작성 중 확인하지 않았다. 당일 팀원 동선은 리허설에서 확정한다.

이 초안은 새 퀘스트·DB·지도·타 문명 씬·온라인 프로토콜을 변경하지 않는다. 완료 기준은 문서 작성과 사용자 검토용 제출이며, 실제 시연 성공은 리허설 이후에만 판정한다.

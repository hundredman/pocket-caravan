# 후속 작업 착수 검토

사용자 지시: 계획에 적혀 있다는 이유로 바로 구현하지 않는다. 현재 에셋·배치·공용 기능과 사용자에게 주는 효과를 확인한 뒤, 빠른 보완과 새 콘텐츠 제작을 구분한다. 이번 작업은 문서/소스/맵 JSON 정적 조사이며 게임 구현과 Unity Play 검사는 하지 않았다.

## 현재 판단

분위기 A1~A7, 나룻배·앉기·날씨 통나무는 연결 완료 상태다. 일상 활동은 승인된 우물 물 긷기1종이 연결됐다. 소 여물은 사용자 지시로 현재 범위에서 제외했으며, 최종 버그 수정 이후 선택 확장 후보로만 남긴다. 이번 조사에서 별도 신규 기능을 곧바로 구현해야 할 결함을 확정하지 않았다.

| 작업 | 빠른 진행 여부 | 근거와 먼저 할 일 |
|---|---|---|
| 기존 기능 짧은 실제 조작/이어하기 확인 | 우선 권장 | 자동 QA는 있으나 사람 직접 입력·시작화면 이어하기는 미검사다. 우물 지급/재수령 제한, 나룻배 도착, 앉기 해제 등을 각각 좁은 범위로 확인한다. 전체 Q1 완주나 온라인 검증까지 빠른 검사로 묶지 않는다. |
| 문서의 완료·예시·대기 상태 정리 | 바로 가능 | ATM-B4를 무조건 진행 중/여물 다음으로 표시한 부분을 정정한다. 과거 Plan의 옛 미완료 표시는 최신 CurrentState/WorkLog와 대조해 한 번에 정리할 후보이며, 다른 담당 행을 임의로 완료 처리하지 않는다. |
| 놀거리 ★ 표시(ATM-B1) | 조건부 | 새 그림 부담은 작을 수 있으나 문서가 공용 여부 팀 결정을 선행으로 둔다. 베네치아 지역용 ActivityHints는 있지만 그대로 고려 전용 표시를 더하면 공용 정리 때 중복될 수 있다. 결정 확인 전 구현하지 않는다. |
| 소 여물 주기(ATM-B4 확장 후보) | 현재 범위 제외 | 고려 Resources의 cow는 울음소리 WAV다. 고려 생활 연출은 닭/개이고, 소 전용 그림·외양간/먹이 자리 배치를 이번 조사에서 찾지 못했다. 새 그림/움직임·배치·상호작용·보상/저장을 갖추고 승인받아야 한다. 현재는 우물1종으로 일상 활동이 이미 있다. 최종 버그 수정 이후 필요할 때만 다시 검토한다. |
| 떠돌이 상인(ATM-B6 일부) | 재사용 가능, 즉시 구현은 보류 | 공용 RoadEvent.Type.Peddler와 MapJsonBuilder의 event 생성 분기가 존재한다. 따라서 기반이 전혀 없다는 설명은 틀리다. 다만 현재 담당13맵 JSON에서 kind=event 배치는0개다. 기존 돌발 상인과 문서의 일일 떠돌이 상인을 구별하고, 위치/그림·일정·물품/가격·재진입/저장을 검토해야 한다. 공용 틀을 기다리라는 기존 조건도 팀과 확인한다. |
| 전시실·숨은 수집물7개(ATM-B6) | 빠른 작업 아님 | 다른 지역 전용 구현은 참고할 수 있지만 고려의 내용/위치/진행 표시·전시 그림/완료 보상·중복/저장 검사가 필요하다. 문서도 공용 틀 선행을 둔다. |
| 정직 시험·새 퀘스트 연출(ATM-B7) | 설계 먼저 | 베네치아 전용 VeniceHonesty는 있지만 고려에 옮길 이야기·발동 퀘스트·선택 결과/재산·신용 영향이 확정되지 않았다. 기존 고려 퀘스트 안내 누락 조사는 따로 작게 할 수 있으나, 새 분기 구현까지 빠르다고 보지 않는다. |

## 추천 순서

1. 이미 연결한 기능에서 사람이 누르는 입력과 이어하기를 좁게 확인하고, 실제로 발견한 결함만 우선 고친다.
2. 남은 계획 표에서 완료된 것과 새 콘텐츠 후보/팀 결정 대기를 구분한다.
3. 그 후 사용자에게 필요한 추가 활동을 제안한다. 소 여물, 전시실, 수집물은 자동 다음 작업으로 잡지 않는다. 수확 돕기는 기존 논을 활용하는 확장 후보로 사용자 동의를 받았으며 최종 버그 수정 뒤 검토한다. 작은 구역1곳/하루1회/소액 사례비부터 검토하되 보상 수치·위치·벤 모습/복원은 아직 미정이다.

우물/배/앉기 등을 다시 만드는 작업은 없다. 새 그림이나 소리, 보상·위치/진행을 바꾸는 선택은 별도 검토한다. 새 코드 구현, 보상 변경, 맵/에셋/공용 파일 변경·Play/성능 측정은 이번에 하지 않았다.

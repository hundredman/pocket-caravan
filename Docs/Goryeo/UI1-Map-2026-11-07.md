# UI1 지도 이름·이름표 수정

사용자는 앞선 공용 글자 대비를 “이대로 승인”했다. 이어 지도 표시2파일을 수정했다. 새 지도 그림은 승인 대기이며 원격 integration에는 반영하지 않았다.

## 변경

WorldMapUI가 WorldIndex의 현재 displayName을 우선 표시한다. 등록 정보가 없거나 이름이 비어 있으면 기존 atlas 이름, 마지막으로 mapId를 쓴다. 전체13구역 중 옛/축약 이름10곳을 현재 등록 이름으로 표시하고 상세5구역에도 같은 원칙을 쓴다. 북쪽 쉼터 마을·남쪽 호숫가 마을의 정착지2곳은 그대로 유지한다. 저장/지도ID/WorldIndex 데이터·생성 atlas/지형·씬·맵 이동은 바꾸지 않았다.

CuteMap은 글자의 실제 너비/줄 높이로 이름표를 잡는다. 가까운 후보가 다른 이름표/지도 점/현재 위치 핀에 가려지면 지도 틀의 빈 자리도 찾고, 멀어진 이름표는 가는 연결선으로 위치를 알린다. 긴 이름은 줄바꿈한다. 배치 결과는 지형 영역·이름/목적지·핀 자리·폰트가 같으면 재사용하며 매 OnGUI마다 전체 후보를 찾지 않는다. 임의 개수/극단적으로 긴 번역까지 겹침0을 보장하는 기능은 아니다.

하단 현재 위치/범례는 실제 글자 폭이 한 줄에 맞지 않으면 줄을 나누고 지도 영역 높이를 조절한다. 기존 공용 테마·팔레트·글꼴·작은 글자 크기와 지역별 UI배율은 유지한다. 타 문명 전용 코드/지도/데이터는 수정하지 않았지만 공용 CuteMap 변경은 타 문명에도 적용된다.

## 실행한 검사

Unity 저장OFF 자동 Play286확인·실제 GameView15캡처. 모든 캡처에서 이름표 텍스트의 창 내부 수용·이름표끼리 겹침0·지도 점/현재 핀 가림0·하단 범례 겹침0을 확인했다. 실제 이름 문자열과 atlas 전체 항목 보존도 대조했다. 화면이 바뀌지 않는 다음 프레임에서 배치 캐시 재사용을 확인했다.

- 고려 전체/상세:480×270·360×270, 전체960×540. 전체13등록 이름+정착지2, 상세5등록 이름을 확인했다.
- 검토용 의뢰로 모든 현재 장터를 목적지 표시한 전체 지도를480/360에서 검사했다. 이는 표시 스트레스 자료이며 실제 의뢰 수락/배달 검사가 아니다.
- 나루·닥나무 마을·내륙 교역 길목 실제3등록 씬에서 다른 현재 위치 핀으로 확인했다.13구역의 모든 칸을 이동한 검사는 아니다.
- 베네치아/아라비아/북유럽 실제 지도 각480/360에서 공용 표시를 확인했다. 타 문명 이름의 정합성/모든 보조 주석/게임 동작 전체를 검증한 것은 아니다.
- 실제 M/Esc는 가상 Keyboard→InputReader를 사용했다. 상세/전체 전환은 검토 도구가 private regional 값을 바꿨으며 네이티브 토글 클릭 검사가 아니다.
- 기존 사용자 저장8파일 SHA256 불변·검토 임시파일0. 본 저장은 이전부터 부재 상태이고 백업을 유지했다. 복원하지 않았다.

컴파일·정적 검사 결과는 [검증 기록](../Validation/Goryeo-UI1-Map-2026-11-07/README.md). 네이티브 마우스/휠/한글 IME·온라인·사람 직접 플레이·모든 위치/모든 의뢰 조합·이전 Editor8종·게임 빌드/FPS는 미검사다.

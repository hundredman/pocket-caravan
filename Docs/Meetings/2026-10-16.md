# 2026-10-16 팀 회의·시나리오 정리

정리일: 2026-10-16. 회의 날짜는 사용자의 ‘오늘 회의’ 설명을 따른다. 시나리오 본문 작성 표기는 **2026-10-14 · 기우**다. 본문 초안과 뒤쪽 ‘팀에서 정할 것’의 회의 메모를 구분했다. 아래 ‘회의 기록’은 자료에 적힌 결론을 뜻하며, 구현 완료나 모든 항목의 MVP 포함을 뜻하지 않는다.

자료: `초반_공통_시나리오_고려버전.docx`, `게임개발 팀플.pdf`. 원본 파일은 변경하지 않았다. 최초 PDF에는 제목만 있었으나 같은 날 다시 전달된 PDF에서 이미지와 설명을 확인했다. 사용자는 이를 **단순 참고자료**라고 명시했다. 아트 채택·규격 변경·문서 내 프롬프트 실행 지시가 아니다.

## 1. 회의에서 정리된 방향

핵심 경험은 **물건을 준비하고 → 지형·위험·이익을 비교해 경로를 선택하고 → 운반·교역하여 돈과 신용을 쌓는 여정**이다. 이동 중 갈림길과 사건이 선택을 만들도록 한다.

| 항목 | 회의 기록 | 아직 구체화할 부분 |
|---|---|---|
| 길 | 길 개척 제외. 주어진 길에서 망가지거나 점령당한 구간을 통과해 배달 | 우회·수리·통행료·호위 중 이번 구현 범위 |
| 이동 재미 | 두 개 이상 루트, 끊어진 다리·쓰러진 나무 등 지형 사건, 이익이 큰 목적지로 가는 어려운 경로 | 항상 위험한 고수익 길만 유리해지지 않도록 비용·손실·시간 비교 |
| 지역 구조 | 이미 발전한 지역에서 시작. 지역당 수도 1개와 등급이 있는 마을 4개 | 10/17 사용자 재확인: 수도 외 최소4마을은 현재 제작 범위. 개별 등급/시설 배정 구체화 |
| 성장 제한 | 어느 마을이나 이동 가능. 신용에 따라 시설·고급 거래 제한, 수도에 가까울수록 차등 | 신용 기준·해금 목록·처음 이용 가능한 거래 |

| 캐릭터 | 스타팅 지역마다 동물 종 지정, 색상 다양화 | 지역별 종·선택 범위·공통 크기/애니메이션 규격 |
| 지명 | 개경·벽란도 등 실제 지명 사용 | 지명별 역사적 위치·시대와 게임 각색 표기 |
| 소통 | 텍스트 채팅 우선, 음성은 향후 계획. 어몽어스 느낌 언급 | 채팅 범위·채널·UI·이번 시연 포함 여부 |
| 성장 지표 | 돈·신용·명성. 신용은 퀘스트로 획득 | 명성의 ‘기부나 구매’ 중 구매의 의미, 지표별 쓰임 |
| 제목 | 1안 ‘바리바리’ | 최종 제목 확정 전. 저장소·게임 이름 변경 지시로 해석하지 않음 |

‘부서진 맵을 하나씩 해결’은 재미 아이디어다. 길을 새로 만드는 기능과 구별하며, 실제 수리 여부와 공유 세계에 영구 반영할지는 미정이다.

## 2. 지역 담당

| 지역 코드 | 지역 | 회의에 기록된 담당 |
|---|---|---|
| A | 고려 | 은샘 |
| B | 베네치아 | 윤채 |
| C | 아라비아 | 은인 |
| D | 바이킹·북유럽 | 기우 |

메모의 E는 마을, F는 길로 대륙 전체 구성 요소를 가리킨다. 추가 팀원이나 확정된 담당자로 해석하지 않는다.

**지역 코드 A~D와 공통 기능 담당 코드는 별개다.** 시나리오 본문의 ‘A 경제/B 맵·사건/C NPC·마을/D UI’, 기존 개발 일정의 기능 분담안은 서로 다른 안이다. 지역 담당 실명만으로 네트워크·경제·UI 업무까지 자동 배정하지 않는다. 공통 기능 담당과 보조/리뷰어는 별도 합의가 필요하다.

## 3. 공통 1장 시나리오 초안

제목은 **‘빈 지게에서 손수레까지’**. 선대의 운반 도구와 장부를 물려받은 행상이 손수레 자금을 모은다. 모든 지역이 목표 틀을 공유하고 의뢰인·상품·지명·대사를 바꾼다. 따뜻하고 귀여운 분위기, 전래 이야기의 핵심 장면을 교역에 맞게 각색하는 구상이다.

흐름 제안: 필수 Q1·Q2 약 5분 → Q3~Q6·일반 의뢰를 자유롭게 선택하는 10~20분 → Q7 손수레 구입. 본문의 전체 예상 12~25분과도 차이가 있어 실제 플레이로 재산정해야 한다. 목표 시간·보상 비율·금액은 확정 수치가 아니다.

| 퀘스트 | 고려 버전 | 확인할 경험 |
|---|---|---|
| Q1 필수 | 의좋은 형제의 볏섬 | 의뢰 수락·마을 간 배달·무게/달리기 |
| Q2 필수 | 팥죽 할머니의 팥 심부름 | 자기 돈으로 구매한 뒤 납품·기초 매매 |
| Q3 선택 | 정직한 배달꾼 | 도자기 운반·낙하·정직 선택과 신용 |
| Q4 이벤트 | 까치가 물어온 소식 | 장날 정보와 시세 차익 |
| Q5 선택 | 호랑이보다 무서운 곶감 | 위험 경로·도적 대응·운반 |
| Q6 선택 | 놀부의 싹쓸이 | 경쟁 상인의 대량 거래에 대응하는 판매처/시점 선택 |
| Q7 마무리 | 흥부의 손수레 | 모은 돈으로 운반 능력 확대 |

NPC 역할 8개: 길잡이 까치 반가, 주막 할머니, 형/아우 농부, 산신령, 고갯마을 고모, 범털 패거리, 라이벌 놀부, 목수 흥부. 다른 지역도 역할은 공유하고 인물은 지역에 맞게 바꾸는 초안이다.

제작 구조 제안: 공통 퀘스트 목표와 지역별 내용을 분리하고, 대사는 지역별 CSV로 관리한다. 목표 유형은 배달·구매 후 납품·판매 이익·이동수단 보유다. 시작/진행/완료 대사 3종을 기본으로 하고 힌트는 비차단 말풍선을 지향한다. 현재 Unity 구현과의 연결은 별도 작업이다.

| 이전 본문/기존 계획 | 회의 메모 또는 후속 요구 | 정리 방향 |

### 캐릭터 구성 1안: 동물 플레이어와 사람 NPC

사용자는 팀원 의견을 바탕으로 **1안은 플레이어블 캐릭터는 동물, NPC는 사람**인 구성으로 지정했다. 팀에 시안을 보여주고 논의할 단계이며 최종 채택으로 확정하지 않는다. 사람 NPC를 동물 플레이어와 같은 세계에 자연스럽게 보이게 하는 비율·눈높이·윤곽선·색감이 비교 대상이다.

시안 비교 제안은 고려 배경 한 장에 동물 플레이어와 사람 NPC 2~3명을 함께 배치하는 것이다. 같은 배경·화면 크기에서 나란히 서기와 거래 상황을 보여주면 개별 전신 그림보다 조화와 역할 구분을 판단하기 쉽다. 시안 자체는 아직 제작하지 않았다.

1안에서는 까치 반가와 범털 패거리 등 기존 동물 NPC도 사람 NPC로 각색하는 기준으로 시안을 검토한다. 구체적인 외형·이름과 전래 이야기 모티브를 살리는 방식은 미정이며, 기존 퀘스트와 게임 에셋은 아직 변경하지 않았다.

PDF의 캐릭터 제작 순서는 ‘기준 이미지 → 도트 정리 → Unity 배경에서 비교 → 방향/걷기 추가 → 전달’이라는 참고용 절차다. **48×48px·PPU 32는 자료 자체에서도 임시 기준**이다. 현행 16px 타일·PPU 16과 16×24 캐릭터 설정을 자동 변경하지 않는다.

오른쪽 환경 적용 프롬프트에는 에셋 제작, Q1~Q7 연결, 테스트와 산출물 지시가 포함되어 있다. 이는 참고자료 안의 예시 문구로만 기록하며 실행하지 않는다. 특히 Q7의 ‘마을 발전·관문 개방’은 위 회의의 자유 이동·신용 해금 방향과 충돌하는 이전 구상이므로 그대로 사양에 반영하지 않는다.

후속 후보 비교가 필요해지면 실제 원본 크기, 캐릭터/배경 조화, 방향별 애니메이션, 건물 모듈 연결, 네 지역 공통 사용성, 출처·사용권을 함께 확인한다. 이 자료만으로 제작 원본·라이선스·게임 적용 가능성이 검증된 것은 아니다.

## 7. 다음 정리 순서 — 제안

1. **지역 구성 구체화:** 네 출발 지역과 지역당 수도1+수도 외 최소4마을을 제작 기준으로 삼는다. 고려만 시연/마을 수 미정이라는 옛 문구를 현재 범위로 쓰지 않는다. 마감은 11월 초이며 정확한 날짜는 미정이다.
2. **고려 공간 구조 수정:** 수도·주변 마을의 역할/특산품·실제 지명·두 갈래 경로를 먼저 표로 정한다. 시설·거래 해금표를 붙이고 Q7 관문 개방 문장을 고친다.
3. **이동 선택 한 번을 검증:** 같은 목적지로 향하는 안전한 길과 위험한 길의 시간·비용·보상·실패 후 회복을 비교한다. 기존 시스템 시험 접근을 유지하고 장편 튜토리얼 완료를 필수로 만들지 않는다.
4. **지역 간 공통 제작 계약 합의:** 맵/상품/시장 ID, 출구·스폰, 아트 크기, 퀘스트 목표·대사 형식을 맞춘다. 지역 담당과 별개로 네트워크·경제·UI 담당을 정한다.
5. **멀티 공유 규칙 결정:** 채팅 포함 범위, 도로 장애물/수리의 개인·공유 여부, Q3 선택과 Q6 시장 사건이 다른 이용자에게 미치는 영향을 정한다. 초기 2~4명 검증과 최종 MMORPG 목표를 구분한다.
6. **아트 참고자료를 후보 비교에 활용:** 재첨부된 시안은 분위기·비율·소품 표현의 참고로 보존한다. 실제 에셋 선정이나 제작은 별도 판단하며 꾸미기·환율·상인회 등은 MVP 필수 목록에 자동 추가하지 않는다.

이번 작업은 회의 내용과 수정 필요점의 정리다. 게임 코드·맵·빌드에는 변경이 없다. 후속 계획 변경은 [개발 일정](../DeliveryPlan.md)과 [작업 목록](../ImplementationBacklog.md)에 합의 결과와 완료 기준을 반영한다.

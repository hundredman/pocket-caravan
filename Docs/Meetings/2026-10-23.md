# 10월 23일 회의와 담당 범위

사용자 전달 및 후속 확인 기준. 개발 목표일은 2026-10-27(화). 전체 프로젝트의 최종 제출일과 구분한다.

- 중앙 대륙 전체 100,000칸. 고려·북유럽·아라비아·베네치아 각각 20,000칸.
- 칸은 프로젝트 Grid의 1×1 셀(16px, PPU16)이며 바다·산·건물을 포함한 전체 맵 면적이다. 통행 가능 면적만 세지 않는다.
- 팀원 한 명당 자기 문명20,000 + 중앙 대륙1/4인25,000 = 45,000칸.
- 은샘 담당은 고려와 중앙 동쪽. 다른 팀 문명이나 중앙의 다른 세 구역을 임의 제작하지 않는다.
- 장날은 중앙 대륙의 여러 마을 중 한 곳에서 열린다. 유저가 같은 장소에 모이도록 방문/거래 유인을 제공한다. 거래 보너스·신용 보너스는 후보이며 확정된 보상이나 지급 규칙이 아니다. 개최 주기·시간·마을 선정 방식도 미정.
- 마을 이동은 페이드아웃/페이드인. 지역별 생활 애니메이션과 작은 재미 요소를 추가한다.
- Git에 업로드할 때 사용자에게 알린다. 로컬 수정이나 생성만으로 Git 공유를 했다고 말하지 않는다.

## 고려 아트

2D 탑다운 **픽셀 아트**를 유지한다. 무료 에셋의 반복만으로 만들지 않으며, 고려 전용 건물·소품과 지역 배치를 제작한다. 정확한 복원보다 아름다움·흥미·게임 화면의 완성도를 우선한다. 다른 문명의 전형을 그대로 붙이지 않으며 고증된 사실과 게임 각색을 구분한다.

사용자는 마을별로 다양한 테마를 허용했다. 아래 배분은 제작 방향이며 사용자 최종 아트 승인을 뜻하지 않는다.

| 마을 | 풍경 방향 | 유지할 교역 기능 |
|---|---|---|
| 예성 나루 | 청록빛 포구와 물가, 목재 선착장 | 시작 거점·교역·입문 의뢰 |
| 개경 | 기와 전각·연못 정원·시전·등불 | 수도·상급 시설·객주 |
| 닥목 | 숲·계류·한지 작업장 | 종이 생산과 배달 |
| 송악 | 소나무·산록·산사 분위기 | 산지 교역과 북서 경유 |
| 장단 | 황금 들판·초가·추수 작업 | 농촌 교역과 남쪽 순환 |

공통 팔레트와 픽셀 밀도를 유지하며 계절 테마는 현실의 동시 계절을 복원한 설정이 아니라 지역별 미술적 각색이다. 시장/상품/퀘스트 ID와 기존 재산 저장은 보존한다.

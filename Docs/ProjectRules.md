- 위 기준과 최신 사용자 지시를 대조하고 변경 범위를 적는다.

## 2026-10-23 우선 적용 변경

[회의 확인](Meetings/2026-10-23.md): 담당 범위는 고려 전체20,000칸과 중앙 동쪽25,000칸. 바다·산·건물 포함. 10/27 화요일 개발 목표. 기존80×64 균일 청크는 면적 계약을 만족하지 않아 가변 크기 구역으로 재배치한다. 2D 탑다운 픽셀 아트·전용 에셋·마을별 다양한 테마를 사용하고 정확한 복원보다 아름다움과 흥미를 우선한다. 장날은 중앙의 한 마을에서 열리며 보상·주기는 미정이다. 원격 업로드 시 사용자에게 알린다.

## 2026-10-24 우선 적용 변경

사용자는 타일 자체 확대가 아니라 **맵 전환 없이 이동 가능한 면적 확대**를 요구했다. 고려20,000칸을 수도/4마을 중심의 넓은5권역으로 나누고 도로·자연을 포함한다. 면적은 균등 분할할 필요가 없다. 카메라는 조금 더 넓히고, 길이 반 타일처럼 경계에 걸쳐 보이지 않도록 한다. 자연 에셋 수형/종류를 늘리고 군락·빈터·물가를 고려한다. 성능과 향후 멀티플레이 비용을 검토하되, 온라인 검증 없이 안정성을 보장하지 않는다. 최신 구조는 [넓은 권역 개편](BroadGoryeoRegions.md)을 따른다.

# 돌아가며 열리는 큰 장 (중앙 대륙 장터 날) — 공통 규칙 제안

작성: 기우 (북유럽 담당), 2026-10-26. 북쪽 1/4에 먼저 구현 (`Assets/PocketCaravan/Scripts/North/NorthCraft.cs`). 공용 코드는 고치지 않았다.

PPT(10/26) "중앙 마을 교역 + 마을을 돌며 열리는 장터"를 위한 규칙. 네 조각이 같은 규칙을 쓰면, 화요일 통합 뒤 한 장소에 두 플레이어가 모이게 할 수 있다.

## 규칙
1. **하루에 한 곳.** 각 조각의 중앙 장터 마을 목록을 정해 두고, 게임 날짜(`GameManager.I.Clock.day`) % 마을 수 번째 마을에 큰 장이 선다.
   - 북쪽 1/4 차례: 북문 마을(north_post) → 눈숲 마을(north_cwood) → 개울 나루 마을(north_ccreek) → 북쪽 길목 마을(north_cross)
2. **팔 때 덤 2할.** 큰 장 마을 장터에서 팔면 판 값의 20%를 덤으로 더 준다 (`GameEvents.ItemSold`를 듣고 돈을 더함). 사는 값은 그대로.
3. **눈에 보이게.** 큰 장 마을 광장에 좌판·깃발 줄·구경꾼을 더 세운다.
4. **알려 주기.** 중앙에 들어설 때 하루 한 번 "오늘 큰 장: ○○ 마을" 알림. 길 안내·점쟁이 같은 NPC도 말해 준다.

## 통합 때 정할 것
- 네 조각을 합친 뒤에는 "중앙 전체에서 하루 한 곳"으로 바꿀지(16곳 중 1곳 → 시연 때 만나기 좋음), "조각마다 한 곳"으로 둘지.
- 멀티플레이: 큰 장 마을은 서버가 정하는 값(게임 날짜)으로 계산하므로 두 사람에게 같은 마을이 나온다.
- 덤 비율(20%)과 공용 장날(`Clock.IsMarketDay`, `marketDayDemand`)을 겹쳐 쓸지.

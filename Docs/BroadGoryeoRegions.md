## 제작 원본

기존 `continuous.py`→`compact.py`는 마을·생활 동선의 중간 제작 템플릿이다. `World/Terrain/legacy_goryeo_sources.json`은 그13개 입력만 보존한다. 현재 등록은 `World/Regions/goryeo.json`의5개다. `broad_regions.py`가 다섯 권역의 실제 크기/좌표/공통 수계/길/자연/접경을 만든 뒤 `goryeo_art.py`가 팔레트를 적용한다. export는 등록 순서로 JSON/타일/지도와 런타임 위치 이주표 `Resources/GoryeoLayout.json`을 함께 쓴다.

전용 자연 원본 `Art/Goryeo/Source/Woodland.png`: 소나무4수형, 활엽수/버드나무/자작나무/가을나무, 바위·수풀·갈대·고사목12종. 화면을 덮는 큰 이미지가 아니라 실제16px 타일로 출력한다. 자연물은 공통 좌표 기반 밀도 변화, 물가 종 선택, 길 주변 여백을 사용한다. 숲 배치는 결정적이며 재생성 시 같은 결과다.

길은 통행 셀 전체에 흙길 중심 타일을 사용한다. 다리는 실제 통행 셀이며 도로 경계의 반칸 표현과 구분한다. 서로 크기가 다른 맵의 접경은 전역 좌표로 짝을 맞추며, 걸을 수 있는 풀밭 경계도 왕복 연결한다.

## 기존 프로젝트와의 충돌/처리

- 저장: `layoutVersion=1`을 새 저장에 추가한다. 이전 저장은 원본 객체를 변경하지 않고, 유지된 마을은 좌표 오프셋/높이 보정, 폐지된 도로는 대응 권역 시작점으로 옮긴다. 재산·진행·경제 ID는 바꾸지 않는다. 실제 통행 불가 위치는 기존 안전 위치 탐색으로 보정한다.
- 의뢰/길 안내: 폐지된 맵 이름은 `GoryeoLayout.Resolve`로 해석한다. 시장/상품/NPC/퀘스트/가격 좌표는 그대로다. 지도와 안내는 현재 등록11맵을 사용한다.
- 이동 시간: 기존 작은 도로의 진입 시 가산시간은 새 마을권역에 단순 복사하지 않았다. 원래 마을은 가산0이며 일반 게임 시간은 계속 흐른다. 길이 길어진 데 따른 실제 소요시간과 의뢰 마감/교역 균형 재평가는 남아 있다. 옛 도로를 없애도 시간 균형이 완전히 같다고 주장하지 않는다.
- 종전 검사 중13개의 고려 구역명/고정40×40/특정 도로 씬 경유를 요구한 항목은 새5권역 계약으로 변경한다. 지형·스폰·강·접경·시장 수·재산 보존 검사는 유지한다.

## 성능과 멀티플레이

가장 큰 활성 맵은4,800칸이다. 모든 자연물은 타일맵으로 배치하며 개별 나무 GameObject를 만들지 않는다. 물결 애니메이션은 고려 맵당96개로 제한하고 화면 밖에서는 Sprite 교체를 생략한다. NPC/조명 수는 지역 면적에 비례해 무제한 늘리지 않는다.

현재 실제 온라인 동기화 구현은 없다. 정적 지형은 공통 콘텐츠로 배포하고 모든 타일을 반복 송신하지 않는 설계가 적합하다. 향후 움직이는 유저/NPC, 거래/시장 상태를 서버 권한으로 처리하고 근처 관심 영역만 복제해야 한다. 편집기 단일 플레이 성능 측정은 다중 클라이언트/서버 부하 검증을 대체하지 않는다.

원격 push와 새 독립 실행 빌드는 이번 개편과 별도로 판단한다. 기존3D 실험/다른 팀 지역은 보존한다.

사용자의 중간 검토에서 남북으로 긴 맵 비율이 어색하다는 지적을 받아, 세로50×80 배치를 폐기하고 북쪽3권역·남쪽2권역의 균형 잡힌 형태로 조정했다. 건물/주민 스프라이트를 늘리거나 마을 자체를 세로로 확대하지 않는다.

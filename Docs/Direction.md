# 방향 기준

정리: 2026-10-24. 사용자(은샘)가 직접 정한 개발 방향이다. **다른 문서와 충돌하면 이 문서가 우선한다.**
사용자가 새로 지시하면 다른 문서에 정정 문구를 덧붙이지 말고, 이 문서 본문을 먼저 고친다.

## 1. 아트 스타일

- **귀여운 픽셀 아트.** 실사풍이나 세밀한 채색화풍으로 만들지 않는다.
- **모든 요소를 한 스타일로 통일한다.** 플레이어 캐릭터, NPC, 건물, 자연물, 소품, 아이콘, 타일이 모두 같은 그림체·도트 밀도·팔레트·시점·빛 방향을 쓴다.
- 기준 시안: [Figma 팀 파일 `아트 시안` 페이지](https://www.figma.com/design/JeXCjYTYRGtV8FCnXWWiqe/?node-id=0-1)의 디자인 레퍼런스, 고려 캐릭터 시안, 물체·풍경 시안.
- 세부 기준, 현재 에셋의 문제, 제작 방법은 [아트 기준](ArtGuide.md)에 있다.

## 2. 에셋 사용 규칙

에셋은 **만들어진 목적 그대로만** 쓴다.

| 금지 | 예 |
|---|---|
| 잘라 쓰기 | 나무·건물·호수의 일부만 떼어 쓰기 |
| 이어 붙이기 | 작은 호수 에셋 여러 개를 붙여 큰 호수 만들기 |
| 다른 용도로 쓰기 | 언덕 조각을 밭으로, 지붕 조각을 바닥으로 쓰기 |
| 즉석 변형 | 맵 생성 중에 늘이기·줄이기·색 바꾸기로 다른 물체처럼 쓰기 |

- 필요한 것이 없으면 **새로 만든다.**
- 넓게 이어지는 것(물·해안·강·길·성벽·밭·풀/흙 경계)은 **처음부터 조립용으로 만든 에셋**만 쓴다. 조립용 에셋은 가운데·가장자리·바깥 모서리·안쪽 모서리·끝 조각을 갖춘다.
- 색이나 크기가 다른 변형이 필요하면 별도 에셋으로 만들어 등록한 뒤 쓴다.
- 한 개체 그림을 엔진 타일 크기로 나눠 놓는 것은 렌더링 방식일 뿐이다. 이때도 개체는 항상 **원래 모양 전체가 한 번에** 놓여야 한다.
- 이 규칙은 10/24 이전의 "온전한 개체 분리 허용" 기준을 대체한다.

## 3. 세계와 맵

- 1칸 = Unity Grid 1칸. 바다·산·건물을 포함한 전체 면적으로 센다.
- 세계는 중앙 대륙 **100,000칸**과 네 스타팅 지역 **각 20,000칸**으로 이루어진다. 고려는 동, 북유럽은 북, 베네치아는 서, 아라비아는 남에 있다. 네 지역은 중앙 대륙과 자연스럽게 이어진다.
- **내 담당:** 고려 20,000칸 + 고려와 이어지는 중앙 대륙 동쪽 약 25,000칸, 합계 45,000칸. 중앙 대륙 동쪽은 대륙 중심에서 시계 방향으로 대략 1~2시부터 4~5시까지의 범위다.
- **고려 구조:** 수도 개경이 중심에 있고, 네 마을이 개경을 둘러싼다. 마을을 한 줄로 길에 늘어놓지 않는다.
- **대륙과의 연결:** 고려와 중앙 대륙 동쪽은 원래 붙어 있는 땅처럼 넓은 면으로 이어진다. 좁은 길, 다리, 해협 하나로 잇지 않는다.
- **고려 배치는 사용자 검토를 받은 뒤 구현한다.** 현재 검토안은 [세계 배치](WorldLayout.md)와 [Figma `고려 배치 검토안` 페이지](https://www.figma.com/design/JeXCjYTYRGtV8FCnXWWiqe/?node-id=131-2)에 있다.
- 다른 문명과 중앙 대륙의 나머지 3/4은 다른 팀원 담당이다. 임의로 만들지 않는다.

## 4. 그대로 유지하는 이전 결정

아래는 이번 방향 전환과 상관없이 유지한다. 근거 문서는 `Reference/`에 있다.

- 2D 탑다운. 이전 3D 실험은 보존만 한다.
- 플레이어는 지역별 동물 캐릭터다. 고려 너구리, 아라비아 사막여우, 베네치아 고양이, 바이킹 북극여우.
- 핵심 재미는 교역(특산품·시세 차익)과 운반(적재·수단·경로 선택)이다. NPC 의뢰·퀘스트·시설을 포함한다.
- 주행 중 짐이 떨어지지 않는다. 대신 감속하고, 흔들림은 연출로만 남긴다.
- 플레이어가 길을 새로 내지 않는다. 길은 정해져 있다.
- 플레이어끼리 직접 거래하지 않는다. NPC 거래와 의뢰는 있다.
- 시대는 대항해시대 이전 상인 문화를 모은 가상 세계다. 정확한 복원보다 아름다움과 재미를 우선한다.
- 멀티플레이는 기본 시스템을 먼저 만든 뒤 2~4명으로 검증한다. 장기 목표는 MMORPG다. 현재 온라인 기능은 없다.
- HUD에 날짜와 시각을 표시하지 않는다. 대화는 짧게 쓰고 페이지로 나눈다.

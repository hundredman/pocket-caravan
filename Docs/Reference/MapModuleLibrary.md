# 환경 구역 원형·스킨 제작 라이브러리

2026-10-17. 사용자 요청은 문명 사이 길 몇 개를 더 연결하는 것에서 **여러 환경의 구역을 골라 교체·수정·조합하는 제작 기반**으로 구체화됐다. 이 라이브러리는 본편 등록 맵10개와 별도이며, 40개를 세계 좌표나 다른 팀 담당 문명에 자동 배치하지 않는다.

## 제공 범위

- **40개 구역 원형:** 40×40 타일. 기본 도로 연결부는 가장자리19~21의3칸, 방향은 catalogue의 ports. 마을은 시설/건물 배치 원형이며 상점·경제·NPC가 모두 붙은 완성 마을이 아니다.
- **환경 스킨13종:** 온대 초원, 침엽수림, 가을 숲, 이끼 숲, 습지, 모래 해안, 건조 초원, 고산 지대, 사막, 붉은 협곡, 설원, 툰드라, 화산암. 현재는 기존 Ninja Adventure 아트를 바탕으로 만든 팔레트/atlas 초안이다. 선인장·바위·폐벽은 별도 간단 소품을 추가했다. 13종의 완전한 신규 제작 아트셋이라는 뜻은 아니다.
- **날씨 표현8종:** 맑음, 흐림, 비, 눈, 안개, 모래바람, 낙엽바람, 반딧불 밤. 밤/낙엽은 엄밀한 기상 분류보다 연출 프리셋이다.
- **편집 도구:** 원형 검색/복제, Unity Tile Palette, 노면·충돌 브러시, 편집 지형 JSON 내보내기, 격자 recipe 조합, 별도 걷기 시험장.

40×13×8을 서로 다른 환경4,160개가 완성됐다고 세지 않는다. 지형40개와 독립 표현 프리셋이며, 조합에 따라 사막 원형의 선인장이 설원 스킨에서도 남는 등 생태적으로 어색할 수 있다. 배치·식생 종류는 해당 원형을 수정하고, 표현만 바꾸는 경우 스킨을 쓴다.

## 세 가지 독립 데이터

1. **구역 구조:** source/레이아웃 JSON의 도로 등급, 충돌, 물/다리/건물/식생 배치, 연결부. 기존 속도 계산은 RoadGrid, 충돌은 Blocked를 따른다.
2. **환경 외형:** EnvironmentSkin이 타일 이름→atlas 스프라이트로 교체한다. Overrides에 원본/대체 Tile 에셋을 넣으면 실제 새 그림으로 특정 타일을 우선 교체할 수 있다. 원본 Tile 에셋과 도로/충돌/출구/가격은 바꾸지 않는다. 미등록 타일은 원본 그림을 유지하고 LastUnmapped로 확인한다.
3. **날씨 외형:** WeatherSkin의 장면 색·안개·입자 표현. 입자는 풀을 재사용하며 설정상 최대160개. 실제 성능/서버 인원 수용량을 보장하는 수치는 아니다.

현재 비가 와서 길이 잠기거나 눈으로 물이 얼어 걷게 되는 규칙, 가시거리 판정, 피해·통행료·보급품·도적 확률은 구현하지 않았다. 화산암 스킨의 붉은 물도 자동으로 피해 지형이 되지 않으며 빙설 호수는 계속 물 충돌이다. 이후 규칙을 붙일 때는 공유 지형/날씨 상태와 시각 스킨을 분리한다. 멀티는 서버가 상태를 결정하고 클라이언트는 그 ID를 렌더링하는 방향이며 이 작업에서 네트워크 프로토콜을 추가하지 않았다.

## Unity에서 확인·편집

메뉴: **Pocket Caravan → 맵 제작 → 환경 원형 라이브러리**.

1. 원형을 검색하고 환경/날씨를 선택한다. 썸네일은 기본 환경이며 선택한 조합은 Play에서 보인다.
2. **제작 시험장 만들기/열기** → Play. 아래 원형/환경/날씨 버튼으로 바꿔 가며 WASD로 걷는다. 본편 시간/시나리오 UI와 저장 적용/자동 저장을 끈 시험장이다.
3. **독립 편집 씬으로 복제**로 새 파일을 만든다. Tile Palette에는 `Art/NinjaAdventure/TileAssets`의 기본 타일을 넣어 시각 지형을 수정한다. **기본 ModulePreview 씬은 재생성 대상**이므로 수작업은 복제 씬에서 한다.
4. **맵 제작 → 노면·충돌 브러시**를 열고 Scene 뷰에서 클릭/드래그한다. 노면0~3 또는 통행 금지/허용을 지정한다. Undo와 씬 저장을 지원한다. 그림만 바꿨다고 이동 규칙도 바뀌지는 않는다.
5. **편집한 구역을 JSON으로 내보내기**로 별도 파일에 저장한다. 원형 지형만 다루며 NPC/출구가 있는 본편 씬은 손실 방지를 위해 거절한다. 라이브러리 기본 Tile 에셋을 사용하며 새 아트는 EnvironmentSkin Overrides로 연결한다. 생성 폴더 Layouts에 수작업 파일을 덮어쓰지 않는다.
6. 복제 씬은 `previewOnly=true`다. 본편 승격 때는 ID·출구·TownData/NPC·등록부·지형 지도·저장/서버 정책을 연결하고 이 플래그를 해제해야 한다. 원형을 복제했다고 본편 통합이 자동 완료되지 않는다.

환경을 기존 맵에 적용할 때는 Grid에 MapAppearance를 붙이고 환경/날씨 에셋을 지정한다. 표준 Ground/Deco/Objects/Above 층을 자동으로 찾거나 visualLayers를 직접 지정한다. Blocked나 논리 Road 층을 넣지 않는다. Play에서 컨텍스트 메뉴 **스킨 다시 적용**을 쓴다. 편집 씬에는 임시 실행 Tile/Sprite를 저장하지 않는다. 스킨이 필요 없는 기존 맵은 컴포넌트를 붙이지 않으면 이전대로 동작한다.

## 원형 추가·조합

- 수정 원본: `Assets/PocketCaravan/MapModules/Sources/*.json`. 파일명과 id를 동일하게 두고 seed, shape, 환경, 집/나무/바위/수역 등을 편집한다. `paths`를 지정하면 `points`, `width`, `grade`로 기본 길을 대체한다. `ports`는 W/E/N/S 연결부다.
- `Tools/MapGen/Modules/catalogue.py`는 **없는 기본 source만 초기화**한다. 이미 편집한 source는 재초기화하지 않는다.
- `Modules/layouts.py`가 구조를 생성하고 `Modules/skins.py`가 환경 그림을 생성한다. 아트 교체를 위한 프로필 Override 목록은 Import에서 보존한다. 생성된 기본 프로필의 atlas/이름/날씨 수치는 재가져올 때 코드 기준으로 갱신하므로 독자 프리셋은 별도 에셋으로 복제해 관리한다.
- Ninja Adventure 원본 팩(`NA_PACK` 또는 기존 MapGen 기본 경로)과 Pillow를 준비하고, 번들 Python으로 `Tools/MapGen/Modules/export_library.py` 실행 → Unity 메뉴 **내보낸 라이브러리 가져오기**. source→Layouts/Previews/catalogue/atlas만 갱신하며 본편 생성/등록 도구는 실행하지 않는다.
- 조합 예시: `MapModules/Recipes/four_crossroads.json`. cells의 x/y/module을 교체해 네 원형을80×80으로 합친다. `python Tools/MapGen/Modules/compose.py <recipe> <output>` 실행. 맞지 않는 연결부, 분리된 구역, 중복 좌표를 거절한다.
- 그림 타일을 그대로 회전하면 나무/집이 조각나므로 완성 구역 회전은 현재 거절한다. 새 방향의 길은 source의 paths/ports/소품 배치를 수정해 만든다. 연결부는 설계된 도로의 접합 규칙이며 모든 구역 사이의 잔디 이동을 강제로 막는 벽은 아니다.
- Unity 메뉴 **네 구역 조합 시험장**에서 확인한다. 별도 실행 빌드에는 원형/조합 시험장 전환 버튼이 있다.

## 검사·빌드

- `Modules/validate_library.py`: 전 원형의 길/스폰/연결부/다리/집 입구·스탬프 보존 및 환경 atlas 검사.
- 통합 unittest: 내보낸 구조 해시, 조합 연결부와 실패 사례, 본편 좌표 비침범.
- `MapModuleChecks.Begin()`: ModulePreview Play에서 전 원형과13환경×8날씨 표현의 판정 불변 검사.
- 편집→JSON 왕복은 시각 Tile·노면 등급·충돌 값을 수정하고 내보낸 값의 좌표를 확인했다.
- 별도 빌드 메뉴 **환경 원형 시험장 Windows/macOS**. 본편 프리뷰와 다른 `Builds/ModuleLibrary` 경로를 쓴다. 이 빌드는 마을 거래/퀘스트를 완성한 게임이 아닌 제작 확인용이다.

이번 확인 기록은 [검증 요약](../Validation/ModuleLibrary-2026-10-17.json)에 남겼다. 정적 검사1,010개(스탬프/연결부 포함), Unity 원형·노면 셀/스킨 판정 검사8,745개, 통합 단위17개를 통과했다. 조합 맵은 가로/세로 경계를 실제 이동으로 통과했고 두 시험장 사이 전환도 확인했다. Mac·Windows 빌드 오류0. Windows에는 미지원 3D Terrain/VR 계열 셰이더 경고18개가 있으며 실제 Windows 실행은 별도 확인이 필요하다. Mac은 headless 첫 씬에서 저장 차단 분기를 확인했고 그래픽 확인은 Editor Play에서 수행했다.

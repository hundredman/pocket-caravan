# 개발 작업 목록


정리: 2026-10-18. 실제 구현/검사 근거는 [진행표](../Archive/DevelopmentStatus.md), 배포 범위는 [빌드 현황](BuildStatus.md) 우선. **먼저 무엇을 할지**, 일정은 [개발·검증 계획](DeliveryPlan.md)의 11월 초 마감 역산표에서 본다. 사용자가 마감을 ‘11월 초’로 확인했으며 정확한 날짜는 아직 미정이다. 기존 구현을 다시 만드는 목록이 아니라, 현재 프로토타입에서 남은 작업을 실행 단위로 나눈 것이다. 각 항목의 실제 반영은 진행표와 패치 기록으로 구분한다.

초기 MVP: 네 스타팅 지역과 여러 중간 구역, 교역/운반/경로 선택, 2~4명 실제 공유 세계 검증. 최종 제품: MMORPG 규모의 다중 접속 교역 세계. 2~4명은 최종 정원이 아니다. 아래 담당 A~D는 배정안이며, 지역 담당은 **은샘 고려·윤채 베네치아·은인 아라비아·기우 북유럽**이다. 다른 지역은 동시 개발 중이며 이 저장소에서 미통합 산출물까지 미구현이라고 단정하지 않는다. 공통 기능 A~D는 별도 배정안이다.

## 2. 우선순위와 상태

- **P0:** MVP 경험/진행/팀 통합/재산 일관성에 필수. 늦어지면 병목을 공개하고 일정·범위를 다시 합의한다.
- **P1:** 고려의 품질과 체험을 높일 작업. P0의 실제 결함과 비교해 양·세부 표현을 조절한다. 원본 요구의 영구 폐기는 아니다.
- **후속:** MVP 안정 뒤 MMORPG 확장/콘텐츠 확대. 필요한 데이터·권한 경계는 초기에 고려한다.
- 상태는 `진행 전·미구현 / 부분 구현·보완 / 검증 대기·미검증 / 완료 / 보류`로 기록한다. 아래 표의 상태는 이번 검토 시점의 기준이며 일정에 적힌 날짜가 지나도 자동 완료되지 않는다.

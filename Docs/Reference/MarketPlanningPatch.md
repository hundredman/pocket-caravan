# 교역 수량·운전자금 안내 패치

기록: 2026-10-20. 고려 지역의 자유 교역에서 **얼마나 사며, 얼마를 쓰고, 다음 교역에 얼마가 남는지** 판단하기 쉽게 만든 로컬 UI/거래 패치다. 선행 [고려 경제 조정](GoryeoTradeBalancePatch.md)을 포함한다. 공급 가격·수레 가격/용량·보수·거점 수·기존 저장 형식은 이번에 바꾸지 않았다.

## 반영한 내용

- 품목 선택 뒤 1개/최대5개/최대100개 또는 +/-로 수량을 선택한다. 잔고·실재고·적재 여유·소유 수량에 따라 실제 거래 가능한 수량과 총액을 표시한다. 배달 화물도 적재 공간을 차지한다.
- 현재 장터의 가격을 단순히 수량에 곱하지 않는다. 복제한 시장에서 한 개마다 가격·재고·시장 성장 변화를 계산한다. 미리보기는 실제 잔고/화물/재고/성장 이벤트를 바꾸지 않는다.
- 판매 예상 손익과 이번 방문 판매 정산은 실제 평균 매입 원가로 계산한다. 퀘스트 보상은 매매 대금/손익에 포함하지 않는다. 단위 판매 이벤트의 기존 정수 반올림 방식은 유지해 기존 퀘스트 계약을 바꾸지 않았다.
- 거래 직전 견적을 다시 확인한다. 잔금·원가·가격 등이 달라졌으면 시작하지 않는다. 단위 거래 중 이벤트로 가격이 바뀌면 다음 거래 전에 멈추며 완료한 수량만 정산한다.
- 운반 수단을 별도 탭으로 분리하고 구매 후 잔금을 표시한다. 잔금0이면 일반 배달로 매입 자금을 마련할 수 있다고 안내한다. 일정 잔금을 강제하거나 돈을 추가 지급하지 않는다. 판매하지 않는 수단/시장 등급 미달의 구매도 실행 단계에서 차단한다.
- 공급/수요 안내는 현재 지역 가격 설정을 따른다. 기존 originTown은 가격/출신 효과와 연결된 기준이므로 전역 변경하지 않고, 품목 상세에 ‘기준가 지역’으로 구분한다. 설정상 공급 역할은 현재 시세의 최저가 보장이나 역사적 전문 생산지 주장과 다르다.
- 비교 장부는 과거 관측한 첫1개의 가격이다. 전체 비교는 L에서 확인하며 도착 후 가격이나 전량 이익을 보장하지 않는다.

## 협업·확장 경계

공용 TownMarket/MarketState를 수정했으므로 통합된 모든 지역에 같은 UI가 적용된다. 각 지역의 상품/차량/지역 가격 데이터는 유지했다. 미통합 북유럽 Draft와 베네치아 브랜치 콘텐츠를 수정하거나 통합하지 않았다. 새 저장 필드나 맵 재생성은 없다. 기존 단위 매매 이벤트와 생성자 호출은 호환된다.

수량 견적은 **현재 로컬 시장**에 대한 계산이다. 서버 거래의 원자성·동시 구매·요청 재전송 방지·행위자별 출신/거리 검증은 EC-02에 남는다. 중간 중단이 가능한 로컬 연속 거래를 온라인 원자적 거래 완료로 취급하지 않는다.

## 검증과 남은 관찰

검증 원본/소스 커밋/빌드 해시는 [검증 기록](../Validation/MarketPlanning-2026-10-20.json)에 남긴다.

- 새 검사: 데이터15, Play16. 수량별 실제 결제, 원가, 퀘스트/성장 이벤트 보존, 오래된 견적 거절, 배달 적재, 지갑 넘침 방지, 중간 시세 변화 중단, 판매 중 퀘스트 보상 분리를 확인했다.
- 기존 검사: 고려 경제/진행 데이터57, 고려 보수·귀환 Play20, 기존 매매/수레 Play16, 로컬 상태30, Python 통합26 통과. 검사 수를 합산해 전체 게임 검증률로 쓰지 않는다.
- 1920×1080 Editor 화면에서 수량별 매입/매도, 판매 후 정산, 수레 잔금0 안내를 직접 캡처·검토했다. 처음 발견한 매도 버튼 잘림을 수정했다. 모든 화면 비율/다국어 길이를 확인한 것은 아니다.
- Windows·Mac 검토 ZIP은 별도 기록을 따른다. Mac 초기화와 실제 사람의 플레이/다른 컴퓨터 실행은 구분한다.

다음 사람 플레이에서는 수레 직후 운전자금 부족을 알아차리는지, 장부의 과거 단가를 미래 수익 보장으로 오해하는지, 손수레 확장 후 더 많은 수량을 무조건 사는 대신 한계 이익을 판단하는지 관찰한다. 첫 왕복/반복 왕복의 실제 소요 시간과 자발적 귀환품 선택을 기록한 뒤 이동 피로·거점 거리·신용 문턱을 조정한다. 재미·30~45분 분량·멀티 검증은 남아 있다.

## 남은 보완 우선순위

1. **10/19 발표 전:** 실제 PPTX·PDF·대본의 구현 현황/일정 상태를 현재 코드와 맞춰 다시 검토·출력한다. 두 파일을 동일 원본에서 갱신하고 화면 검수해야 한다. 온라인 시험 근거 없이 완료 표기를 넣지 않는다.
2. **다음 팀 공유:** 게시판 패치 포함 본편 빌드를 새로 만들고, 소스 SHA/종류/검사/해시/공유 URL을 기록한다. 현재 공개 ZIP은10/15 버전이다.
3. **팀 확정 필요:** 정확한11월 마감일, 공통 기능 실명 담당/가용시간, 출신 배율·조건, 관문/장 해금 정책, 사람 NPC1안의 최종 채택 여부. 문서 정리로 임의 확정하지 않는다.
4. **기능 후속:** 퀘스트 지역·장 제한, 북유럽 이벤트 저장/Q6, 전체 지역 통합은 미완료다. [PR #2 상세 의견](https://github.com/hundredman/pocket-caravan/pull/2#issuecomment-6235707730)과 [게시판 범위](RegionalContracts.md)를 따른다.
5. **파일 공유 범위:** 로컬 `Assets/Caravan3DPrototype/`, `Assets/GoryeoJourneyPrototype/`, `Tools/Prototype3D/` 및 관련 meta는 현재 미추적 실험이다. 삭제·이동·공유 완료로 처리하지 않았다. 본편과 함께 유지할지 나중에 별도 보존할지 정한다.

## 원본과 생성 파일

- 본편 Python 설계/등록 JSON → 완성 맵 JSON → Unity 씬/WorldIndex/지형 지도. 생성 씬만 바꾸면 재생성 때 유실될 수 있다.
- 환경 라이브러리 Sources → Layouts/스킨/프리뷰. 독립 편집 씬의 내보낸 지형 JSON을 Sources 설계 파일 전체로 덮어쓰지 않는다.
- 장애물 definitions.json → Definition 에셋, 배치 목록은 맵/씬. 에셋 수치를 직접 바꾸면 다음 가져오기에서 원본으로 돌아간다.
- 발표 제출 원본은 Presentations/2026-10-19의 PPTX/PDF 한 쌍. output은 로컬 이력/검사용이며 제출 폴더가 아니다.
- 과거 검토 파일은 이동/삭제하지 않았다. 현재 사용법과 분리하되 요구/고증/검증의 근거를 남긴다.

# Claude 판단 기록 (2026-10-25)

Codex 검토 요청 세 건(B1, A3a→A3b, R2→D10)에 대한 답. 은샘의 최신 결정(환경 아트는 지금 그림 유지, 큰 호수는 기존 유지)을 따른다.

## 1. B1 — 맵별 면적의 기준

- **기준은 저장소의 원본 계산 결과다**(`Tools/WorldLayout/layout_proposal_d_coast_v2.py`, seed 7). 은샘이 승인한 것은 그 결과의 모양(Figma v2 프레임)이다.
- [세계 배치](WorldLayout.md)의 맵별 숫자 5개는 Claude가 원본을 저장소에 옮기기 전, 작업 폴더에서 돌린 계산에서 적은 값이라 몇 칸 차이가 났다. 경계와 모양은 그대로 두고 **문서 숫자를 원본 계산 결과로 고친다**: 개경 5,001 · 나루 3,997 · 장단 4,298 · 북동 길 3,050 · 남동 길 3,051. 합계(20,000 / 25,000)와 육지 칸 수는 같다.
- Codex는 이 숫자로 B1 이관과 테스트를 이어 간다.

## 2. A3b — 지금 에셋을 어떻게 할지

은샘 결정: 지금 환경 그림이 좋다. 바꿀 것은 사용자가 짚은 것만.

| 항목 | 판정 |
|---|---|
| 건물·나무·소품 그림 (궁궐·초가·기와·버드나무·숲 등) | **유지.** 그림을 바꾸지 않는다 |
| 시트에서 잘라 쓰기(`goryeo_art.sprite`, `STAMPS`), 즉석 색 바꾸기(`recolor`, `tone`) | **지금 모습 그대로 '굽기'.** 생성 중에 자르거나 색을 바꾸는 대신, 지금 화면에 나오는 결과를 온전한 개체 PNG로 한 번 만들어 A2 목록에 등록하고 그것을 쓴다. 화면 변화 0이 완료 기준 |
| 언덕 조각을 밭으로 쓰기(`FIELD`) | 화면은 유지. 위와 같이 밭 전용 에셋으로 굽고 등록 |
| 작은 연못 | A4 새 조립 세트로 교체. **은샘 승인 완료(2026-10-25: “작은 연못 좋은 것 같아. 승인할게.”)**, 범위는 작은 연못 경계이며 큰 호수/새 물결 애니메이션 제외 |
| 큰 호수 | 지금 그대로 유지(은샘 결정) |
| 나무·건물 겹침 | C3a에서 정상 이동으로 확인 후 필요한 곳만 수정 |

**C6 다시 정의:** 옛 출처 그림을 없애는 작업이 아니다. ① 위 '굽기'로 생성 중 자르기·색 바꾸기 코드를 쓰지 않게 하고 ② 게임에서 쓰지 않는 옛 맵·옛 생성 코드의 동물 NPC 참조 등 남은 찌꺼기를 정리한다. 지금 그림(Ninja 팩 타일 포함)은 유지한다.

## 3. D10 — 평판 가격·흥정 수치 (Claude 임시안, 구현 후 은샘 플레이로 조정)

Codex 계산(R2)에서 어떤 후보든 보정이 겹치면 같은 장터에서 사서 바로 되파는 이익이 생겼다. 그래서 수치보다 먼저 **안전 규칙 하나**를 둔다.

**안전 규칙:** 모든 보정(평판, 흥정, 출신, 장날)을 적용한 뒤, 한 마을에서 어떤 물건을 사는 값은 같은 마을에서 그 물건을 파는 값보다 항상 1냥 이상 높다. 이 규칙이 있으면 같은 장터 되팔기 이익은 0이 되고, 수치는 체감 위주로 정할 수 있다.

| 단계 | 사는 값 보정 | 파는 값 보정 | 흥정 최대 폭(사고팔 때) |
|---|---:|---:|---:|
| 적대 | +15% | 0% | 흥정 불가 |
| 경계 | +7% | 0% | 흥정 불가 |
| 중립 | 0% | 0% | 3% |
| 우호 | −3% | 0% | 5% |
| 신뢰 | −6% | 0% | 8% |
| 존경 | −10% | 0% | 10% |

- 판매 가산은 쓰지 않는다(되팔기 위험이 가장 컸다).
- 계산 순서와 반올림은 지금 본편처럼 개당 계산.
- **점수 구간(임시):** 적대 −6,000~−3,001 · 경계 −3,000~−1 · 중립 0~2,999 · 우호 3,000~8,999 · 신뢰 9,000~20,999 · 존경 21,000~42,000. 출신 문명은 3,000(우호 시작)에서 시작.
- **크기 이름 → 점수(임시):** 작음 25 · 중간 75 · 큼 250. 하락도 같은 표.
- Codex 확인: 안전 규칙을 넣은 뒤 같은 계산을 다시 돌려 같은 장터 되팔기 이익이 0인지 보고한다. 품목·시설 잠금 단계는 R2 구현 때 '신뢰'(일부 희귀품·수도권 고급 시설)·'존경'(최상위)으로 연결한다.

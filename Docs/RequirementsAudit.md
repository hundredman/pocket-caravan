# 전체 요구·구현·누락 대조

기준일: 2026-10-15. 원본 《Guild & Cargo — 출신 상인과 성장 구조 계획》 15쪽 전체와 이후 사용자 요구, 현재 개발 문서·2D 코드·맵 원본·패키지·로컬 실행 검증을 대조했다. 범위는 현재 저장소의 기본 2D와 팀 통합 계획이다. 보존 중인 3D 실험의 재개나 다른 팀원 저장소의 구현까지 검사한 것은 아니다.

## 1. 완료 표기의 원칙

- **로컬 구현**: 현재 코드가 있음. 온라인·밸런스·사람의 재미까지 검증됐다는 뜻이 아니다.
- **부분 구현**: 요구의 일부만 있음. 어떤 부분이 없는지 함께 기록한다.
- **미구현/미검증**: 제안·필드·패키지·에셋만으로 완료 처리하지 않는다.
- **후속/결정 필요**: 원본 요구를 삭제하지 않고 이번 범위와 장기 범위를 구분한다. 사용자가 폐기하지 않은 기능을 임의로 영구 폐기했다고 쓰지 않는다.
- 기술 검사를 통과해도 무설명 첫 교역·반복 이동·경제 균형·2~4명 온라인은 각자 검사한다. 이 문서는 발견한 누락을 추적하는 기준이며 모든 결함이 없음을 보증하지 않는다.

## 5. 결정·실행 순서

최신 사용자 요청에 따라 아래 후속 작업은 즉시 일괄 착수하지 않는다. [전체 완성도 검토](HolisticDesignReview.md)의 게임성·협업·공유 경제·MMORPG 확장 관문을 함께 판단한다. 초기 2~4명은 MVP 검증 인원이며 최종 제품 정원이 아니다.

1. 이번 로컬 재산·의뢰·회수 수정의 회귀와 Player 빌드를 끝내고 기존 저장/씬 보존을 확인한다.
2. **로컬 저장 손상 복구와 첫 왕복/실패 후 재기**를 다음 기능 마감의 선행 과제로 둔다. 기능 존재와 사람의 이해를 함께 확인한다.
3. 팀은 네 지역 최소 산출물·실제 남은 날짜·네트워크 담당/스택·첫 두 클라이언트 통합일을 정한다. 사용자 담당 고려 아트 완성을 기다렸다가 멀티를 시작하지 않는다.
4. 고정 도로와 원본 개척의 관계, 기한 의뢰/시간 노출, NPC 모형을 결정 목록에서 관리한다. 임의로 원본 기능을 다시 대량 구현하거나 영구 삭제하지 않는다.
5. 고려 아트/동선은 GY-01~12의 우선순위로 진행한다. 날씨·배·투자 등 확장을 시작하기 전에 그 기능이 어떤 미충족 경험을 해결하는지 명시한다.

## 6. 재현 방법과 검증 한계

`Assets/PocketCaravan/Scenes/Goryeo/Dakmok.unity`에서 Play → `Pocket Caravan > Tests > 로컬 의뢰·회수·저장 검사`. 실행하면 저장하지 않는 격리 시험 상태로 바뀌므로 해당 Play의 진행은 시험 데이터가 된다. 종료 후 다시 Play한다. 시작 맵에서는 실행을 거절한다. 검사 도구는 Editor 폴더에 있어 Player 빌드에 포함하지 않는다.

`LocalStateChecks.Run()`은 의뢰 수락·지급·분실·만료·재기·최소 지역 부팅, 낙하 회수/적재/원가, 저장 흔들림·이전 JSON·ID 충돌, 게시판 조건 퀘스트를 실제 코드로 검사하고 `output/comprehensive-audit/local-state-checks.json`에 결과를 남긴다. 실제 파일 저장/강제 종료/네트워크 거래/사람의 재미 검증은 포함하지 않는다.

최종 로컬 상태 회귀 **30개 통과**. 검사 코드는 `Assets/PocketCaravan/Editor/LocalStateChecks.cs`에 보존했다. 오디오 청취점 보완을 마지막 검사에 포함했다.

기존 맵 검사66·경로4·대사102·이동 시험장19·교역/생활감15는 서로 다른 범위의 과거 검사 기록이다. 이번 새 검사를 합해 모든 기능의 자동 커버리지 비율로 표시하지 않는다. 서버가 없으므로 온라인 필수 시나리오는 여전히 전부 미통과다.

초기 결함은 변경 전 격리 실행에서 재현했고, 같은 API 경로에 대해 변경 후 재호출/거절/복구를 확인했다. 퀘스트 목록은 긴 요약 5개를 활성화한 격리 화면에서 마지막 두 항목까지 표시됨을 확인했다(`output/comprehensive-audit/quest-scroll-bottom.png`). 본편 저장·네 맵·WorldIndex·빌드 목록은 전후 해시가 같다. 이 결과는 임시 파일로 실제 저장하다 강제 종료하는 복구 검사를 포함하지 않는다.

오디오는 네 구역에서 활성 청취점 하나와 외부 청취점에 대한 양보/복구를 확인했다. 길에서 음악 재생 상태도 확인했다. 나루의 강물 클립 로딩은 확인했지만 Editor 일시정지 상태의 isPlaying=false를 재생 실패나 성공 증거로 해석하지 않는다. 실제 스피커/헤드폰 청감 검사는 별도이며 음원/음량 계산 검사만으로 실제 들린다고 단정하지 않는다.

최종 Mac Player 빌드는 성공(오류0·경고2, 약10초)했다. 경고는 ① 에디터의 미컴파일 변경으로 후처리/임포터 변경이 빌드에 반영되지 않을 수 있다는 경고 ② Unity Cloud 네이티브 심볼 업로드 토큰 부재다. 빌드 직전 isCompiling/isUpdating/Play/씬 dirty는 모두 false였고 이번 검사 메뉴도 실행됐지만, 첫 경고가 해소된 클린 에디터 빌드는 아직 검증하지 않았다. 실행 파일은 `Builds/validation-comprehensive-audit/`의 로컬 검사 산출물이며 배포 파일을 교체하지 않는다.

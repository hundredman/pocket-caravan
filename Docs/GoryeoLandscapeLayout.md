# 고려 지형·접속 재배치

> 후속 구현: [고려 교역·성장·순환 반영](GoryeoProgressionPatch.md). 이 문서의 기존 수치/연결/미구현 판정은 패치 전 검토·배치 기록이다. 현재 구현은 후속 기록을 먼저 확인한다.

기준: 2026-10-18. 사용자 방향은 ‘한국적인 지형과 전체 인상은 반영하되 한반도 윤곽을 그대로 복제할 필요는 없음’이다. 최종 지도 확정이 아니라 팀 검토용 프로토타입 수정이다.

## 실제 구현한 배치

- 개경 북쪽 궁성 서편 길 → 송악 산록 마을. 산록 북단에는 통행로와 분리한 높은 터 두 곳을 둔다.
- 개경 남문 → 예성 길 → 서쪽 예성 나루. 나루의 남쪽 강과 선착장, 길의 시내·다리와 두 경로를 유지한다.
- 개경 동문 → 닥나무 마을 → 남쪽 장단 들마을. 장단 북쪽 진입로와 주거 배치를 조정한다.
- 장단 동쪽 → 솔바람 고개 → 북쪽 솔재 → 북쪽 버들 물가 길 → 북쪽 버들나루. 새 접속로는 두 경로의 끝에 붙여 샛길/큰길 비교를 건너뛰는 지름길이 되지 않도록 한다. 버들나루 남단에는 실제 강을 건너는 다리를 둔다.

고려는 6맵(수도1+마을4+길1), 중간권은4맵 그대로다. 연결은 모두 왕복 가능하며 새로운 순환 교역망이나 다른 문명 접속을 추가한 것은 아니다. 이번 수정은 지역 동선과 지형 인상을 다듬는 단계이며, 한국 고유 건축·복식·생산 작업의 최종 아트 완성을 뜻하지 않는다.

## 고증과 각색

[만월대 기록관](https://www.manwoldae.org/front/cont/contentview.do?conId=24)의 송악산 남쪽 기슭 궁성 입지와 [국사편찬위원회 벽란도 설명](https://contents.history.go.kr/mobile/tg/view.do?ganada=&levelId=tg_002_1090&pageUnit=10&subjectCode=all&tabId=02)의 개경 서쪽 예성강 하구 교역을 지형 모티브로 참고했다. 수도 북쪽 산록, 서남쪽 나루라는 상대 인상을 적용한다.

현재 예성 나루는 벽란도 항구 전체의 실측 복원이 아니다. 닥목·송악 산록·장단 들마을의 위치, 특산품 집산 역할과 길 연결은 게임을 위한 각색이다. 실제 한반도 해안선·산맥·수계나 역사적 전문 생산지 지도를 재현했다고 설명하지 않는다. 단일 연도 고증으로 세계관을 새로 확정하지 않는다. 기존 [고려 고증 검토](GoryeoDesignReview.md)의 시대·각색 구분을 유지한다.

## 협업·경제·편집 기준

맵/마을/상품/퀘스트 ID와 GUID, 지역 등록부, TownData의 가격용 worldCoord는 유지한다. 월드 좌표의 Manhattan 거리로 가격·의뢰 보상이 계산되므로 지형 배치에 맞춰 좌표까지 바꾸지 않는다. 방향이 들어간 안내소 설명은 생성기와 실제 TownData 모두 갱신한다. 저장을 불러올 때 발밑이 새 벽·나무·물과 겹치면 가장 가까운 통행 가능한 도로의 중앙으로 옮긴다. 유효한 저장 위치·화물·금액은 유지하며 경계 출구를 복구 후보에서 제외한다. 도로 없는 제작 구역은 일반 통행 지면을 찾고 통행 지면 자체가 없는 맵은 복구 불가다. 타 담당 지역과 북유럽 Draft PR은 수정하지 않는다.

수정 원본은 `Tools/MapGen/{maps,gaegyeong,goryeo_villages,frontier}.py`다. 출구에는 반대편 도착 스폰과 도로를 함께 둔다. `cartography.layout`은 실제 출구 방향으로 지도 배치를 계산한다. 고려 확대 지도는 외부 출구를 생략한 연결된 부분집합이다.

- 게임 내 전체 지도: `Resources/WorldMap/GoryeoTerrain.png`와 `GoryeoLayout.json` (호환 파일명 유지, 실제 포함 범위는10맵).
- 고려 확대 지도: `GoryeoRegionalTerrain.png`와 `GoryeoRegionalLayout.json` (6맵). 발표8번은 이 지도를 사용한다.
- 지도는 실제 타일과 출구를 사용한다. PNG만 변형해서 실제 연결과 다른 지도를 만들지 않는다.
- 재생성: MapGen export → 맵 검사 → Unity의 `MapJsonBuilder.BuildSelected`로 변경9맵만 재생성. Route01과 다른 팀 씬은 재직렬화하지 않는다.

## 확인과 남은 작업

타일 기반 길·나무·상호작용·다리·지도 겹침 검사205개, 예성 길 수단별 경로 비교4개, 공통 등록부·지도 검사23개와18출구 정적 검사를 통과했다. 실제 Play 전환과 저장 위치 보정 결과는 [검사 기록](Validation/GoryeoLandscape-2026-10-18.json)을 따른다.

새 지형은 소스·Unity 씬·게임 지도·PPT/PDF·발표 대본에 함께 반영한다. 기존10/15 공개 ZIP과10/17 로컬 ZIP에는 이 변경이 없다. 환경 아트 교체, 수계의 맵 경계 연속성, 거점별 재방문 이유·경제 밸런스는 다음 반복 작업이다. 세계 지도에서 모든 강을 실제로 연속된 하나의 예성강으로 해석하면 안 된다.

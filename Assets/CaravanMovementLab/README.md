# 이동·운반 시험장

2026-10-18 안내. 노면·적재 감속과 시각 흔들림을 비교하는 독립 시험장이다. 신규 주행 낙하·누적 게이지·정차 안정화는 없다. [최신 구현](../../Docs/DevelopmentStatus.md).

## 실행

- Unity 메뉴 **Pocket Caravan > Tests > 이동·운반 시험장 열기** 후 Play.
- 또는 `Scenes/MovementLab.unity`를 열고 Play.
- 대사·퀘스트·돈 모으기·수레 구매 없이 등짐/손수레와 화물을 바로 선택한다.
- 별도 로컬 테스트 세션으로 실행한다. 본편 저장을 적용하거나 덮어쓰지 않는다. 내부 시계와 NPC 경제도 진행하지 않는다.
- 본편으로 돌아갈 때는 Stop 후 기존 나루 씬을 연다. 본편 빌드 목록·WorldIndex는 바꾸지 않는다.

## 조작

| 키 / 화면 버튼 | 기능 |
|---|---|
| WASD / 방향키 | 기존 본편 이동 |
| Shift | 달리기 |
| 1 / 2 | 등짐 / 손수레 즉시 전환 |
| 3 / 4 / 5 / 6 | 빈짐 / 무게 5 / 무게 10 / 현재 수단에 가득 싣기 |
| R | 출발점 복귀, 선택한 화물 복원, 체력·운반 상태·이번 측정 초기화 |
| 체력 소모 | 체력 규칙 켜기·끄기 |
| 출발 / 큰길 / 오솔길 / 풀밭 버튼 | 해당 지형으로 즉시 이동 |
| Tab | 전체 경로 보기 / 가까이 따라가기 |

등짐 적재량은 10, 손수레는 30으로 기존 본편 데이터를 쓴다. 손수레에서 등짐으로 바꾸면 화물을 등짐 한도에 맞춘다.
화물은 본편의 무게 1인 인삼을 시험용으로 무료 제공한다. 이동 수단·적재량 변경 시 측정 상태를 초기화한다.

## 비교할 요소

- **큰길:** 멀리 우회하지만 손수레가 빠르고 흔들림이 적다.
- **오솔길:** 중간 거리, 중간 속도와 흔들림. 굽은 길과 작은 다리를 지난다.
- **풀밭 지름길:** 가장 짧다. 손수레는 느리며, 화물을 실으면 더 흔들린다. 여울도 동일한 풀밭 등급으로 처리한다.
- 경로 사이의 풀밭도 이동 가능하다. 반드시 정해진 세 경로로만 갈 필요는 없다.

화면에는 발밑 지형, 실제 속도, 적재량, 체력과 이동 거리를 표시한다.
도착 깃발 쪽 광장에 들어가면 최근 세 결과를 기록한다. 날짜·시각·제한시간·카운트다운은 표시하지 않는다.
도착 후 R로 다시 시작한다. 지형 바로 이동을 쓴 결과는 전체 경로 결과와 구분한다.

추천 비교 순서:

1. 체력 소모를 끄고 무게 5로 등짐/손수레의 순수 이동 차이를 느껴본다.
2. 같은 무게 5를 유지하고 큰길·오솔길·풀밭을 각각 통과한다.
3. 같은 적재량에서 거친 노면의 감속·시각 흔들림을 비교한다.
4. 체력도 켜고 걷기/달리기를 비교한다.
5. 마지막에 각 수단을 가득 채워 적재량 차이까지 비교한다. 같은 무게 비교와 최대 적재 비교를 혼동하지 않는다.

수레 그림과 화물 상자가 캐릭터 뒤를 따라가며, 운동·속도·적재·흔들림은 본편 코드를 사용한다.
수레 자체의 별도 충돌체, 관성·선회 반경, 바퀴 물리는 이 시험장에 구현하지 않았다.
현재 수치로 경로 선택이 달라지는지는 확인할 수 있지만, 이것만으로 이동이 재미있다는 결론을 내리지 않는다.

## 다시 만들기

프로젝트 루트에서 `python3 Tools/MapGen/movement_lab.py` (Pillow 필요) 실행 후
Unity 메뉴 **Pocket Caravan > Tests > 이동·운반 시험장 만들기**.
생성기는 Play 중이거나 현재 씬에 저장하지 않은 변경이 있으면 중단한다.

원본은 `Tools/MapGen/movement_lab.py`, 시험장 JSON·씬·수레 그림은 이 폴더에 있다.
본편 공용 타일을 재사용하며, 이 시험장을 생성할 때 등록 본편 맵은 다시 만들지 않는다.

본편에 공통 손수레 표현(`CarryVisual`)이 추가되었으므로 이 시험장은 해당 표시를 끄고 자체 수레를 사용한다. 두 개가 겹쳐 보이지 않아야 한다.

2026-10-17 개발 반영: 신규 주행 낙하/게이지/정차 안정화는 사용하지 않는다. 노면/짐/속도에 반응하는 시각 흔들림은 감속 연출로 유지한다. 현재 기준은 Docs/DevelopmentStatus.md 및 실제 시험장 UI를 따른다.

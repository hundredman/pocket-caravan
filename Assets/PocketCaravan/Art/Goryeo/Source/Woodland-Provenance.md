# Woodland atlas

Generated using the built-in image generation tool during the 2026-10-23/24 session. Twelve source shapes are retained with original alpha. The exporter crops each cell to its opaque bounds, resizes to native 16px tile dimensions with nearest-neighbour sampling, limits to 18 colours and snaps alpha. This is decorative fantasy pixel art, not a botanical reconstruction.

## Prompt

Production environment sprite atlas for a Korean Goryeo top-down PIXEL ART RPG. Exactly 12 completely separated isolated natural objects in a strict 4-column 3-row grid on a transparent canvas. Each object entirely inside its cell with generous transparent margins, no labels, no ground squares, no background. True low-resolution pixel art: original logical sprites about 48x64 pixels, clear blocky pixel clusters, restrained 12-18 color shading, sharp irregular organic silhouettes, no realistic texture, no antialiasing, no soft gradient. Orthographic overhead RPG view from 55 degrees, not isometric. Cohesive muted jade green, moss green, warm bark, blue-grey granite palette. Row1 left to right: wind-bent Korean red pine with sparse asymmetric wide boughs; tall old pine with slender curving trunk and uneven broad canopy; younger irregular two-trunk pine; crooked mature pine leaning the opposite direction with exposed roots. Row2: broad deciduous oak with irregular lobed deep green canopy; slender willow with hanging leaves suitable beside a river; light silver birch with small airy crown; small yellow-green autumn deciduous tree. Row3: low irregular mossy granite boulder cluster; lush uneven fern and woodland shrub clump; clump of tall river reeds with a few tan seedheads; old fallen twisted log with small mushrooms and moss. Each asset has a distinct silhouette and asymmetry. Handcrafted fantasy game pixel art, natural woodland variety, NOT twelve copies of same tree, no round candy tree, no conifers shaped like Christmas trees, no scenery, transparent alpha. All twelve objects must be separated and never touch another grid cell. Landscape 1536x1024 sprite atlas.

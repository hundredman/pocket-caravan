## 발표에서 구분할 범위

- 현재 로컬 구현: 고려9맵(수도1+마을4+길4)+중간권4맵, 시설3종, 이동·교역·배달·장부·로컬 저장, 신규 주행 낙하 제거. 감속을 표현하는 시각 흔들림은 유지.
- 제작 도구: 환경 원형40개·환경13종·날씨8종·장애물48종은 별도 시험장이다. 본편에 전부 배치하거나 실제 날씨·전투·멀티가 완성된 것은 아니다.
- 북유럽4맵은 Draft PR 통합 검토 중. 다른 지역은 담당별로 개발 중이다. 네 문명을 현재 완성했다고 설명하지 않는다.
- 온라인과 퀘스트 지역/장 제한은 미구현/후속이다. 게시판 목적지의 지역·경로 제한은 main에 반영됐다.
- 출신 역할은 고려 정보·아라비아 적재·베네치아 판매·북유럽 이동. 최종 수치와 적용 조건은 미확정이다.
- 사람 NPC는 아트1안이다. 참고 시안을 실제 완성된 게임 캐릭터/애니메이션으로 소개하지 않는다.

10/16~18 행은 기획 정리 완료와 로컬 구현, 온라인 미구현을 나눠 표시했다. 발표 전 추가 온라인 시험이 실제로 이뤄졌다면11·12·14·16쪽과 대본을 함께 갱신한다. 기존 공개10/15 ZIP은 이 자료의 현재 구현과 다르므로 [빌드 현황](../../Docs/Reference/BuildStatus.md)을 확인한다.

이 폴더의 지정 PPTX/PDF 한 쌍이 팀 제출용이다. output은 제작 이력/검사용이며 제출 대상이 아니다. 원본 PDF/DOCX 참고자료는 보존한다.

8번은 중간권까지 가로로 나열한 전체 지도 대신 고려9맵 확대 약도를 쓴다. 송악은 개경 북쪽, 장단은 닥목 남쪽이며 실제 씬과 출구를 함께 수정했다. 한반도 실측 복원이 아닌 지형 모티브임을 구분한다.

후속 교역·성장 패치를 반영해8번 지도와12번 구현 표, 관련 대본/노트를 갱신했다. 고려9+중간권4맵이며, 선택 의뢰·지역 공급/수요·산록 순환은 로컬 구현이다. 사람의 목표 플레이타임 검증과 온라인 구현은 미완료다.

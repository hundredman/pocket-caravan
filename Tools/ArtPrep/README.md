# A5 아트 정리 도구

Python + Pillow 12.3 이상. 실제 크기 격자를 보존하며 최근접 축소·명시 팔레트 고정·반투명 제거만 수행한다. 도구 통과는 미술 승인과 다르다.

```sh
python Tools/ArtPrep/prepare_art.py input.png output.png \
  --size 16 24 --palette Tools/ArtGen/current_palette_candidates.txt \
  --report output/art-prep.json
```

- 출력 크기와 팔레트를 반드시 입력한다. D3 팔레트를 자동으로 결정하거나 변경하지 않는다. 현재 색 후보를 쓰는 시험 결과도 승인 전 시안이다.
- 확대된 픽셀 경계가 95% 이상 정수 격자에 맞을 때만 격자를 추정한다. 사진 같은 질감, 균일한 그림, 불규칙한 경계에서는 거절할 수 있다. 오류를 무시하지 말고 그림을 확인한 뒤 `--grid-step 64`처럼 수동 지정한다. `입력 크기 = 출력 크기 × 격자 간격`이어야 하며, 자르기나 종횡비 변경은 하지 않는다.
- 실제 크기로 직접 그린 입력은 확대/축소 없이 팔레트·알파만 정리한다. 축소는 `NEAREST`이고 디더링·부드러운 보간을 하지 않는다.
- 알파가 임계값(기본128) 미만이면 투명, 나머지는 완전 불투명이다. 투명 픽셀의 숨은 RGB는 0으로 정리한다. 배경 자동 제거·윤곽선 수정은 하지 않는다.
- 불투명 RGB는 명시 팔레트에서 RGB 거리상 가장 가까운 색으로 바꾼다. 출력 크기·사용 색·알파를 보고서에 기록한다. 원본과 팔레트 파일을 출력/보고서로 덮어쓰는 것을 막는다.
- 추정 결과가 맞아도 형태·표정·빛·이음매·화면 적합성은 사람이 검토한다. A2 목록/배치 검사와 사용자 승인도 별도로 필요하다.

`Docs/Validation/A5-sample-comparison.png`는 정리 전/후를 같은 배율로 보여 주는 기술 시험이다. 실제 아트·팔레트 승인본이 아니다. Claude 샘플 화면 검토는 대기다. C 시험은 이 도구로 정리한 시안으로 제출하며 본편에 넣지 않는다.
